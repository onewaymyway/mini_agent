# 四格漫画生成指南

本文档介绍 mini_agent 的四格漫画生成技能（`comic-4panel`），从主题构思到一次性生成完整四格漫画图的全流程。

---

## 概述

`comic-4panel` 是一个**编排型技能**，它不包含脚本代码，全部由 Agent 框架根据 SKILL.md 中的规范自行完成。核心流程：

```
主题构思 → 分镜脚本 → 一次性生成完整漫画 → 用户选择交付
```

**特点**：
- 一次性生成 2×2 网格布局的完整四格漫画（非四图拼接）
- 支持多候选生成，用户选择满意的版本
- 同时输出纯画面版和对白叠加版
- 优先使用中文 prompt，可切换英文
- 5种预定义画风 + 自定义风格支持


## 输入参数

### 必需参数

| 参数 | 说明 | 示例 |
|---|---|---|
| **theme** | 漫画主题/关键词 | "程序员日常"、"蕾姆的太空冒险" |

### 可选参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `style` | `anime` | 画风：anime / manga-bw / chibi / realistic / watercolor / custom |
| `style_suffix` | `""` | 自定义风格后缀（style=custom 时使用） |
| `characters` | `""` | 角色描述 |
| `output_dir` | `./comic_output` | 输出目录 |
| `filename` | `comic_4panel_{timestamp}` | 输出文件名（不含扩展名） |
| `language` | `zh` | 对白语言：zh / ja / en |
| `humor_type` | `日常` | 幽默类型：日常 / 荒诞 / 吐槽 / 温馨 |
| `num_candidates` | `2` | 每次生成的候选图数量 |
| `add_text_overlay` | `true` | 是否同时生成对白叠加版 |
| `auto_mode` | `false` | 快速模式，跳过中间确认 |
| `prompt_lang` | `zh` | prompt 语言：zh（优先中文）/ en（强制英文） |

## 生成流程详解

### Step 1: 主题构思

Agent 将用户的简短主题扩展为完整的漫画创作概念，包括：

- **核心创意**：一句话概括漫画的笑点/主题
- **风格基调**：轻松吐槽 / 温馨治愈 / 荒诞搞笑 等
- **场景设定**：故事发生的场所
- **角色设定**：包含中英文视觉描述，保证画面一致性
- **叙事弧线**：起承转合四段结构

**示例输出**：

```yaml
theme_concept:
  core_idea: "程序员写bug vs 修bug的日常反差"
  tone: "轻松吐槽"
  setting: "太空船控制室"
  characters:
    - name: "蕾姆"
      visual_desc_zh: "蓝发女仆装少女，头发遮住右眼"
      visual_desc_en: "blue-haired girl in maid outfit with hair covering right eye"
      personality: "认真负责"
  narrative_arc: "起：正常工作 → 承：发现bug → 转：修bug的荒诞过程 → 合：bug越修越多"
```

> 默认模式下，Agent 会暂停等待用户确认后再继续。

### Step 2: 分镜脚本

基于主题概念，生成4个画面的详细分镜脚本：

- 每格的**场景描述**（中英文）
- 每格的**角色表情/动作/位置**（中英文）
- 每格的**对白和旁白**
- 每格的**构图指示**（中英文）
- 明确标注**起承转合**结构

> 默认模式下，Agent 会暂停等待用户确认后再继续。

### Step 3: 生成漫画

Agent 基于分镜脚本构建单条完整 prompt，一次性调用图片生成 API 生成 2×2 网格布局的完整四格漫画。

#### Prompt 结构

**中文版**（默认）：

```
一幅2×2网格布局的四格漫画。

第1格（左上）：[角色描述]，[表情]，[动作]，在[场景]。[构图]
第2格（右上）：[角色描述]，[表情]，[动作]，在[场景]。[构图]
第3格（左下）：[角色描述]，[表情]，[动作]，在[场景]。[构图]
第4格（右下）：[角色描述]，[表情]，[动作]，在[场景]。[构图]

[风格后缀]
```

**英文版**（prompt_lang=en）：

```
A 4-panel comic strip in 2x2 grid layout.

Panel 1 (top-left): [CHARACTER], [EXPRESSION], [ACTION], in [SCENE]. [COMPOSITION]
Panel 2 (top-right): ...
Panel 3 (bottom-left): ...
Panel 4 (bottom-right): ...

[STYLE_SUFFIX]
```

#### 角色一致性策略

- 每格使用**完全相同的角色描述块** → 保证外观一致
- 风格后缀中强调 `所有格角色设计一致` / `consistent character design across all panels`

#### 多候选生成

- 默认生成 2 张候选图（`num_candidates=2`）
- 每张使用相同 prompt，利用模型随机性产生不同结果
- 候选图命名：`{filename}_v1.png`, `{filename}_v2.png`, ...

#### 对白文字叠加

当 `add_text_overlay=true`（默认）时，同时生成对白叠加版：

- 对白气泡：白色圆角矩形 + 黑色描边
- 旁白文字：半透明黑色背景条
- 叠加版命名：`{filename}_v{i}_text.png`
- 原始纯画面版保留

### Step 4: 用户选择与交付

Agent 展示所有候选图路径，用户可以：

- **选择满意的版本**：输入编号确认
- **重新生成更多**：说"重新生成"、"再来几张"、"更多"
- **回到上一步修改**：说"换个分镜"、"修改主题"

**输出文件结构**：

```
comic_output/
  ├── comic_4panel_20260619_v1.png        # 候选1 纯画面版
  ├── comic_4panel_20260619_v1_text.png   # 候选1 对白叠加版
  ├── comic_4panel_20260619_v2.png        # 候选2 纯画面版
  └── comic_4panel_20260619_v2_text.png   # 候选2 对白叠加版
```

## 风格预设

| 风格 | 说明 | 适用场景 |
|---|---|---|
| `anime` | 动漫风格，鲜艳色彩 | 通用，最推荐 |
| `manga-bw` | 黑白漫画，墨线+网点纸 | 传统日式漫画感 |
| `chibi` | Q版风格，大头小身 | 可爱/搞笑主题 |
| `realistic` | 半写实动漫，精细阴影 | 严肃/科幻主题 |
| `watercolor` | 水彩插画，柔和色彩 | 温馨/治愈主题 |
| `custom` | 用户自定义风格后缀 | 任意风格 |

### 自定义风格示例

```
画个四格漫画，主题是花田摄影，
风格用custom，风格后缀是"油画风格，厚重笔触，印象派色彩"
```

## 交互模式

### 分步确认模式（默认）

- Step 1 完成后暂停 → 用户确认主题构思
- Step 2 完成后暂停 → 用户确认分镜脚本
- Step 3-4 连续执行 → 展示候选图供选择

适合需要精细控制创作过程的场景。

### 快速模式

用户说"直接生成"、"不用确认"时启用，跳过中间确认，一步到位。

适合对结果要求不严格、快速出图的场景。

### 重新生成

- 说"重新生成"、"再来几张" → 生成新候选图，编号递增
- 说"换个分镜" → 回到 Step 2 修改分镜脚本
- 说"换个主题" → 回到 Step 1 重新构思

## 常见问题

### Q: 生成的四格漫画布局不标准怎么办？

1. 尝试切换英文 prompt（`prompt_lang=en`），英文对布局指令的理解通常更好
2. 增加候选图数量（`num_candidates=3`），从中选择最满意的
3. 在分镜脚本中更明确地描述每格的构图

### Q: 角色在不同格中外观不一致？

1. 确保角色描述足够具体（如"蓝发女仆装少女，头发遮住右眼，白色头饰"）
2. 尝试英文 prompt，角色描述的一致性通常更好
3. 多生成几张候选图，选择一致性最好的

### Q: 中文 prompt 生成效果不好？

1. 切换英文 prompt：告诉 Agent "用英文 prompt 生成"
2. 也可以中英混合：布局声明用英文，内容描述用中文
3. 某些模型（如 gpt-image-1）对中文支持较好，可优先尝试

### Q: 对白文字叠加效果不理想？

1. 纯画面版始终保留，可以直接使用纯画面版
2. 后续版本将支持自定义气泡样式、字体、位置
3. 也可以在生成后手动用图片编辑软件添加对白

### Q: 生成速度慢？

每张候选图约需 30-60 秒，多候选串行生成。建议：
- 首次生成使用 `num_candidates=2`
- 满意后不需要更多候选图

## 技术架构

```
comic-4panel (编排型 skill)
  │
  ├── SKILL.md          # 规范和知识（无脚本代码）
  │
  ├── 依赖 gen_image_with_text
  │   └── gen_image.py   # 图片生成 CLI
  │       └── agnes_tools.py  # AgnesImageClient
  │
  └── Agent 自行完成
      ├── 主题构思（LLM 生成）
      ├── 分镜脚本（LLM 生成）
      ├── Prompt 构建（按规范拼接）
      ├── 图片生成（bash 调用 gen_image.py）
      ├── 对白叠加（PIL，可选）
      └── 用户交互（确认/选择/重新生成）
```
