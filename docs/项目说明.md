# mini-claude-code 项目说明

## 项目概述

mini-claude-code 是一个用 Python 实现的简化版 Claude Code CLI 工具，支持技能（skills）系统。它提供了与 Claude AI 模型的交互接口，支持多种 LLM 提供商、工具调用、权限管理和并发控制等功能。

## 主要功能

### 核心功能
- **交互式 REPL**：支持对话式交互，可处理单条命令或进入交互式模式
- **多 LLM 支持**：支持 Anthropic、OpenAI、Ollama、NVIDIA 等多种 LLM 提供商
- **工具系统**：内置 bash、文件读写、glob 搜索、grep 等工具，支持自定义工具
- **技能系统**：可加载和管理扩展技能，支持自动激活
- **权限管理**：工具调用前需要用户确认，支持沙箱模式
- **会话管理**：支持保存、加载、恢复对话历史
- **并发控制**：支持子任务和 LLM 调用的并发限制

### CLI 命令
- `/help` - 显示帮助
- `/clear` - 清除对话历史
- `/skills` - 列出所有技能
- `/skill on/off <name>` - 激活/停用技能
- `/stats` - 显示会话统计
- `/model <name>` - 切换模型
- `/session` - 会话管理命令
- `/tasks` - 任务管理命令
- `/concurrency` - 查看/调整并发限制

## 各模块详细说明

### 根目录核心文件

| 文件 | 功能 |
|------|------|
| `main.py` | CLI 入口，参数解析，REPL 循环，slash 命令处理 |
| `agent.py` | Agent 核心循环，LLM 调用，工具执行，历史管理 |
| `config.py` | 配置加载（从环境变量、CLAUDE.md），系统提示构建 |
| `permissions.py` | 权限守卫，沙箱模式，危险命令检测 |
| `renderer.py` | Rich 库封装，终端输出格式化，流式渲染 |
| `session.py` | 会话序列化/反序列化，历史记录持久化 |
| `repl_input.py` | 行编辑，输入提示 |

### tools/ 目录

工具系统采用装饰器模式，每个工具是一个 Python 函数：

- `__init__.py`：
  - `@tool()` 装饰器：注册工具到全局注册表
  - `ToolRegistry`：工具注册和调度
  - `ToolDef`：工具定义数据结构

- `builtin.py`：内置工具实现
  - `bash` - 执行 Shell 命令
  - `read_file` / `write_file` - 文件读写
  - `create_file` / `delete_file` - 文件创建/删除
  - `list_dir` - 列出目录内容
  - `glob` - 文件路径匹配
  - `grep` - 正则搜索
  - `patch_file` - 补丁式文件编辑
  - `web_search` - Web 搜索（需配置 API）

- `orchestration.py`：任务编排工具

### llm/ 目录

LLM 抽象层，支持多提供商切换：

- `base.py`：`LLMClient` 基类，定义标准接口
- `factory.py`：根据 provider 名称创建客户端
- `debug_logger.py`：调试日志（记录请求/响应到文件）
- `system_tool_call.py`：将工具调用转换为系统提示格式

**providers/**：具体提供商实现
- `anthropic.py` - Anthropic API
- `openai.py` - OpenAI API
- `ollama.py` - 本地 Ollama
- `nvidia.py` - NVIDIA API

### orchestrator/ 目录

并发和任务管理：

- `task.py`：任务状态定义（pending/running/completed/failed）
- `task_manager.py`：任务队列管理，任务持久化
- `task_display.py`：任务表格/日志显示，实时仪表板
- `sub_agent.py`：子 Agent 实现（可并发执行复杂任务）
- `concurrency.py`：信号量控制（任务并发数、LLM 调用并发数）
- `status_bar.py`：顶部状态栏（显示活跃任务数、LLM 使用率）

### prompts/ 目录

集中化管理提示词：

- `manager.py`：`PromptManager` 类，加载和管理提示词片段
- `system/`：系统级提示词模板（角色定义、行为规则）
- `fragments/`：可复用的文本片段（CLI 消息、权限提示）
- `user/`：用户交互相关提示词

### skills/ 目录

技能系统：

- `__init__.py`：`SkillLoader` 类，技能发现、加载、激活
- 技能文件格式：`.claude/skills/<skill_name>/SKILL.md`
- 支持基于关键词的自动激活

### sessions/ 目录

自动生成的会话文件存储目录：
- 格式：`{session_id}_{timestamp}.json`
- 包含对话历史和统计信息

### tests/ 目录

单元测试：
- `test_llm.py`：LLM 客户端测试
- `test_prompts.py`：提示词管理测试
- `test_session.py`：会话管理测试
- `test_orchestrator.py`：任务编排测试
- `test_system_tool_call_and.py`：系统工具调用测试
- `test_nvidia.py`：NVIDIA 提供商测试

## 运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 设置 API 密钥
export ANTHROPIC_API_KEY=sk-...

# 运行（交互式模式）
python main.py

# 运行（单条命令）
python main.py "分析当前目录结构"

# 常用参数
python main.py --provider openai --model gpt-4o
python main.py --sandbox          # 沙箱模式
python main.py --debug-llm        # 启用调试日志
```

## 技术特点

1. **模块化架构**：LLM 抽象层支持多提供商无缝切换
2. **工具装饰器**：简单的 `@tool()` 注册机制
3. **提示词管理**：集中化提示词，便于维护和国际化
4. **并发控制**：细粒度的任务/LLM 并发限制
5. **会话持久化**：支持断点续传
6. **权限守卫**：防止意外的破坏性操作

## 扩展开发

### 添加新工具

```python
from tools import tool

@tool(
    name="my_tool",
    description="执行某个操作",
    schema={
        "type": "object",
        "properties": {
            "param": {"type": "string", "description": "参数说明"}
        },
        "required": ["param"]
    },
    requires_approval=True
)
def my_tool(param: str) -> str:
    """工具逻辑"""
    return f"结果：{param}"
```

### 添加技能

在 `.claude/skills/<skill_name>/SKILL.md` 创建技能文件：

```markdown
---
name: my-skill
description: 我的扩展功能
triggers: keyword1, keyword2
---

技能的具体使用说明...
```
