# 项目内置命令与工具信息汇总

本文档梳理了 mini-claude-code 当前支持的所有命令、工具和技能。

---

## 一、CLI 启动参数

启动程序时支持的命令行参数：

| 参数 | 简写 | 说明 |
|------|------|------|
| `--model` | `-m` | 指定使用的模型（覆盖 CLAUDE_MODEL 环境变量） |
| `--system` | `-s` | 额外的系统提示词文本 |
| `--project` | `-p` | 项目根目录 |
| `--skills-dir` | | 额外的技能目录 |
| `--verbose` | `-v` | 显示原始工具调用 JSON |
| `--sandbox` | | 沙箱模式（禁止破坏性操作） |
| `--yes` | `-y` | 自动批准所有工具调用 |
| `--no-stream` | | 禁用流式输出 |
| `--max-turns` | | 每条用户消息的最大 agentic 轮数 |
| `--provider` | | LLM 提供商：anthropic\|openai\|ollama\|... |
| `--base-url` | | 自定义 API 端点 |
| `--system-tool-call` | | 使用系统提示工具调用模式（最大兼容性） |
| `--debug-llm` | | 启用 LLM 请求/响应调试日志 |
| `--debug-llm-console` | | 同时在控制台打印调试信息 |
| `--workers` | | 最大并发子 Agent 数（默认 4） |
| `--max-llm-calls` | | 最大并发 LLM 调用数（默认 8） |
| `--session-dir` | | Session 文件保存目录 |
| `--session-fmt` | | Session 文件格式：json 或 jsonl |
| `--no-save-session` | | 禁用自动保存 Session |
| `--resume` | | 按 Session ID 恢复之前的对话 |
| `--agent-name` | | Agent 显示名称（默认：orzooo） |

## 二、REPL 交互式命令

进入 REPL 后，以 `/` 开头的命令：

### 基础命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息 |
| `/clear` | 清除对话历史 |
| `/exit` 或 `/quit` | 退出程序 |
| `/stats` | 显示会话统计信息（轮数、Token 消耗等） |
| `/verbose` | 切换详细模式（显示工具调用原始 JSON） |

### 技能管理

| 命令 | 说明 |
|------|------|
| `/skills` | 列出所有可用技能 |
| `/skill on <name>` | 激活指定技能 |
| `/skill off <name>` | 停用指定技能 |

### 模型与提供者

| 命令 | 说明 |
|------|------|
| `/model <name>` | 切换模型（如 `/model claude-haiku-4-5`） |
| `/provider` | 显示当前 LLM 提供者信息 |
| `/provider list` | 列出所有注册的提供者 |
| `/provider switch <name> [model]` | 切换 LLM 提供者 |

### 会话管理

| 命令 | 说明 |
|------|------|
| `/session` 或 `/session info` | 显示当前 Session 信息 |
| `/session list [n]` | 列出最近 n 个 Session（默认 20） |
| `/session save` | 立即保存当前 Session |
| `/session resume <id>` | 加载一个旧 Session（追加到当前历史） |
| `/session new` | 清空历史，开始新 Session |
| `/session delete <id>` | 删除一个 Session 文件 |
| `/session dir` | 显示 Session 目录 |

### 任务管理

| 命令 | 说明 |
|------|------|
| `/tasks` 或 `/tasks list` | 显示所有任务列表 |
| `/tasks dashboard` | 实时任务仪表板（直到所有任务完成） |
| `/tasks log <id>` | 显示指定任务的日志 |
| `/tasks cancel <id>` | 取消指定任务 |
| `/tasks cancel-all` | 取消所有待处理/运行中的任务 |
| `/tasks workers <n>` | 设置最大并发工作线程数 |

### 并发控制

| 命令 | 说明 |
|------|------|
| `/concurrency` 或 `/concurrency status` | 显示当前并发限制和队列状态 |
| `/concurrency tasks <n>` | 设置最大并发任务数 |
| `/concurrency llm <n>` | 设置最大并发 LLM 调用数 |

### 其他

| 命令 | 说明 |
|------|------|
| `/compact` | 压缩对话历史为摘要（节省上下文窗口） |
| `/prompts` | 列出所有管理的提示词文件 |

## 三、内置工具

Agent 可以通过工具调用使用的内置函数，全部在 `tools/builtin.py` 和 `tools/orchestration.py` 中定义。

### 文件操作工具

| 工具名 | 功能 | 需要审批 | 参数 |
|--------|------|----------|------|
| `read_file` | 读取文件内容，支持指定行范围 | ❌ | `path`, `start_line`, `end_line` |
| `write_file` | 覆盖或创建文件 | ✅ | `path`, `content` |
| `create_file` | 创建新文件（文件已存在会失败） | ✅ | `path`, `content` |
| `delete_file` | 删除单个文件 | ✅ | `path` |
| `patch_file` | 补丁式编辑文件（精确查找替换） | ✅ | `path`, `old_string`, `new_string` |
| `list_dir` | 列出目录内容，支持深度限制 | ❌ | `path`, `depth` |
| `glob` | 按通配符模式查找文件 | ❌ | `pattern`, `root` |
| `grep` | 在文件中正则搜索 | ❌ | `pattern`, `path`, `file_pattern`, `case_sensitive` |

### Shell 命令

| 工具名 | 功能 | 需要审批 | 参数 |
|--------|------|----------|------|
| `bash` | 执行 Shell 命令 | ✅ | `command`, `timeout`, `workdir` |

### Web 搜索

| 工具名 | 功能 | 需要审批 | 参数 |
|--------|------|----------|------|
| `web_search` | 网络搜索（需配置 API 密钥） | ❌ | `query` |

> **注意**：`web_search` 当前是占位实现，需要配置 `BRAVE_API_KEY` 或 `SERPER_API_KEY` 才能使用真正的搜索功能。

### 并发编排工具

| 工具名 | 功能 | 需要审批 | 参数 |
|--------|------|----------|------|
| `spawn_agent` | 派生单个子 Agent 异步执行任务 | ❌ | `prompt`, `name`, `depends_on`, `model`, `system_extra`, `tags` |
| `spawn_agents` | 批量派生多个子 Agent | ❌ | `tasks` (任务列表) |
| `get_task_status` | 查询任务状态和结果 | ❌ | `task_id`, `include_log` |
| `list_tasks` | 列出所有任务及其状态 | ❌ | `status`, `tag` |
| `cancel_task` | 取消指定任务 | ❌ | `task_id` |
| `wait_for_tasks` | 等待多个任务完成 | ❌ | `task_ids`, `timeout_seconds` |

### 工具审批说明

- **需要审批（✅）**：涉及写操作、执行命令等可能产生副作用的操作
- **不需要审批（❌）**：只读操作或安全的操作

沙箱模式（`--sandbox`）下，所有需要审批的工具都会被阻止。

## 四、可用技能

技能定义在 `.claude/skills/` 目录下，每个技能一个 `SKILL.md` 文件。

### python-expert

| 属性 | 值 |
|------|-----|
| **描述** | Expert Python coding assistant with best practices for modern Python development |
| **触发词** | python, py, pytest, fastapi, django, flask, asyncio, pydantic |

**技能内容摘要：**

- **风格规范**：使用 Python 3.10+ 特性（match/case、`|` 联合类型）、`dataclasses`、`pathlib.Path`、`f-strings`、类型注解
- **测试**：使用 `pytest`（非 unittest）、`pytest.fixture`、参数化测试、`pytest-mock`
- **异常处理**：抛出具体的异常类型、使用 `contextlib.suppress`、文档化异常
- **性能**：优先使用生成器、`functools.lru_cache`、先 profiling 再优化

## 五、命令执行流程

```
用户输入
    ↓
REPL 输入处理 (repl_input.py)
    ↓
命令解析 (main.py _handle_slash)
    ↓
Agent.run_turn()
    ↓
LLM 处理 (agent.py _agentic_loop)
    ↓
工具调用 → 权限检查 (permissions.py) → 工具执行 (tools/)
    ↓
结果返回给用户
```

## 六、快速参考

### 常用命令组合

```bash
# 启动并指定模型
python main.py --model claude-haiku-4-5

# 沙箱模式（安全测试）
python main.py --sandbox

# 自动批准所有操作
python main.py --yes

# 自定义 Agent 名字
python main.py --agent-name MyBot

# 启用调试日志
python main.py --debug-llm
```

### 常用 REPL 命令

```text
/help              # 查看帮助
/stats             # 查看统计
/skills            # 查看技能
/session list      # 查看历史会话
/tasks             # 查看子任务
/concurrency       # 查看并发状态
```
