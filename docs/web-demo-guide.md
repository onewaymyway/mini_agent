# Web Demo 使用指南

> 基于 Streamlit 的 mini-agent 图形化交互界面

## 简介

`apps/mini_agent_webdemo/app.py` 提供了一个功能完整的 Web 界面，允许用户通过浏览器与 mini-agent 进行交互。

## 快速开始

### 1. 启动 HTTP 服务

首先确保 mini-agent 的 HTTP 服务已启动：

```bash
# 启动 mini-agent 并启用 HTTP 服务
python -m mini_agent --http --http-port 8765
```

### 2. 启动 Web Demo

```bash
# 安装依赖
pip install streamlit requests

# 启动 Web Demo
streamlit run apps/mini_agent_webdemo/app.py
```

默认会在浏览器中打开 `http://localhost:8501`

## 功能模块

### 侧边栏配置

#### 服务配置

| 选项 | 说明 | 默认值 |
|------|------|--------|
| API 地址 | HTTP 服务地址 | `http://127.0.0.1:8765/v1` |
| Token 来源 | 手动输入或从文件读取 | - |

#### 连接状态

- **绿色** ✓ 已连接，显示当前 Agent 状态
- **红色** ✗ 未连接

Agent 状态包括：
- `idle` - 空闲
- `running` - 运行中
- `waiting_permission` - 等待审批
- `error` - 错误

#### 运行统计

显示:
- 总轮次数
- Token 使用量

#### 视图开关

- **显示事件流** - 切换右侧事件流面板
- **文件系统** - 切换文件浏览面板

#### 操作按钮

- **中断执行** - 停止当前正在执行的任务
- **清空对话历史** - 清除所有对话记录
- **清空事件日志** - 清除事件流记录

### 主对话区

#### 消息显示

- **用户消息** - 紫色渐变背景，右侧对齐
- **Agent 消息** - 绿色背景，左侧对齐
- **流式输出** - 显示闪烁的光标

#### 输入区域

```
┌─────────────────────────────────────────────────────┐
│ 消息输入                                            │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 输入消息... (点击「发送」按钮)                 │ │
│ └─────────────────────────────────────────────────┘ │
│ [📨 发送] [📋 同步历史] [📊 查看 Turns] [🔔 拉取事件] │
└─────────────────────────────────────────────────────┘
```

按钮功能：
- **发送** - 发送消息给 Agent
- **同步历史** - 从 HTTP 服务拉取对话历史
- **查看 Turns** - 展开 Turn 历史记录面板
- **拉取事件** - 手动拉取新的事件

### 右侧事件流面板

显示实时事件类型包括：

| 事件类型 | 图标/颜色 | 说明 |
|----------|-----------|------|
| token | 白色 | 流式输出的 token |
| tool_call | 橙色 🔧 | 工具调用请求 |
| tool_result | 绿色 ✅ | 工具执行结果 |
| tool_error | 红色 ✗ | 工具执行错误 |
| turn_start | 蓝色 ▶ | 新轮次开始 |
| turn_done | 绿色 ✓ | 轮次完成 |
| permission_req | 橙色 ⚠️ | 权限请求 |
| error | 红色 ✗ | 错误信息 |
| info | 灰色 ℹ️ | 一般信息 |
| warning | 黄色 ⚠️ | 警告信息 |

支持事件类型过滤。

### 权限审批面板

当 Agent 请求需要权限的工具时，会在对话区下方自动显示审批面板（内联实时渲染）：

```
┌─────────────────────────────────────────────────────┐
│ ⚠️ 权限审批                                         │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 🔐 权限请求：bash                               │ │
│ │ ┌─────────────────────────────────────────────┐ │ │
│ │ │ {                                                             │ │ │
│ │ │   "command": "rm -rf /tmp/cache",           │ │ │
│ │ │   "timeout": 30                             │ │ │
│ │ │ }                                                             │ │ │
│ │ │ [展开/收起]                                 │ │ │
│ │ └─────────────────────────────────────────────┘ │ │
│ │                                                 │ │
│ │ [✅ 批准 (y)] [⚡ 永久批准 (a)]  [❌ 拒绝 (n)] [🚫 永久拒绝 (d)] [✏️ 编辑 (e)] │ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

**审批选项说明：**

| 快捷操作 | 按键 | 说明 |
|----------|------|------|
| ✅ 批准 | `y` 或 `yes` | 仅批准当前这一次请求 |
| ⚡ 永久批准 | `a` 或 `always` | 批准并添加到白名单，以后同类请求自动通过 |
| ❌ 拒绝 | `n` 或 `no` | 仅拒绝当前这一次请求 |
| 🚫 永久拒绝 | `d` 或 `deny` | 拒绝并添加到黑名单，以后同类请求自动拒绝 |
| ✏️ 编辑命令 | `e` | 仅对 bash 命令可用，可修改命令后再批准 |

**快捷输入方式：**

1. **直接输入指令**：在输入框中输入 `y`/`a`/`n`/`d` 然后按发送
2. **点击按钮**：直接点击审批面板中的对应按钮
3. **命令行输入**：也可以在 mini-agent 的命令行终端中输入审批指令

### 文件系统面板

启用后可浏览项目文件：

- 目录导航（点击进入子目录）
- 文件预览（点击查看文件内容）
- 当前路径显示

## API 集成说明

Web Demo 通过以下 API 端点与服务交互：

| 端点 | 方法 | 用途 |
|------|------|------|
| `/v1/health` | GET | 健康检查 |
| `/v1/status` | GET | 获取 Agent 状态 |
| `/v1/chat` | POST | 发送消息 |
| `/v1/interrupt` | POST | 中断执行 |
| `/v1/history` | GET/DELETE | 对话历史管理 |
| `/v1/events` | GET | 获取事件列表 |
| `/v1/turns` | GET | 获取 Turn 列表 |
| `/v1/permissions/pending` | GET | 待审批权限 |
| `/v1/permissions/{req_id}` | POST | 审批权限 |
| `/v1/fs/list` | GET | 列出目录 |
| `/v1/fs/read` | GET | 读取文件 |

## 故障排除

### 连接失败

1. 检查 HTTP 服务是否启动
2. 确认 API 地址和端口正确
3. 检查 Token 是否正确

### 事件不显示

1. 确认状态连接正常
2. 检查事件类型过滤设置
3. 手动点击「拉取事件」按钮

### 权限审批无响应

1. 审批操作可通过 Web 界面按钮或输入框快捷指令完成
2. 输入 `y`/`a`/`n`/`d` 后点击「提交审批」按钮
3. 点击审批面板按钮后，状态会在 1.5 秒内自动刷新
4. 查看侧边栏「调试日志」了解审批请求详情
5. 确认 HTTP 服务的 PermissionGate 已正确配置

### 状态不同步

1. 点击侧边栏「🔄 刷新」按钮手动同步状态
2. 检查「显示事件流」面板中是否有 permission_done 事件
3. idle 状态下系统会自动进行 2 次补同步，确保不漏掉最后的事件

## 限制与注意事项

1. **实时性**：依赖于 HTTP 轮询，非真正的实时推送
2. **文件大小**：文件预览限制在 5000 字符以内
3. **浏览器兼容**：推荐使用 Chrome、Firefox、Safari 等现代浏览器
4. **认证安全**：生产环境务必设置强 Token
