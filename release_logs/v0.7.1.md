## 🎉 概览

v0.7.1 是一个重大功能版本，重点聚焦于 **自我演化系统（Stage 2-4+）**、**Daemon 多用户架构**、**隐私保护**、**热重载系统**、**工具调用格式自动纠错**、**终端/CLI 改进**，以及大量的 **文档与测试完善**。

本版本跨度 **1100+ 次提交**，时间范围 2026-06-20 至 2026-06-27，约一周的高强度开发。

---

## 🚀 核心新功能

### 1. 自我演化系统（Stage 2-4+ / Phase C, W2, W3, G）

自我演化系统大幅扩展，包含多个阶段：

| 阶段 | 描述 | 核心组件 |
|------|------|----------|
| **Stage 2** | 安全网：StateRepo / 验证流水线 / EvolutionWorkspace | `StateRepo`、`Validators`、`EvolutionWorkspace`、`evolution` CLI 命令 |
| **Stage 3.1 / Phase C** | Lesson → Skill 闭环 | `EvolutionAgent`、`LessonReview`、`SkillPropose`、`skill_propose` 工具 |
| **Phase W2** | Workdir 知识层 | `WorkdirKnowledge`、`TimelineReflection`、`workdir_knowledge` 工具 |
| **Phase W3** | Global 知识层 | `GlobalKnowledge`、`ContextBuilder` 集成、知识搜索 |
| **Phase G** | 后台循环 | `PhaseG` 后台任务循环、提醒匹配、Lesson 复盘 |
| **Eval 系统** | 评估框架 | `eval` CLI 命令、`EvalRunner`、评估测试 |

**关键特性：**
- **Lesson 记忆系统**：从用户纠正中自动提取 Lesson，会话结束时自动反思
- **纠正检测器**：自动检测用户纠正并提取 Lesson
- **Lesson 规则**：基于规则的 Lesson 验证与去重
- **演化 Agent**：专门从 Lesson 提出 Skill 的子 Agent
- **Skill 提案**：自动化 Skill 提案，经 StateRepo T1 级安全验证
- **Workdir 知识**：项目级知识跨会话持久化
- **Global 知识**：跨项目知识共享
- **后台循环**：提醒、Lesson、演化的自主后台处理

### 2. Daemon 多用户架构

Daemon 模式完全重构，支持多用户：

- **新架构**：`SessionPool`、`UserStore` 多用户会话管理
- **会话隔离**：每用户独立会话与上下文
- **API 层**：`bridge.py`、`server.py` 提供 HTTP/WebSocket API
- **Daemon CLI**：增强的多用户 Daemon 命令
- **测试覆盖**：新增 `daemon_test.txt` 测试用例

### 3. 隐私保护系统

全新的隐私保护机制，防止敏感数据泄露：

- **Privacy Guard 模块**：`src/mini_agent/perception/privacy_guard.py`
- **配置集成**：`agent_config.json` 中的隐私模式配置
- **自动脱敏**：自动检测并脱敏 API Key、Token、密码等敏感模式
- **测试覆盖**：`privacy_text.txt` 测试用例、隐私集成测试

### 4. 热重载系统

开发与运行时配置热更新能力：

- **热重载模块**：`src/mini_agent/perception/hot_reload.py`
- **监控目标**：Skills、配置、工具、Agent Profile
- **自动重载**：文件监听 + 防抖重载
- **文档**：新增 `docs/hot-reload-guide.md`

### 5. 工具调用格式自动纠错与重试

自动检测并修正格式错误的工具调用：

- **格式纠错检测器**：`src/mini_agent/perception/format_correction_detector.py`
- **自动重试**：LLM 产生格式错误时自动重试修正后的格式
- **可配置**：重试次数、纠错模式通过配置控制
- **测试**：`test_format_correction_detector.py`、`test_format_correction_integration.py`
- **文档**：`docs/format-correction-detector-update.md`

### 6. Raw Output 模式

终端显示的原始输出模式：

- **Raw Output 标志**：`--raw-output` CLI 参数
- **终端集成**：绕过 Rich 格式化的原始模式
- **工具结果截断**：与 raw-output 参数联动的可配置截断
- **文档**：`docs/raw-output-mode-guide.md`

### 7. 新内置工具：`patch_file_simple`

基于行锚点的简化补丁工具：

- **行锚点编辑**：使用起止行号 + 内容进行精准编辑
- **更健壮**：避免了 `patch_file` 的空白匹配问题
- **文档**：`docs/patch-file-simple-guide.md`

## 🔄 迁移指南

### 配置变更
- `config.py` 已拆分为 `config/` 包，需更新导入：
  ```python
  # 旧
  from mini_agent.config import Config
  # 新
  from mini_agent.config.models import Config
  from mini_agent.config.loader import load_config
  ```

### 新增配置项（agent_config.json）
```json
{
  "privacy": {
    "enabled": true,
    "patterns": ["sk-", "api_key", "password", "token"]
  },
  "hot_reload": {
    "enabled": true,
    "watch_paths": ["skills", "config"]

  "format_correction": {
```
