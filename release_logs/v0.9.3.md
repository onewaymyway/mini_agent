# v0.9.3 更新说明

> 发布日期：2026-07-27
> 涵盖 commit 区间：2026-07-20 ~ 2026-07-27（约 7 天迭代）

本版本是一次以 **Workflow 体系全面升级** 为主线、围绕 **看板（Kanban）/ 自主执行 / 自主进化** 持续打磨的重大迭代，同时补齐了 **知乎内容发布** 端到端工作流、**主动推荐 + 日报 + 决策画像** 机制，以及 **LLMHelper 统一化** 等多项基础设施改进。

---

## 🌟 核心亮点

### 1. Workflow 体系全面升级

Workflow 从"单文件 YAML"演进为"文件夹化 + 本地 Agent/Skill/Prompt"的完整工程形态，并补齐了从编写、调试、运行到扩展的全链路能力。

- **文件夹化模式**：每个 workflow 拥有独立目录，可携带私有 `agents/`、`skills/`、`prompts/`、`steps/` 资源；新增 `resource_bundle.py`、`agent_spawn.py` 负责本地资源加载与子 Agent 派生。
- **Python Step 支持**：新增 `py_step_runner.py` 与 `py_context.py`，允许 workflow 直接执行 Python 脚本作为 step，并提供 subprocess 端到端测试。
- **Session → Workflow 转换**：新增 `session_summarizer.py` 与对应 prompt，可将历史 session 一键提炼为可复用 workflow。
- **CLI 直接运行**：新增 `workflow_cmd.py`，支持命令行直接执行 workflow；同步新增 `workflow-debugger` skill（沙箱跑单步、断点续跑、长期统计）。
- **可扩展性**：新增 `plugins.py` 与 `myplugins/example_http_step.py`，支持自定义 step 类型；新增 `git_integration.py`，workflow 可感知 git 状态。
- **稳定性与可观测性**：
  - `watchdog.py` 看护机制 + 趋势感知
  - `api_helpers.py` 统一 API 调用
  - `executors.py` 增加异常处理、`SkillAgentStepExecutor` 的 `max_turns` 限制
  - `runner.py` 完善事件保存、修复输出异常、修复进程死锁
  - `schema.py` / `store.py` / `tools.py` 持续打磨
- **示例与模板**：
  - 新增 `doc_change_review`、`notify_summary`、`release_pipeline` 等示例 workflow
  - 新增 `code_review`、`multi_perspective_debate`、`research_report` 三个内置模板
- **Skill 同步**：更新 `workflow-generator` 与 `workflow-debugger` 两个 skill 文档。

### 2. 知乎内容发布工作流（zhihu_content_publish）端到端打通

从零搭建并持续迭代了完整的 5 步发布流程：

| Step | 作用 |
|------|------|
| `01_analyze_doc` | 解析输入文档，提取主题与候选问题 |
| `02_search_zhihu` | 在知乎站内搜索相关问题（已优化搜索策略） |
| `03_filter` | 批量筛选候选问题 |
| `04_enrich_questions` | 批量补全问题字段 |
| `05_enrich_questions`（单问题版） | 单问题深度补全 |

配套新增 prompts（`01_analyze_doc.md` / `02_search_zhihu.md` / `03_filter_batch.md` / `04_enrich_questions.md` / `04_enrich_missing_fields.md` / `04_enrich_single_question.md`）与 step 实现，并补充 `tests/test_zhihu_workflow_steps.py` 覆盖。

### 3. 看板（Kanban）大改版 + 自主执行 / 自主进化

看板从"信息展示"升级为"主交互界面"，并承载自主执行与自主进化的可视化与控制能力。

- **主交互界面**：新增 `看板主交互界面改进方案.md`，看板成为日常操作主入口。
- **产出预览（Artifacts Dashboard）**：新增 `diff_view.py`，支持产出文件预览与 diff 查看。
- **Cron Job 创建**：看板可直接创建定时任务。
- **大数据量分页**：新增 `看板大数据量分页显示改进计划.md`，解决长列表性能问题。
- **自主执行 / 自主进化改进方案**：新增 `kanban_and_autonomy_improvement_plan.md` 与实施记录，迭代多轮：
  - `objective_executor` 多轮迭代（adaptive_concurrency、kanban_tracks r2/r3/r4、outcome_tracker）
  - `proposal_risk.py` 提案风险评估
  - `resource_arbiter` 资源仲裁与门控
  - `autonomous_loop` 自主循环优化
  - `soft_goal_deriver` 软目标派生
- **API 扩展**：`api/routes.py` / `api/server.py` / `api/models.py` 持续完善看板相关接口。

### 4. 主动推荐 + 日报 + 决策画像

新增"数字分身"机制，让 Agent 能主动给出建议、生成日报、沉淀决策画像。

- **日报（Daily Digest）**：新增 `daily_digest.py` 与 `digest_cmd.py`，日报增加错误统计信息，修复 daemon 模式下看不到日报的问题。
- **主动推荐（Next Action Advisor）**：新增 `next_action_advisor.py` 与 `next_action_cmd.py`，基于当前状态推荐下一步动作。
- **决策画像（Decision Profile）**：新增 `decision_profile_builder.py` 与 `profile_cmd.py`，沉淀用户决策偏好。
- **Cron 调度器**：`cron_scheduler.py` 持续完善。
- **Work Index 主动提醒**：新增 `work_index_proactive_reminder_design.md`，让 Agent 在合适时机主动提醒未完成事项。

### 5. LLMHelper 统一化

将主对话循环之外的所有 LLM 调用统一收敛到 `LLMHelper`，降低分散调用带来的不一致与维护成本。

- 新增 `src/mini_agent/llm/service.py`
- 改造范围：`ensemble/`（decision / judge / runner / strategies）、`evolution/objective_executor`、`perception/goal_backlog`、`perception/memory_factory`、`agent/turn_loop`、`agent/llm_control`、`api/server`、`tools/orchestration`
- 新增 `tests/test_llm_helper.py` 与 `tests/test_orchestration_llm_helper_provider.py`
- 新增 `docs/llm-helper-guide.md`

### 6. Browser-CDP Skill 增强

- 知乎相关脚本持续优化：`zhihu_search.py` / `zhihu_search_with_login.py` / `zhihu_column_search.py` / `zhihu_hot.py` / `launch_zhihu_logged_in.py`
- 新增 `tests/test_browser_cdp_detect_running.py`（检测运行中的浏览器）
- 新增 `tests/test_browser_cdp_dedicated_port_fallback.py`（专用端口 fallback）
- 新增 `next_doc/browser_cdp_stability_fixes.md` 稳定性修复记录

### 7. Skill 系统优化

- `active_skills.md` / `agent_core.md` / `skill_manager.py` 持续打磨
- `reminders_correction.py` 增强 reminder 纠错
- 新增 `docs/skill-system-guide.md`

### 8. Goal Mode 改进

- `goal_spec_builder.md` 优化验收标准生成 prompt
- `goal_mode/runner.py` / `goal_mode/spec.py` / `goal_mode_cmd.py` 多轮迭代
- `perception/goal_backlog.py` 持续完善
- 新增 `docs/goal-mode-guide.md`

## 🛠 稳定性与体验修复

- **进程死锁**：修复 `agent/_helpers.py` / `api/server.py` / `ui/renderer.py` / `workflow/runner.py` 中偶发的进程死锁问题。
- **Daemon 输入**：修复 daemon 进程无法输入的问题（`cli/daemon.py`）。
- **临时文件路径**：
  - 修复子 agent 数据保存到错误位置的问题
  - 统一临时文件与结果文件目录到主 agent 目录
  - 修复修改临时文件后报错的问题
- **Turn Judge 模型切换**：修复模型切换后 turn_judge 模型未更新的问题（`agent/llm_control.py`）。
- **Max Turns 自动继续**：新增达到 `max_turns` 后自动继续的机制（`agent/turn_loop.py` + `config/loader.py` + `config/models.py` + `agent_config.json`）。
- **Hard Loop 统计**：更新 `_hard_loop_count` 统计逻辑（`agent/turn_loop.py`）。
- **异常信息**：增加异常信息打印（`tool_executor.py`）与异常信息保存（`cli/app.py`）。
- **Workflow 输出**：解决有时候 workflow 输出不对的问题（`workflow/executors.py`）。
- **Workflow 错误堆栈**：workflow 执行错误增加堆栈信息（`workflow/runner.py` + `workflow/schema.py`）。
- **类型问题**：解决 `tools/__init__.py` 中的类型不对问题。
- **命令执行**：解决部分命令无法正确执行的问题（`next_action_cmd.py` + `profile_cmd.py`）。
- **开关失效**：解决开关不起作用的问题（`config/loader.py`）。
- **关闭每 turn 检索**：新增关闭每个 turn 开始的检索逻辑的开关（`config/models.py` + `context_builder.py` + `agent_config.json`）。
- **模型下架提示**：NVIDIA provider 增加模型下架提示（`llm/providers/nvidia.py`）。
- **删除无用日志**：清理 `perception/token_counter.py` 中的无用日志。
