# Release Notes — v0.9.4

**发布日期：** 2026-08-04  
**提交范围：** 2026/7/27 ~ 2026/8/4（共约 70+ commits）

---

## 🚀 新增功能

### hybrid_exec 脚本/LLM/Agent 混合执行系统
全新引入混合执行架构，支持脚本优先、LLM 探索、Agent 兜底的三级执行策略：
- 新增 `src/mini_agent/hybrid_exec/` 模块：executor、explorer、fallback、repairer、runner、spec、workflow_integration 等核心组件
- 新增 CLI 命令与 API 路由，支持 `mini-agent hybrid-exec run/list/show` 等命令
- 新增 `hybrid-exec-task-generator` skill，帮助用户从零构建符合规范的 TaskSpec
- 提供端到端可运行演示脚本 `examples/hybrid_exec_demo.py`
- 新增测试用例覆盖探索/修复/降级全流程

### Cron 任务专属执行机制
- 新增 `cron_job_executor`、`cron_job_runner`、`cron_job_workspace` 独立执行模块
- 新增 `cron_agent_bridge`，实现 Cron 与 Agent 执行通道的桥接
- 支持 Cron 任务独立工作空间与调度验证

### Session 清理功能
- 新增 `session_cleanup` 模块，支持自动清理过期/废弃 session
- 集成至 cron_scheduler，可通过定时任务触发清理

### 外部输入网关扩展
- 新增 `watchlist` 订阅机制与 `report_tiers` 报告分级系统
- 新增通知模块 `notification/`（dispatcher、channels/email、channels/kanban）
- 新增外部数据去重与持久化（`poll_history`、`novelty_judge`）
- 新增归档 GC 模块（`archive/gc.py`）
- 看板新增「🔌 外部输入」面板，支持来源/路由规则/待处理告警/事件流水的分页展示

### 外部数据知识化与自我改进闭环
- 新增 `external_input/knowledge_extractor.py`，将外部数据自动知识化
- 新增 `tech_radar_search`，主动检索技术趋势反哺 wiki
- 新增 `external_trend_capability_link`，将外部趋势链接至能力改进候选
- 新增 `ecosystem_positioning_scan`，生态定位扫描
- 新增 `relevance_threshold_calibration`，阈值自校准

### 知乎内容发布 Workflow
- 新增 `zhihu_content_publish` workflow，支持知乎搜索 + 回答发布全流程
- 新增 `zhihu_publish_answer` skill 支持

### 机制验证 Demo Workflow
- 新增 `mechanism_validation_demo` workflow，用于验证各执行机制

## ✨ 功能改进

### Daemon 执行模型与调度心跳解耦
- 将调度心跳（`scheduler_heartbeat`）从执行模型中解耦，提升系统稳定性
- 新增 `recovery_event_log`，记录任务恢复事件
- 新增「任务卡死回收 + 调度自愈可观测性」硬化机制
- 新增 `test_reap_stale_steps_observability` 等可观测性测试

### Goal 执行公平性调度
- 调度策略从「纯优先级排序」改为「公平轮询」，防止低优先级 Goal 饥饿
- 新增优先级老化机制（防饥饿兜底）
- 支持 Goal 粒度并发上限配置
- 执行时间片化，提升多 Goal 并发时的公平性
- 看板新增 Goal 执行公平性可视化

### 自诊断信号闭环深化
- 新增 `sys:suggestion_outcome_review`（建议采纳率回看）
- 新增 `sys:improvement_backlog_merge`（改进信号聚合器）
- 新增 `sys:self_model_snapshot`（能力自画像时间序列快照）
- 新增 skill 结果有效性审计（`wiki_utility_audit` 姊妹版）

### 系统关联性断点修复
- 新增 `failure_pattern_store`，持久化记录失败模式
- 新增 `suggestion_feedback_ledger`，建议反馈账本
- 新增 `correction_writer` 与 `decision_consumption`，修复知识写入与消费断点

### Goal 与 Cron 绑定
- 新增 `goal_cron_bridge`，支持将 Goal 绑定至 Cron 定时执行
- 新增周期性 Goal 可见性与干预能力

### Goal 标准生成机制
- 新增不同生成模式，支持更灵活的 Goal 规格构建

### 统一参数注册与解析机制
- 新增 `param_registry`，统一参数注册与解析入口
- 更新配置加载器，支持参数级联与校验

### browser-cdp Skill 重构
- 搜索器模块全面重构，新增结构化 `src/searchers/` 目录
- 新增优酷视频搜索器（`YoukuSearcher`）
- 修复 `smart_wait.py` 核心 Bug：CDP Network 事件替代 Performance API
- 新增反检测、验证码处理、无限滚动等参考文档
- 完善测试套件（unit/integration/e2e）

### finance-data-toolkit Skill 全面升级
- 新增异步抓取（`async_fetchers`）
- 新增异常处理与韧性机制（`exceptions.py`、`resilience.py`）
- 新增数据验证模块（`validation.py`）
- 新增社交数据抓取（股吧等）
- 新增 Yahoo Finance scraper
- 新增完整的测试套件（8 个测试文件）

### 看板功能增强
- 执行可观测性与管控能力增强（`ObjectiveIsolatedRunner` 共享线程池健康检查）
- 新增看板配置管理模块
- 标签页自动适配

- 新增 workflow 输出目录支持

### Workflow 机制改进
