## 🔥 新增功能

### stock_watch（A 股监控分析系统）重大升级

**股票筛选器与数据源重构**
- 新增 `iwencai_api.py`（~524 行），基于 CDP + 问财新 API 实现全自动数据抓取
- 新增 `refresh_iwencai_cookie.py` entrypoint，支持自动/交互双模式刷新 Cookie
- `data_sources.py` 重构：`fetch_iwencai_screener()` 优先级调整为 新 API → 旧 API → pywencai
- 修复 `DEFAULT_CDP_PORT` 9334 → 9222（与 browser_launch.py 保持一致）
- 修复 Referer 中文 query 的 UnicodeEncodeError（加 quote() 编码）
- `_parse_iwencai_response` 适配新 API 返回格式

**候选人池与信号系统**
- 新增 `candidate_pool.py`：候选人池状态化管理（候选池/关注池/黑名单）
- 新增 `signals.py`：统一信号接口，支持可组合信号链
- 新增 `indicators.py`：技术指标计算（连续三日放量上涨等）
- 新增 `news_signals.py` / `announcement_signals.py`：新闻和公告事件信号
- 新增 `source_health.py`：数据源健康度追踪与自动降级
- 新增 `outcomes.py`：结果追踪与反馈闭环
- 新增 `golden_cases.py`：黄金案例库，用于持续学习
- 新增 `run_signal_scan.py`、`run_pool_tracking.py` entrypoints
- 新增 `change_pool_state.py` entrypoint：手动操作池状态切换
- 新增 `secrets.local.yaml.example`：密钥配置示例文件

**持续优化迭代机制**
- 新增 `backlog.py`：待办事项管理
- 新增 `review.py`：外部项目代码审查机制
- 新增 `maintenance.py`：维护工具
- 支持任意外部项目的持续优化迭代，不限于 stock_watch
