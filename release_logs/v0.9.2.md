## 🎉 新功能

### Wiki 知识库系统（全新）

引入完整的 Wiki 式知识库架构，支持结构化知识沉淀、检索与专题管理。

- **阶段一：基础设施** — 新增 `wiki/` 模块，包含模板系统（decision/entity/experience/process/topic）、图结构、索引器、解析器、验证器、写入器
- **阶段二：迁移与双写** — 实现从旧存储到 Wiki 的平滑迁移，支持双写一致性
- **阶段三：检索切换** — 新增 `wiki/search.py`、`wiki/topics.py`，切换检索入口
- **阶段四：专题页与收尾** — 完善专题页功能
- **提取层改进** — 新增轻量级提取触发器、世界提取器、实体摘要、决策写入器
- **组织层改进** — 新增知识图谱扩展、话题 LLM 聚类、降级清理、缺口扫描、生命周期管理
- **CLI 命令** — 新增 `/wiki` 相关命令，支持知识库交互
- **文档** — 新增 `docs/wiki-knowledge-base-guide.md`

### Notepad 记事本机制（全新）

新增持久化便签系统，用于跨轮次记录关键信息、约束和待办事项。

- 新增 `tools/notepad.py` 工具模块
- 新增 `cli/commands/notepad.py` 命令行接口
- 支持开启/关闭开关配置
- 集成到 compaction 流程中

### Finance Data Toolkit（全新 Skill）

新增金融数据抓取与分析全链路工具箱。

- 数据抓取：东方财富、股吧、新浪财经等多源支持
- 数据清洗：对齐、去重、特征工程、缺失值处理、标准化
- 技术分析：指标计算
- 舆情分析：情感分析
- 新闻聚合：多源新闻抓取
- 研报生成：自动化报告生成
- 回测框架：策略回测
- 批量处理：批量数据获取

### Browser CDP Skill 增强

浏览器控制技能大幅扩展，支持多种搜索场景。

- 新增知乎搜索（普通/带登录/自动搜索）
- 新增 Arxiv 论文搜索（单篇/多篇）
- 新增 Bing 搜索

- 新增页面元素分析、详情清洗、浏览器控制台交互
- 重构为渐进式规范加载架构

### 运行时自动屏蔽（Auto Quarantine）

新增自动隔离机制，当检测到异常行为时自动暂停相关功能。

- 新增 `auto_quarantine.py`

## 🚀 重大改进

### Compact 机制主动化改进

完成 P0/P1/P2 全部三个阶段，实现更智能的上下文压缩。

- **P0：目标相关性动态权重** — 压缩时考虑 Goal 相关性，动态调整权重
- **P0：Compact 兼做沉淀检查点** — 压缩过程中提取决策和经验
- **P1-A：安全点判定** — 在安全节点触发压缩，避免破坏正在进行的工作
- **P1-B：触发信号强度叠加** — 累积触发信号，减少误触发
- **P2-A：压缩质量事后自检** — 新增 `compact_audit.py`，压缩后验证质量
- **P2-B：Raw history 按需找回** — 新增 `recall_history.py` 工具，可回溯被压缩内容
- **Token 预估** — 压缩前增加 Token 预测，支持轻量/深度两级压缩策略
- **Chunk Compact 修复** — 修复分块压缩不正确的问题
- **循环 Compact 修复** — 解决重复压缩的循环问题
- **Skill 自动卸载** — Compact 时自动卸载无用 Skill，节省上下文空间
- **话题转换检测优化** — 多次迭代优化，提升话题切换识别准确性
- **Compact 结果打印** — 压缩完成后显示详细结果

### Goal 模式全面增强

Goal 机制经历多轮重构，稳定性与功能性大幅提升。

- **探索/收敛双模式** — 根据任务状态自动切换探索与收敛策略
- **伪进展趋势识别** — 新增 `ProgressTracker`，识别无效循环
- **Dead-end 持久清单** — 从滚动窗口升级为持久化失败路径记录
- **自验证优先** — 强制执行 `verification_command` 获取客观证据
- **过程/结果判断分离** — 通过 `process_flags` 区分中间过程和最终结果
- **进展分数纳入 Checklist** — 进度评估结合 Checklist 通过数变化
- **分级 Compact 联动** — 与恢复次数挂钩，动态调整压缩深度
- **Goal 重规划提议** — 支持在卡顿时自动提议重新规划
- **/goal resume 优化** — 不带参数时默认继续当前 Session 的 Goal
- **GoalJudge 模型优化** — 调整判官使用的模型策略
- **退出逻辑优化** — 改进 Goal 完成和退出的判断

### 判官机制统一化

将 Turn Judge 和 Goal Judge 统一为 RoleAgent 架构。

- 新增 `role_agents/` 模块，包含 dispatcher、judge_factory、verdict 等
- 结构化判定输出：强制 JSON 格式 + json_repair 解析
- 统一判官配置文件和提示词
- 新增 Evaluator、Coach 等角色 Agent
- StuckDetector 抽取为独立组件

### 记忆与自我进化系统

- **记忆语义检索** — 支持混合 TF-IDF + 本地离线小型 Embedding 模型（默认关闭）
- **记忆巩固重构** — 从"淘汰"改为"归纳"，支持分组阈值配置
- **自主探索闭环** — 好奇心评分 + 探索结果回写记忆
- **Affordance/自我模型** — 闭环学习，风险门控校准
- **Outcome 负面判定** — 失败结果自动回写 Lesson
- **决策/取舍知识提炼** — 从压缩历史中提取决策依据
- **日常对话消费路径** — 新增两条知识消费通道
- **认知锚点改为 Session 相关** — 更准确的上下文关联
- **Phase_G 改名 Consolidation** — 术语统一

### Agent 架构重构

- **agent.py 拆分** — 拆分为 core、lifecycle、compaction、turn_loop、reflection、profile、snapshot、llm_control、reminders_correction、role_judge 等模块
- **Skill 渐进式加载** — 支持主文件 + 子资源按需加载
- **Skill 触发机制优化** — 更精准的自动激活

### 系统稳定性与可观测性

- **静默异常处理** — 全局统一添加日志信息，覆盖 60+ 文件
- **Log 机制更新** — 改进调试日志和系统日志
- **Retry 逻辑优化** — 改进模型调用重试策略
- **Rollback 逻辑修复** — 修复快照回滚问题
- **Token 计算优化** — 更准确的 Token 预估和显示
- **Context Window 配置修复** — 解决 `model_context_window=120000` 不生效问题
- **Format Correction Detector** — 与 Reminder 系统结合，新增多种格式问题检测
- **Bash 工具流式输出开关** — 支持实时查看长命令输出
