# Release Notes — v0.8.1

**发布日期**: 2026-07-04
**提交总数**: 105 commits
**时间跨度**: 2026-06-27 ~ 2026-07-04

---

## 📌 版本概述

v0.8.1 是一个功能丰富的版本，引入了多个重大新功能：

- **Goal 模式** — 全新的目标驱动交互模式，支持用户设定目标后让 Agent 自主规划执行
- **Mini Agent 看板** — 全新的 Web 看板应用，可视化监控 Agent 运行状态
- **微信 Bot 接入** — 完整的微信机器人插件体系，支持登录、消息收发、权限管理
- **Daemon 多用户架构** — 完整的 Phase 1~4 多用户支持，每个用户拥有独立的 SessionAgent
- **工具结果智能截断** — 原始输出留存 + LLM 智能摘要，大幅节省上下文空间
- **自主 Agent 能力** — Daemon 模式下的时间加权记忆、认知锚点、自维护模块等
- **Hooks 扩展** — 回合结束 Hook、自动回复等钩子机制
- **Ensemble（多结果合并取优）** — Best-of-N 策略，提升复杂任务质量

## 🆕 新增功能

### Goal 模式

全新 Goal 模式，允许用户设定目标后让 Agent 自主规划和执行任务。

- 新增 `goal_mode` 模块（`spec.py`, `state.py`, `runner.py`, `executor.py`）
- 新增 `goal_judge` 角色 Agent，负责目标判断与分解
- 新增 `goal_mode_cmd` CLI 命令
- 新增 `goal_test.txt` 测试用例
- 新增 `docs/goal-mode-guide.md` 使用指南
- 更新配置文件 `agent_config.json` 及配置加载器

### Mini Agent 看板

全新的 Web 看板应用，可视化展示 Agent 运行状态。

- 新增 `apps/mini_agent_kanban/` 应用（`app.py`, `client.py`, `README.md`）
- 看板功能持续迭代优化（多次更新）
- 看板显示优化

### 微信 Bot 接入

完整的微信机器人插件体系，支持登录、消息收发、权限管理等。

- 新增 `apps/weixin_plugin/` 插件目录
  - 微信登录认证（`login.py`, `auth.py`）
  - 微信 API 封装（`api.py`, `codec.py`, `types.py`）
  - Bot 框架（`bot.py`）
  - Mini Agent 集成客户端（`mini_agent_client.py`）
  - 权限轮询器（`permission_poller.py`）
  - 用户映射（`user_mapping.py`）
  - 多种示例 Bot（`echo_bot.py`, `claude_code_bot.py`, `login_demo.py` 等）
- 新增独立 `weixin_bot.py`
- 新增 `docs/weixin-bot-guide.md` 和 `docs/weixin-plugin-guide.md`
- 修复微信 Bot 第一条消息后才能回复的问题
- 新增 `apps/weixin_plugin/README.md` 文档

### Daemon 多用户架构（Phase 1~4）

完整的 Daemon 多用户支持，实现真正的多客户端并发。

- **Phase 1**: 用户识别（角色系统的最小可用版本）
  - 新增 `api/multi_auth.py`、`cli/commands/user_cmd.py`
  - 更新用户存储、路由、模型
- **Phase 2**: per-user 目录与画像
  - 新增 `tools/user_memory.py`
- **Phase 3**: SessionAgentPool（每个 session 一个独立 Agent）
  - 更新 session pool、路由、服务器
- **Phase 4**: Self ↔ SessionAgent 通信
  - 新增 `cli/commands/self_cmd.py`
- 新增 `test_cases/daemon-multiuser-testing-guide.md` 和 `daemon-multiuser-test-results.md`
- 新增 `docs/multi-user-guide.md` 多用户模式文档
- 优化多用户连接体验和多客户端表现
- 支持以指定用户身份连接已运行的 daemon
