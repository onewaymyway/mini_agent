## 🎬 小说转视频 v2

### 长篇支持 + 大场景分层 + 多角色配音

本次版本对小说转视频功能进行了**重大重构**，从单一场景生成升级为完整的长篇内容流水线：

- 新增 `novel-video-studio` skill，实现从小说文本到成片视频的端到端自动化流程
- 支持**长篇小说**自动拆分：全局实体抽取 → 大场景切分 → 单场景详细规划 → 素材与差异化配音生成 → 小场景视频合成 → 最终拼接转场
- 新增多角色配音能力：每个角色可独立配置声音风格（音色/语速/语调），旁白与对话自动区分
- 引入 `check_project_state.py` 总览脚本，快速定位断点，支持失败重试与回滚

### 拆分旧版 Skill 为独立子模块

将原 monolithic 的 `novel-video-studio` 拆分为多个独立 skill，便于维护和扩展：

| 新 Skill | 职责 |
|----------|------|
| `novel-entity-extractor` | 全局角色/地点/关系抽取（含声音设定） |
| `novel-macro-scene-planner` | 大场景边界识别与切分 |
| `novel-scene-detail-planner` | 单场景详细规划（旁白/对话拆分） |
| `novel-asset-generator` | 素材生成 + TTS 语音合成 |
| `novel-scene-video-generator` | 小场景视频片段生成 |
| `novel-video-composer` | 最终视频合成与转场处理 |

每个子 skill 均配备独立的 `SKILL.md`、`README.md` 和校验脚本（`check_*.py`），确保流程可单独测试。

### 旧版清理

- 删除旧版 `novel-asset-generator`、`novel-entity-extractor`、`novel-macro-scene-planner`、`novel-scene-detail-planner`、`novel-scene-planner`、`novel-scene-video-generator`、`novel-video-composer` 等多个旧版目录
- 同步清理 `next_doc/novel_video_generator_plan_v2.md` 旧版规划文档

## 🧠 Agent 核心能力升级

### 环境事实库 (record_env_fact / get_env_fact)

新增环境事实记录与查询机制，避免重复探索：

- 新增 `src/mini_agent/tools/env_facts.py`：环境事实存储与查询工具
- Agent 执行探索时发现的关键结论（如工具安装路径、特殊行为）自动记录
- 后续同类任务可快速查询已有结论，减少无效排查

### 用户输入自动捕获至记事本 (LLM 判断版)

- 新增 `src/mini_agent/history/user_requirement_capture.py`：LLM 判断用户输入是否值得记录到 notepad
- 修改 `api/server.py`、`cli/repl.py`、`config/loader.py`、`config/models.py` 适配新流程
- 只有被 LLM 判定为"有价值"的用户输入才会持久化，避免噪音积累

### 优化 Compact 机制

- 修复 compact 触发 `turnjudge` 的 bug：确保上下文压缩不会误触发 TurnJudge 检查
- 优化紧凑策略，在保留关键上下文的同时释放更多窗口空间

### 开启 Token Debug 功能

- 新增 token debug 模式，可在运行时查看每次 LLM 调用的 token 消耗明细
- 辅助排查用量异常和分析不同 agent 的调用成本

### Ctrl+C 问题修复

- 修复 bash 执行时 Ctrl+C 无法立即终止的问题
- 新增辅助测试脚本，验证中断行为
- Daemon 模式不再因无法中断而卡死

## ⚡ 自动驱动执行稳定性改进

### Daemon 卡死判定重构

- 重构 Daemon 卡死检测机制：调度心跳磁盘旁路 + 双信号判定矩阵
- 原有单信号判定存在误判风险，现采用心跳超时 + 状态变更停滞双重验证
- 新增告警升级：卡死后自动触发重试和通知

### Cron 异步用户反馈机制

- 新增 Cron 任务的异步用户反馈通道
- Cron 执行过程中如遇需要用户决策的情况，通过异步方式收集反馈，不再阻塞调度
- 新增 `evolution/cron_context.py`、`notification/questions_store.py`、`tools/ask_user_async.py`
