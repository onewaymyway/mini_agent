# mini_agent v0.9.1 更新说明

**发布日期**: 2026-07-11  
**基础版本**: v0.9.0  
**提交范围**: 2026-07-05 至 2026-07-11 (约 130+ commits)

---

## 🎯 版本亮点

v0.9.1 是一个**功能大版本**，重点在 **Daemon 模式多会话优化**、**知识索引与分类体系**、**用户行为感知系统**、**代理池系统**、**角色扮演系统**、**产出物看板**、**技能系统扩展** 等核心功能的完善与新增。共计 130+ 次提交，涉及 200+ 文件变更。

---

## 🚀 核心新功能

### 1. 🎯 Daemon 模式多会话深度优化 (20+ commits)
**核心改进**: 解决多会话并发下的显示、状态同步、权限请求、模型提示等问题

- **会话池管理重构** (`src/mini_agent/api/session_pool.py`): 新增会话池管理，支持多会话并发、会话生命周期管理、会话隔离
- **API 路由重构** (`src/mini_agent/api/routes.py`): 重构 `/api/sessions`、`/api/daemon/*` 等路由，支持多会话创建、切换、查询、删除
- **Bridge 通信层优化** (`src/mini_agent/api/bridge.py`): 修复 WebSocket 消息路由、会话消息广播、命令结果回显不完整问题
- **终端 UI 多会话适配** (`src/mini_agent/ui/terminal.py`): 状态栏显示当前会话、多会话切换提示、命令行提示符显示当前会话 ID
- **CLI 守护进程优化** (`src/mini_agent/cli/daemon.py`, `src/mini_agent/cli/app.py`): 修复 daemon 启动参数解析、模型选择提示缺失、权限请求显示异常
- **权限系统适配** (`src/mini_agent/permissions.py`): 多会话下的权限请求隔离与确认流程
- **模型选择提示修复** (`src/mini_agent/api/routes.py`): 修复 daemon 模式下客户端不显示模型选择提示的问题
