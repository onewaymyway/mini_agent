# 目标网站技术特征调研报告

## 调研概述
为优化 browser-cdp skill，拓展可抓取和浏览的网站范围，本次调研了3个目标领域的代表性网站：
1. **小红书** (social/content)
2. **携程** (travel/booking)
3. **大众点评** (local services)

---

## 1. 小红书 (Xiaohongshu)

### 技术特征
- **反爬机制**: 强（登录墙、滑块验证、设备指纹）
- **动态渲染**: React SPA，内容分页加载
- **登录要求**: 高（大部分内容需登录）
- **验证码**: 滑块验证

### 适配难度
| 维度 | 难度 |
|------|------|
| 反爬绕过 | ⭐⭐⭐⭐ |
| 动态渲染 | ⭐⭐⭐ |
| 登录处理 | ⭐⭐⭐⭐ |
| **综合** | **⭐⭐⭐⭐** |

### 建议优先级: ⭐⭐⭐ (中)
- 需处理登录态和验证码
- 内容价值高但反爬较强
- 建议优先适配移动端 API

---

## 2. 携程 (Ctrip)

### 技术特征
- **反爬机制**: 中等（sign 动态加密、设备指纹）
- **动态渲染**: React SPA
- **登录要求**: 搜索无需登录，预订需登录
- **验证码**: 极验滑块（已有支持）

### 适配难度
| 维度 | 难度 |
|------|------|
| 反爬绕过 | ⭐⭐⭐ |
| 动态渲染 | ⭐⭐ |
| 登录处理 | ⭐⭐ |
| **综合** | **⭐⭐⭐** |

### 建议优先级: ⭐⭐⭐⭐ (中高)
- sign 参数需动态生成
- 搜索接口无需登录，适合优先适配
- 已有滑块验证支持

---

## 3. 大众点评 (Dianping)

### 技术特征
- **反爬机制**: 极强（_token 动态加密、设备指纹、WASM 加密、动态字体加密）
- **动态渲染**: React SPA
- **登录要求**: 高（部分功能需登录）
- **验证码**: 滑块验证 + 额外风控

### 适配难度
| 维度 | 难度 |
|------|------|
| 反爬绕过 | ⭐⭐⭐⭐⭐ |
| 动态渲染 | ⭐⭐⭐ |
| 登录处理 | ⭐⭐⭐ |
| **综合** | **⭐⭐⭐⭐⭐** |

### 建议优先级: ⭐ (低)
- WASM 加密逆向难度极高
- 字体加密需额外处理
- 建议寻找替代数据源

---

## 适配优先级总结

| 排名 | 网站 | 优先级 | 理由 |
|------|------|--------|------|
| 1 | 携程 | ⭐⭐⭐⭐ | 搜索无需登录，sign 参数可逆向，已有滑块支持 |
| 2 | 小红书 | ⭐⭐⭐ | 内容价值高，但需处理登录和验证码 |
| 3 | 大众点评 | ⭐ | 反爬极强，WASM+字体加密，不建议直接适配 |

---

## 下一步行动

### 高优先级 (携程)
1. 分析携程搜索接口 sign 参数生成逻辑
2. 实现动态 sign 生成器
3. 测试搜索功能稳定性

### 中优先级 (小红书)
1. 研究登录流程自动化
2. 实现滑块验证处理
3. 测试内容抓取稳定性

### 低优先级 (大众点评)
1. 评估 WASM 逆向可行性
2. 考虑使用移动端 API 替代
3. 或寻找第三方数据源
