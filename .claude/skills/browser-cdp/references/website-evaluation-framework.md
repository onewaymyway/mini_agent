# 网站操作能力评估体系

**版本**: 1.0.0  
**创建日期**: 2026-08-05  
**状态**: 初版框架  
**适用范围**: browser-cdp skill 抓取与浏览能力评估

---

## 1. 评估目标

建立一套可量化、可复现的网站操作能力评估体系，用于：
- 衡量 browser-cdp skill 对各类网站的抓取成功率与稳定性
- 识别不同网站类型的反爬难度与应对策略
- 为新网站接入提供标准化的能力验证流程
- 持续追踪 skill 能力演进，形成能力基线

---

## 2. 评估维度与指标体系

### 2.1 核心维度总览

| 维度 | 权重 | 说明 |
|------|------|------|
| 抓取成功率 | 30% | 目标数据能否被正确提取 |
| 页面加载性能 | 20% | 页面加载与渲染耗时 |
| 元素定位准确率 | 20% | 交互元素能否被准确识别 |
| 反检测能力 | 15% | 绕过反爬机制的能力 |
| 稳定性 | 10% | 多次执行结果一致性 |
| 错误恢复能力 | 5% | 异常场景下的容错与恢复 |

### 2.2 详细指标定义

#### 维度一：抓取成功率（权重 30%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 页面访问成功率 | 成功加载目标页面的比例 | 成功访问次数 / 总尝试次数 × 100% | ≥ 90% |
| 数据提取准确率 | 提取数据与真实值一致的比例 | 正确提取条数 / 总提取条数 × 100% | ≥ 85% |
| 字段完整率 | 成功提取的字段数占预期字段数的比例 | 已提取字段数 / 预期字段数 × 100% | ≥ 80% |
| 综合抓取得分 | 加权综合评分 | 页面成功率×0.4 + 提取准确率×0.4 + 字段完整率×0.2 | 满分100 |

#### 维度二：页面加载性能（权重 20%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 首屏加载时间 | 从导航到首屏内容可见的时间 | CDP Performance 指标或手动计时 | ≤ 5s |
| 页面完全加载时间 | 从导航到页面完全渲染的时间 | 等待 networkidle 或稳定状态 | ≤ 15s |
| 元素等待时间 | 等待目标元素出现的时间 | 从页面加载到元素可交互的时间 | ≤ 3s |
| 平均响应时间 | 单次操作的平均耗时 | 总耗时 / 操作次数 | ≤ 10s |

#### 维度三：元素定位准确率（权重 20%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 元素定位成功率 | 成功定位目标元素的比例 | 成功定位次数 / 总定位尝试次数 × 100% | ≥ 90% |
| 交互成功率 | 成功执行点击/输入等交互的比例 | 成功交互次数 / 总交互尝试次数 × 100% | ≥ 85% |
| 动态元素识别率 | 动态加载元素的识别能力 | 识别动态元素数 / 总动态元素数 × 100% | ≥ 80% |
| 定位策略覆盖率 | 使用的定位策略种类 | 已验证策略数 / 总策略数 × 100% | ≥ 70% |

#### 维度四：反检测能力（权重 15%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 反爬绕过率 | 成功绕过反爬机制的比例 | 绕过成功次数 / 总反爬触发次数 × 100% | ≥ 70% |
| 验证码通过率 | 验证码识别与处理成功率 | 通过验证码次数 / 总验证码次数 × 100% | ≥ 60% |
| 指纹伪装有效性 | 浏览器指纹被识别为机器人的比例 | 1 - 被识别比例 | ≥ 80% |
| 行为模拟自然度 | 操作行为被判定为人类的比例 | 人工审核或自动化检测 | ≥ 75% |

#### 维度五：稳定性（权重 10%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 重复执行一致性 | 多次执行结果的一致性 | 结果一致次数 / 总执行次数 × 100% | ≥ 90% |
| 异常恢复率 | 异常后自动恢复的比例 | 成功恢复次数 / 总异常次数 × 100% | ≥ 80% |
| 内存稳定性 | 长时间运行的内存泄漏检测 | 内存增长速率 | ≤ 5MB/h |
| 连接稳定性 | CDP 连接保持率 | 连接保持时间 / 总运行时间 × 100% | ≥ 95% |

#### 维度六：错误恢复能力（权重 5%）

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 错误分类准确率 | 错误类型识别的准确性 | 正确分类数 / 总错误数 × 100% | ≥ 85% |
| 重试成功率 | 自动重试后的成功比例 | 重试成功次数 / 总重试次数 × 100% | ≥ 70% |
| 降级策略有效性 | 主策略失败后降级策略的成功率 | 降级成功次数 / 总降级尝试 × 100% | ≥ 60% |

## 3. 评估流程

### 3.1 评估准备阶段

```
1. 确定评估目标网站
2. 分析网站类型与特征（静态/动态/SPA/反爬强度）
3. 定义评估场景与测试用例
4. 准备评估环境与工具
5. 设定基线标准
```

### 3.2 评估执行阶段

```
1. 执行基础访问测试（页面加载、元素定位）
2. 执行数据抓取测试（提取目标数据）
3. 执行交互测试（点击、输入、滚动）
4. 执行反检测测试（触发反爬机制）
5. 执行稳定性测试（多次重复执行）
6. 收集日志与性能数据
```

### 3.3 评估分析阶段

```
1. 汇总各维度得分
2. 计算综合评分
3. 识别薄弱环节
4. 生成改进建议
5. 更新能力基线
```

## 5. 网站分类与评估策略

### 5.1 网站类型分类

| 类型 | 特征 | 评估重点 | 示例网站 |
|------|------|----------|----------|
| 静态页面 | 内容直接渲染在 HTML 中 | 元素定位、数据提取 | 新闻站点、博客 |
| 动态页面 | 通过 JS 动态加载内容 | 等待策略、动态元素识别 | 社交媒体、电商 |
| SPA 应用 | 单页应用，路由变化不刷新 | 路由处理、状态管理 | 现代 Web 应用 |
| 强反爬站点 | 有完善的反爬机制 | 反检测、验证码处理 | 招聘、房产平台 |
| 登录保护站点 | 需要登录才能访问 | 认证流程、会话管理 | 知乎、邮箱 |
| 实时数据站点 | 数据实时更新 | 轮询策略、数据一致性 | 股票、天气 |

### 5.2 评估难度分级

| 级别 | 难度 | 说明 | 评估策略 |
|------|------|------|----------|
| L1 - 简单 | 低 | 静态页面，无反爬 | 基础访问+提取测试 |
| L2 - 中等 | 中 | 动态加载，轻度反爬 | 完整六维度评估 |
| L3 - 困难 | 高 | 强反爬，需要绕过 | 重点反检测+稳定性评估 |
| L4 - 极难 | 极高 | 复杂验证，行为检测 | 专项深度评估 |

## 6. 评估报告模板

### 6.1 单次评估报告

```
## 网站操作能力评估报告

**评估网站**: xxx.com  
**评估日期**: 2026-08-05  
**评估版本**: browser-cdp v1.0.0  
**综合评分**: 82.5/100

### 各维度得分

| 维度 | 得分 | 权重 | 加权得分 |
|------|------|------|----------|
| 抓取成功率 | 85 | 30% | 25.5 |
| 页面加载性能 | 78 | 20% | 15.6 |
| 元素定位准确率 | 90 | 20% | 18.0 |
| 反检测能力 | 70 | 15% | 10.5 |
| 稳定性 | 88 | 10% | 8.8 |
| 错误恢复能力 | 75 | 5% | 3.75 |

### 关键发现

1. **优势**: 元素定位准确率高（90%），页面访问稳定
2. **不足**: 反检测能力较弱（70%），遇到验证码时成功率低
3. **建议**: 增强验证码处理模块，优化指纹伪装策略

### 改进建议

- [ ] 优化 stealth.py 反检测模块
- [ ] 增强 captcha_handler.py 验证码处理能力
- [ ] 添加更多代理池节点
```

## 7. 持续改进机制

### 7.1 评估周期

| 类型 | 频率 | 范围 | 负责人 |
|------|------|------|--------|
