---

## 一、沟通策略概述

由于 browser-cdp 是 AI Agent 工具，无法直接与网站运营方建立商业合作。本沟通记录主要记录**技术合作意向**和**数据获取策略**，为后续技术实现提供参考。

### 1.1 沟通目标

1. 了解目标网站的数据开放政策
2. 确认 API 访问权限和限制
3. 评估技术对接可行性
4. 记录合作意向和技术挑战

### 1.2 沟通方式

| 方式 | 适用场景 | 预期效果 |
|------|---------|---------|
| 官网商务合作页面 | 商业网站 | 申请 API 访问权限 |
| 开发者平台 | 技术导向网站 | 获取技术文档和 SDK |
| 开放数据平台 | 政府网站 | 申请数据接口权限 |
| 技术逆向分析 | 无开放 API 网站 | 模拟真实用户行为 |
