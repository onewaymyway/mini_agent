# Browser CDP 技能培训计划

## 培训目标
掌握 Browser CDP 技能的标准操作流程和测试用例库的使用方法，能够独立进行网页自动化操作和测试。

## 培训对象
- 需要使用浏览器自动化的开发人员
- 需要进行网页内容抓取的分析师
- 需要测试浏览器功能的 QA 工程师

## 培训时长
- 总时长：4 小时
- 理论讲解：1.5 小时
- 实操演练：2 小时
- 问答与总结：0.5 小时

## 培训内容

### 第一部分：Browser CDP 技能概述（0.5 小时）
1.1 什么是 Browser CDP
1.2 核心优势与使用场景
1.3 与传统自动化框架（Playwright/Selenium）的区别
1.4 技能目录结构说明

### 第二部分：标准操作流程（SOP）（1 小时）
2.1 环境准备
   - Python 环境检测
   - 依赖安装（websocket-client, requests, pillow）
   - 浏览器启动方式选择

2.2 浏览器连接管理
   - 专用实例模式（--dedicated）
   - 连接已有浏览器模式
   - Headless 模式

2.3 页面导航与控制
   - 打开网址、前进后退刷新
   - 等待元素出现

2.4 内容抓取
   - HTML/文本抓取
   - 表单和链接提取
   - Meta 信息获取

2.5 截图与标注
   - 整页截图
   - 元素级截图
   - 编号标注

2.6 用户交互
   - 模拟点击
   - 文字输入
   - 按键操作
   - 滚动和悬停

2.7 调试与监控
   - 执行任意 JS
   - 读取 console 日志
   - 抓取网络请求

### 第三部分：测试用例库（1.5 小时）
3.1 测试用例库结构
   - 单元测试
   - 集成测试
   - 端到端测试

3.2 核心模块测试
   - browser_launch.py 测试
   - browser_nav.py 测试
   - browser_extract.py 测试
   - browser_screenshot.py 测试
   - browser_input.py 测试
   - browser_console.py 测试

3.3 测试实践
   - 编写测试用例
   - 运行测试套件
   - 分析测试结果

### 第四部分：常见问题与故障排查（0.5 小时）
4.1 路径问题
4.2 登录态丢失
4.3 元素编号失效
4.4 SPA 路由处理
4.5 其他常见坑

## 考核标准
- 能够独立完成浏览器连接和页面导航
- 能够成功抓取网页内容
- 能够编写基本的测试用例
- 能够处理常见的故障和问题

## 后续跟进
- 提供完整的技能文档和参考资料
- 建立技术支持渠道
- 定期回顾和优化培训材料
