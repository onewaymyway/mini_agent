## 五、分类使用指南

### 5.1 搜索器命名规范

搜索器文件命名格式：`{domain}_{subdomain}_search.py`

| 领域代码 | 子领域代码 | 示例 |
|---------|-----------|------|
| ECOM | B2C | jd_search.py, taobao_search.py |
| NEWS | FINANCE | sina_news.py, thp_news.py |
| SOCIAL | FORUM | zhihu_search.py, douban_search.py |
| HEALTH | HOSPITAL | dxy_hospital_search.py |
| HEALTH | APPOINT | haodf_search.py |
| GOV | PORTAL | gov_cn_search.py |
| GOV | STATS | stats_search.py |

### 5.2 分类标签在代码中的使用

```python
# 搜索器分类标签示例
class BaiduSearch(BaseSearcher):
    """百度搜索器"""
    
    # 分类标签
    CATEGORY = "TOOL"
    SUBCATEGORY = "TOOL_SEARCH"
    
    # 反爬难度
    ANTI_DETECTION_LEVEL = 1  # ⭐
    
    # 优先级
    PRIORITY = "P0"
    
    # 支持功能
    FEATURES = ["search", "autocomplete", "related_search"]
```

### 5.3 分类查询接口

```python
# 按分类筛选搜索器
from src.searchers import get_searchers_by_category

# 获取所有电商类搜索器
ecom_searchers = get_searchers_by_category("ECOM")

# 获取所有弱反爬搜索器
weak_anti_searchers = get_searchers_by_anti_level(1)

# 获取所有P0优先级搜索器
p0_searchers = get_searchers_by_priority("P0")
```
