# 大众点评技术特征分析

## 基本信息
- **域名**: dianping.com
- **类型**: 本地生活服务平台（餐饮、酒店、休闲娱乐）
- **所属**: 美团集团
- **技术栈**: React SPA + 移动端优先

## 反爬机制（极强）

### 1. _token 动态加密
- 每个请求必须携带 `_token` 参数
- 通过综合判断 `document`、`window`、`screen`、`element` 对象特征值生成
- 融合自动化测试框架特征检测
- 请求风险判别依据，动态生成，无法静态模拟

### 2. 设备指纹
- 采集浏览器/设备多维度特征
- 检测自动化测试框架（Selenium/Playwright 特征）
- 检测 headless 模式
- 检测虚拟环境特征

### 3. WASM 加密
- 2026年新增风控机制
- 使用 WebAssembly 进行关键参数加密
- 逆向难度极高

### 4. 动态字体加密
- 价格、评分等数字使用自定义字体
- 字体文件动态加载，每次不同
- 需字体映射表或 OCR 识别

### 5. Cookie 验证
- 严格的 Cookie 校验机制
- 需要有效的会话 Cookie
- 首次访问需完成 Cookie 生成流程

### 6. IP 风控
- IP 段封禁机制
- 高频访问触发封禁
- 需代理池支持

## 动态渲染
- **前端框架**: React SPA
- **数据加载**: 大量 Ajax 动态加载
- **分页**: 虚拟列表 + 无限滚动
- **内容**: 评论、评分、图片等动态渲染

## 登录要求
- **搜索**: 无需登录
- **评论详情**: 部分需登录
- **店铺详情**: 部分需登录
- **高频访问**: 强制登录 + 滑块验证

## 接口特征
- **移动端 API**: 有独立移动端接口
- **API 逆向**: 可行但复杂度高
- **关键参数**: queryid、_token、设备指纹
- **响应格式**: JSON

## 适配难度评估
| 维度 | 难度 | 说明 |
|------|------|------|
| 反爬绕过 | ⭐⭐⭐⭐⭐ | _token + 设备指纹 + WASM + 字体加密 |
| 动态渲染 | ⭐⭐⭐ | React SPA，需等待动态加载 |
| 登录处理 | ⭐⭐⭐ | 部分功能需登录，有滑块验证 |
| 接口逆向 | ⭐⭐⭐⭐ | 移动端 API 可行但复杂 |
| **综合难度** | **⭐⭐⭐⭐⭐** | **极高，不建议直接适配** |

## 建议
1. **优先适配移动端 API**（如果可行）
2. **使用 Playwright + 真实浏览器** 模拟用户行为
3. **需要代理池 + Cookie 池** 支持
4. **字体加密需额外处理**（字体映射或 OCR）
5. **WASM 加密逆向难度极高**，建议寻找替代数据源

## 替代方案
- 使用美团开放平台 API（如有）
- 使用第三方数据服务
- 手动采集 + 定期更新
