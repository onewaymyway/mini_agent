## 2. 抓取成功率评估标准（权重 30%）

### 2.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 页面访问成功率 | 成功加载目标页面的比例 | 成功访问次数 / 总尝试次数 × 100% | ≥ 90% | 40% |
| 数据提取准确率 | 提取数据与真实值一致的比例 | 正确提取条数 / 总提取条数 × 100% | ≥ 85% | 40% |
| 字段完整率 | 成功提取的字段数占预期字段数的比例 | 已提取字段数 / 预期字段数 × 100% | ≥ 80% | 20% |
| 综合抓取得分 | 加权综合评分 | 页面成功率×0.4 + 提取准确率×0.4 + 字段完整率×0.2 | 满分100 | 100% |

### 2.2 计算方法

```
页面访问成功率 = (成功访问次数 / 总尝试次数) × 100%

数据提取准确率 = (正确提取条数 / 总提取条数) × 100%

字段完整率 = (已提取字段数 / 预期字段数) × 100%

综合抓取得分 = 页面成功率×0.4 + 提取准确率×0.4 + 字段完整率×0.2
```

### 2.3 评分细则

| 综合得分 | 等级 | 说明 |
|----------|------|------|
| 90-100 | 优秀 | 抓取能力成熟，可稳定生产使用 |
| 75-89 | 良好 | 基本可用，个别场景需优化 |
| 60-74 | 合格 | 核心功能可用，需持续改进 |
| 40-59 | 待改进 | 存在明显短板，需重点优化 |
| < 40 | 不可用 | 当前能力无法支持该网站 |

### 2.4 测试用例

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 首页访问 | 导航到目标网站首页 | 成功加载，返回HTTP 200 |
| 搜索查询 | 输入关键词并提交搜索 | 成功返回搜索结果页 |
| 列表页抓取 | 提取列表页前10条数据 | 成功提取≥8条，字段完整率≥80% |
| 详情页抓取 | 进入详情页提取核心字段 | 成功提取标题、正文、发布时间等 |
| 分页浏览 | 翻页到第2页 | 成功加载下一页内容 |

## 3. 页面加载性能评估标准（权重 20%）

### 3.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 首屏加载时间 | 从导航到首屏内容可见的时间 | CDP Performance 指标或手动计时 | ≤ 5s | 30% |
| 页面完全加载时间 | 从导航到页面完全渲染的时间 | 等待 networkidle 或稳定状态 | ≤ 15s | 30% |
| 元素等待时间 | 等待目标元素出现的时间 | 从页面加载到元素可交互的时间 | ≤ 3s | 20% |
| 平均响应时间 | 单次操作的平均耗时 | 总耗时 / 操作次数 | ≤ 10s | 20% |

### 3.2 计算方法

```
首屏加载时间 = 首屏内容可见时间戳 - 导航开始时间戳

页面完全加载时间 = 页面稳定时间戳 - 导航开始时间戳

元素等待时间 = 元素可交互时间戳 - 页面加载完成时间戳

平均响应时间 = 总操作耗时 / 操作次数
```

### 3.3 评分细则

| 指标 | 优秀 | 良好 | 合格 | 待改进 |
|------|------|------|------|--------|
| 首屏加载时间 | ≤ 2s | ≤ 3s | ≤ 5s | > 5s |
| 页面完全加载时间 | ≤ 8s | ≤ 10s | ≤ 15s | > 15s |
| 元素等待时间 | ≤ 1s | ≤ 2s | ≤ 3s | > 3s |
| 平均响应时间 | ≤ 5s | ≤ 7s | ≤ 10s | > 10s |

## 4. 元素定位准确率评估标准（权重 20%）

### 4.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 元素定位成功率 | 成功定位目标元素的比例 | 成功定位次数 / 总定位尝试次数 × 100% | ≥ 90% | 40% |
| 交互成功率 | 成功执行点击/输入等交互的比例 | 成功交互次数 / 总交互尝试次数 × 100% | ≥ 85% | 30% |
| 动态元素识别率 | 动态加载元素的识别能力 | 识别动态元素数 / 总动态元素数 × 100% | ≥ 80% | 20% |
| 定位策略覆盖率 | 使用的定位策略种类 | 已验证策略数 / 总策略数 × 100% | ≥ 70% | 10% |

### 4.2 计算方法

```
元素定位成功率 = (成功定位次数 / 总定位尝试次数) × 100%

交互成功率 = (成功交互次数 / 总交互尝试次数) × 100%

动态元素识别率 = (识别动态元素数 / 总动态元素数) × 100%

定位策略覆盖率 = (已验证策略数 / 总策略数) × 100%
```

### 4.3 定位策略清单

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| CSS选择器 | 使用 class、id、tag 等选择器 | 静态页面、简单结构 |
| XPath | 使用路径表达式定位 | 复杂嵌套结构 |
| 文本匹配 | 根据元素文本内容定位 | 按钮、链接等 |
| 属性匹配 | 根据 data-* 等属性定位 | 动态生成的元素 |
| 相对定位 | 基于相邻元素定位 | 列表项、卡片等 |
| 滚动定位 | 滚动到元素可见后定位 | 懒加载内容 |

## 5. 反检测能力评估标准（权重 15%）

### 5.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 反爬绕过率 | 成功绕过反爬机制的比例 | 绕过成功次数 / 总反爬触发次数 × 100% | ≥ 70% | 40% |
| 验证码通过率 | 验证码识别与处理成功率 | 通过验证码次数 / 总验证码次数 × 100% | ≥ 60% | 30% |
| 指纹伪装有效性 | 浏览器指纹被识别为机器人的比例 | 1 - 被识别比例 | ≥ 80% | 20% |
| 行为模拟自然度 | 操作行为被判定为人类的比例 | 人工审核或自动化检测 | ≥ 75% | 10% |

### 5.2 计算方法

```
反爬绕过率 = (绕过成功次数 / 总反爬触发次数) × 100%

验证码通过率 = (通过验证码次数 / 总验证码次数) × 100%

指纹伪装有效性 = (1 - 被识别为机器人次数 / 总检测次数) × 100%

行为模拟自然度 = 人工判定为人类的操作次数 / 总操作次数 × 100%
```

### 5.3 反爬机制类型

| 类型 | 说明 | 应对策略 |
|------|------|----------|
| User-Agent 检测 | 检测浏览器标识 | 随机化 UA |
| 请求频率限制 | 限制单位时间请求数 | 限速器、随机延迟 |
| IP 封禁 | 封禁异常 IP | 代理池轮换 |
| Cookie 验证 | 要求有效 Cookie | 会话管理 |
| JavaScript 挑战 | 执行 JS 验证 | CDP 执行 JS |
| 行为分析 | 分析鼠标轨迹、点击模式 | 模拟人类行为 |
| 验证码 | 人机验证 | 验证码处理模块 |

## 6. 稳定性评估标准（权重 10%）

### 6.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 重复执行一致性 | 多次执行结果的一致性 | 结果一致次数 / 总执行次数 × 100% | ≥ 90% | 40% |
| 异常恢复率 | 异常后自动恢复的比例 | 成功恢复次数 / 总异常次数 × 100% | ≥ 80% | 30% |
| 内存稳定性 | 长时间运行的内存泄漏检测 | 内存增长速率 | ≤ 5MB/h | 20% |
| 连接稳定性 | CDP 连接保持率 | 连接保持时间 / 总运行时间 × 100% | ≥ 95% | 10% |

### 6.2 计算方法

```
重复执行一致性 = (结果一致次数 / 总执行次数) × 100%

异常恢复率 = (成功恢复次数 / 总异常次数) × 100%

内存稳定性 = (结束内存 - 开始内存) / 运行时长

连接稳定性 = (连接保持时间 / 总运行时间) × 100%
```

### 6.3 稳定性测试方案

| 测试项 | 执行次数 | 观察指标 |
|--------|----------|----------|
| 重复搜索 | 10次 | 结果一致性 |
| 长时间运行 | 30分钟 | 内存增长、连接保持 |
| 异常注入 | 5次 | 恢复成功率 |
| 并发测试 | 3个实例 | 资源竞争、崩溃率 |

## 7. 错误恢复能力评估标准（权重 5%）

### 7.1 指标定义

| 指标 | 定义 | 计算方法 | 目标值 | 权重 |
|------|------|----------|--------|------|
| 错误分类准确率 | 错误类型识别的准确性 | 正确分类数 / 总错误数 × 100% | ≥ 85% | 40% |
| 重试成功率 | 自动重试后的成功比例 | 重试成功次数 / 总重试次数 × 100% | ≥ 70% | 30% |
| 降级策略有效性 | 主策略失败后降级策略的成功率 | 降级成功次数 / 总降级尝试 × 100% | ≥ 60% | 30% |

### 7.2 计算方法

```
错误分类准确率 = (正确分类数 / 总错误数) × 100%

重试成功率 = (重试成功次数 / 总重试次数) × 100%

降级策略有效性 = (降级成功次数 / 总降级尝试) × 100%
```

### 7.3 错误类型分类

| 错误类型 | 说明 | 处理策略 |
|----------|------|----------|
| 网络错误 | 连接超时、DNS 解析失败 | 重试、切换代理 |
| 页面错误 | 404、500、跳转登录 | 重试、等待加载 |
| 元素错误 | 元素未找到、不可交互 | 等待、滚动、重试 |
| 反爬错误 | 验证码、IP 封禁 | 验证码处理、切换代理 |
| 数据错误 | 提取结果为空、格式错误 | 重试、降级策略 |

## 8. 综合评分计算

### 8.1 计算公式

```
综合评分 = 抓取成功率×0.30 + 页面性能×0.20 + 元素定位×0.20 + 反检测×0.15 + 稳定性×0.10 + 错误恢复×0.05
```

### 8.2 评分等级

| 等级 | 分数范围 | 说明 |
|------|----------|------|

| P0 | ≥ 75 | ≥ 80% |
| P1 | ≥ 65 | ≥ 70% |
| P2 | ≥ 55 | ≥ 60% |
| P3 | ≥ 50 | ≥ 50% |

## 9. 评估执行规范

### 9.1 测试环境

- **浏览器**: Chrome 120+ 或 Edge 120+
- **CDP 端口**: 随机分配，避免冲突
- **网络**: 使用代理池，避免 IP 封禁
- **执行顺序**: 串行执行，避免触发反爬

### 9.2 测试数据

- **搜索关键词**: 每个网站测试 3-5 个关键词
- **数据规模**: 单次评估不超过 100 条数据
- **执行时长**: 单次评估不超过 5 分钟
- **重试次数**: 每个操作最多重试 3 次

### 9.3 数据收集

| 数据类型 | 收集方式 | 存储位置 |
|----------|----------|----------|
| 执行日志 | CDP 日志 | logs/eval_*.jsonl |
| 性能数据 | CDP Performance | logs/perf_*.json |
| 截图 | 关键步骤截图 | output/screenshots/ |
| 评估结果 | JSON 格式 | output/eval_*.json |
| 报告 | Markdown 格式 | output/reports/ |
