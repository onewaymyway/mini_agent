# Browser-CDP 网站兼容性测试框架需求文档

**版本**: 2.0.0  
**创建日期**: 2026-08-07  
**状态**: 评审版  
**目标**: 建立覆盖电商、新闻、社交、政务四类主流网站的兼容性测试框架

---

## 1. 四类网站技术栈差异分析

### 1.1 技术栈对比矩阵

| 维度 | 电商平台 | 新闻资讯 | 社交内容 | 政务服务 |
|------|---------|---------|---------|---------|
| **前端框架** | React/Vue SPA | 混合渲染 | React/Vue SPA | 传统服务端渲染 |
| **数据加载** | AJAX + WebSocket | 懒加载 + 分页 | 无限滚动 + 实时推送 | 表单提交 + 分页 |
| **反爬机制** | ⭐⭐⭐⭐ 极强 | ⭐⭐ 中等 | ⭐⭐⭐ 较强 | ⭐ 弱 |
| **登录要求** | 可选 | 无需 | 常见 | 无需 |
| **动态内容** | 高 | 中 | 极高 | 低 |
| **验证码频率** | 高频 | 低频 | 中频 | 极低 |
| **IP 限制** | 严格 | 宽松 | 中等 | 无 |
| **请求频率限制** | 严格 | 宽松 | 中等 | 无 |

### 1.2 核心差异说明

#### 电商平台 (ECOM)
- **技术特征**: SPA 应用，大量 AJAX 请求，WebSocket 实时数据
- **反爬重点**: 设备指纹、行为分析、滑块验证码、IP 封禁
- **测试难点**: 登录态维持、购物车操作、价格动态变化
- **代表站点**: 淘宝、京东、拼多多

#### 新闻资讯 (NEWS)
- **技术特征**: 动态页面，懒加载图片，分页或无限滚动
- **反爬重点**: 请求频率限制、User-Agent 检测
- **测试难点**: 分页处理、图片懒加载、广告过滤
- **代表站点**: 新浪新闻、网易新闻、财联社

#### 社交内容 (SOCIAL)
- **技术特征**: SPA 应用，无限滚动，实时推送，富文本编辑
- **反爬重点**: 登录态检测、行为分析、内容加密
- **测试难点**: 登录流程、评论提取、关注关系
- **代表站点**: 知乎、微博、小红书

#### 政务服务 (GOV)
- **技术特征**: 传统服务端渲染，表单提交，PDF 下载
- **反爬重点**: 几乎无，部分站点有验证码
- **测试难点**: 表单填写、文件下载、多步骤流程
- **代表站点**: 国家政务服务平台、中国政府网、中国裁判文书网
