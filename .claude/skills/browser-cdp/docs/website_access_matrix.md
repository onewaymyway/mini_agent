## 搜索功能测试

### Bing 搜索
- **状态**：✅ 正常
- **方法**：`page.fill('#sb_form_q', 'query')` + `page.press('#sb_form_q', 'Enter')`
- **验证**：URL 包含 `/search*`，标题包含关键词

### 百度搜索
- **状态**：⚠️ 间歇性可用
- **方法**：需使用 JS 注入 `page.evaluate('document.getElementById("kw").value = "query"')`
- **问题**：频繁搜索会触发安全验证（验证码）
- **建议**：控制搜索频率，或优先使用 Bing

## 技术要点

### 1. 超时设置
- 国内网站：15000ms 足够
- 境外网站：可能需要更长超时或跳过测试

### 2. 搜索框填充
- 动态加载页面：优先使用 `page.evaluate()` 注入值
- 静态页面：可使用 `page.fill()`

### 3. 安全验证
- 百度：频繁搜索触发验证码
- 淘宝：可能需要登录
- 支付宝：需要登录

### 4. 用户代理
建议设置自定义 UA 避免被识别为机器人：
```python
context = browser.new_context(
    user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
)
```
