## 5. 报告存储规范

### 5.1 存储路径

| 报告类型 | 存储路径 |
|----------|----------|
| 单次评估报告 | output/eval_reports/eval_YYYYMMDD_HHMMSS.md |
| 对比评估报告 | output/eval_reports/comparison_YYYYMMDD.md |
| 增量评估报告 | output/eval_reports/incremental_YYYYMMDD_HHMMSS.md |
| 专项评估报告 | output/eval_reports/special_YYYYMMDD_HHMMSS.md |
| 评估结果 JSON | output/eval_results/eval_YYYYMMDD_HHMMSS.json |

### 5.2 命名规范

```
评估报告命名格式：
- 单次评估：eval_{网站域名}_{YYYYMMDD}_{HHMMSS}.md
- 对比评估：comparison_{YYYYMMDD}.md
- 增量评估：incremental_{网站域名}_{YYYYMMDD}_{HHMMSS}.md
- 专项评估：special_{主题}_{YYYYMMDD}_{HHMMSS}.md
```

### 5.3 归档规则

| 报告类型 | 保留期限 | 归档方式 |
|----------|----------|----------|
| 单次评估报告 | 1年 | 按月归档至 output/eval_reports/archive/YYYY-MM/ |
| 对比评估报告 | 2年 | 按季度归档至 output/eval_reports/archive/YYYY-QN/ |
| 增量评估报告 | 1年 | 按月归档 |
| 专项评估报告 | 2年 | 按主题归档 |
