**版本**: 1.0.0  
**创建日期**: 2026-08-07  
**状态**: 正式版  
**适用范围**: browser-cdp skill 抓取与浏览能力评估  
**关联文档**: [evaluation-dimensions.md](./evaluation-dimensions.md)、[evaluation-standards-v2.md](./evaluation-standards-v2.md)

## 1. 评分标准总览

### 1.1 维度权重分配

| 维度 | 权重 | 核心指标数 | 评分范围 | 说明 |
|------|------|-----------|----------|------|
| 可用性 | 25% | 4 | 0-100 | 页面访问成功率、加载性能、超时处理 |
| 性能 | 20% | 4 | 0-100 | 响应时间、并发能力、资源消耗 |
| 安全性 | 15% | 4 | 0-100 | 反爬绕过率、验证码通过率、指纹伪装 |
| 兼容性 | 15% | 4 | 0-100 | 浏览器兼容、设备兼容、网络兼容 |
| 稳定性 | 15% | 4 | 0-100 | 重复一致性、异常恢复、连接稳定性 |
| 数据质量 | 10% | 4 | 0-100 | 提取准确率、字段完整率、数据质量 |

### 1.2 综合评分公式

```python
综合评分 = (
    可用性得分 × 0.25 +
    性能得分 × 0.20 +
    安全性得分 × 0.15 +
    兼容性得分 × 0.15 +
    稳定性得分 × 0.15 +
    数据质量得分 × 0.10
)
```

## 2. 可用性评分标准（权重 25%）

### 2.1 指标权重分配

| 指标 | 权重 | 目标值 | 优秀阈值 | 良好阈值 | 合格阈值 |
|------|------|--------|----------|----------|----------|
| 页面访问成功率 | 40% | ≥ 95% | ≥ 98% | ≥ 95% | ≥ 90% |
| 首屏加载时间 | 25% | ≤ 3s | ≤ 1.5s | ≤ 3s | ≤ 5s |
| 页面完全加载时间 | 20% | ≤ 10s | ≤ 5s | ≤ 10s | ≤ 15s |
| 超时处理成功率 | 15% | ≥ 90% | ≥ 95% | ≥ 90% | ≥ 80% |

### 2.2 评分细则

#### 2.2.1 页面访问成功率评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| 95-100% | 100 | 优秀，几乎无访问失败 |
| 90-94% | 85 | 良好，偶发失败 |
| 85-89% | 70 | 合格，有一定失败率 |
| 80-84% | 55 | 待改进，失败率较高 |
| < 80% | 40 | 不可用，访问不稳定 |

**计算公式**:
```python
page_access_score = min(100, max(0, (page_access_rate - 80) / 15 * 100))
```

#### 2.2.2 首屏加载时间评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≤ 1.5s | 100 | 优秀，加载极快 |
| 1.5-3s | 85 | 良好，加载较快 |
| 3-5s | 70 | 合格，加载正常 |
| 5-8s | 55 | 待改进，加载较慢 |
| > 8s | 40 | 不可用，加载过慢 |

**计算公式**:
```python
fcp_score = max(0, min(100, 100 - (fcp_time - 1.5) / 6.5 * 60))
```

#### 2.2.3 页面完全加载时间评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≤ 5s | 100 | 优秀，页面渲染快 |
| 5-10s | 85 | 良好，页面渲染较快 |
| 10-15s | 70 | 合格，页面渲染正常 |
| 15-20s | 55 | 待改进，页面渲染较慢 |
| > 20s | 40 | 不可用，页面渲染过慢 |

**计算公式**:
```python
plt_score = max(0, min(100, 100 - (page_load_time - 5) / 15 * 60))
```

#### 2.2.4 超时处理成功率评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≥ 95% | 100 | 优秀，超时处理完善 |
| 90-94% | 85 | 良好，超时处理较好 |
| 85-89% | 70 | 合格，超时处理一般 |
| 80-84% | 55 | 待改进，超时处理较差 |
| < 80% | 40 | 不可用，超时处理差 |

**计算公式**:
```python
timeout_score = min(100, max(0, (timeout_handling_rate - 80) / 15 * 100))
```

### 2.3 可用性综合得分

```python
availability_score = (
    page_access_score × 0.40 +
    fcp_score × 0.25 +
    plt_score × 0.20 +
    timeout_score × 0.15
)
```

## 3. 性能评分标准（权重 20%）

### 3.1 指标权重分配

| 指标 | 权重 | 目标值 | 优秀阈值 | 良好阈值 | 合格阈值 |
|------|------|--------|----------|----------|----------|
| 平均响应时间 | 30% | ≤ 2s | ≤ 1s | ≤ 2s | ≤ 3s |
| P95 响应时间 | 25% | ≤ 5s | ≤ 3s | ≤ 5s | ≤ 8s |
| 并发处理能力 | 25% | ≥ 80% | ≥ 90% | ≥ 80% | ≥ 70% |
| 资源利用率 | 20% | ≤ 70% | ≤ 50% | ≤ 70% | ≤ 85% |

### 3.2 评分细则

#### 3.2.1 平均响应时间评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≤ 1s | 100 | 优秀，响应极快 |
| 1-2s | 85 | 良好，响应较快 |
| 2-3s | 70 | 合格，响应正常 |
| 3-5s | 55 | 待改进，响应较慢 |
| > 5s | 40 | 不可用，响应过慢 |

**计算公式**:
```python
art_score = max(0, min(100, 100 - (avg_response_time - 1) / 4 * 60))
```

#### 3.2.2 P95 响应时间评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≤ 3s | 100 | 优秀，长尾响应快 |
| 3-5s | 85 | 良好，长尾响应较快 |
| 5-8s | 70 | 合格，长尾响应正常 |
| 8-12s | 55 | 待改进，长尾响应较慢 |
| > 12s | 40 | 不可用，长尾响应过慢 |

**计算公式**:
```python
p95_score = max(0, min(100, 100 - (p95_response_time - 3) / 9 * 60))
```

#### 3.2.3 并发处理能力评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≥ 90% | 100 | 优秀，并发能力强 |
| 80-89% | 85 | 良好，并发能力较好 |
| 70-79% | 70 | 合格，并发能力一般 |
| 60-69% | 55 | 待改进，并发能力较差 |
| < 60% | 40 | 不可用，并发能力差 |

**计算公式**:
```python
concurrent_score = min(100, max(0, (concurrent_capacity - 60) / 30 * 100))
```

#### 3.2.4 资源利用率评分

| 得分区间 | 评分 | 说明 |
|----------|------|------|
| ≤ 50% | 100 | 优秀，资源利用高效 |
| 50-70% | 85 | 良好，资源利用较好 |
| 70-85% | 70 | 合格，资源利用一般 |
| 85-95% | 55 | 待改进，资源利用较差 |
| > 95% | 40 | 不可用，资源利用差 |

**计算公式**:
```python
resource_score = max(0, min(100, 100 - (resource_utilization - 50) / 45 * 60))
```

### 3.3 性能综合得分

```python
performance_score = (
    art_score × 0.30 +
    p95_score × 0.25 +
    concurrent_score × 0.25 +
    resource_score × 0.20
)
```
