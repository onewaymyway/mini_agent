## 1. 最佳实践概述

### 1.1 实践目标

建立一套系统化、可复用的网站操作最佳实践体系，用于：
- 提高网站抓取成功率与数据质量
- 降低反检测风险与封禁概率
- 优化执行效率与资源消耗
- 沉淀经验知识，支持持续迭代

### 1.2 实践分类

| 实践类别 | 说明 | 适用场景 |
|----------|------|----------|
| 页面加载优化 | 提升页面访问成功率与加载速度 | 所有网站 |
| 元素定位优化 | 提高元素定位准确率与交互成功率 | 所有网站 |
| 数据提取优化 | 提升数据提取准确率与字段完整率 | 数据抓取场景 |
| 反检测优化 | 降低被识别为机器人的风险 | 高防护网站 |
| 稳定性优化 | 提升执行一致性与异常恢复能力 | 长时间运行场景 |
| 性能优化 | 降低资源消耗与执行时长 | 大规模抓取场景 |

## 2. 页面加载优化实践

### 2.1 智能等待策略

| 策略 | 说明 | 适用场景 | 配置建议 |
|------|------|----------|----------|
| networkidle | 等待网络请求空闲 | 动态加载页面 | timeout=10s |
| stable | 等待页面稳定 | SPA 应用 | timeout=15s |
| element-visible | 等待元素可见 | 懒加载内容 | timeout=30s |
| custom-wait | 自定义等待逻辑 | 特殊场景 | 按需配置 |

**最佳实践**:
- 优先使用 `networkidle` 等待策略，避免固定超时
- 对 SPA 应用启用路由监听，等待页面切换完成
- 对懒加载内容使用 `element-visible` 等待策略
- 配置合理的超时时间，避免过长等待或过早超时

### 2.2 超时处理策略

| 场景 | 策略 | 说明 |
|------|------|------|
| 页面加载超时 | 降级重试 | 降低超时阈值，重试 1-2 次 |
| 元素定位超时 | 备用策略 | 切换至 XPath 或 JS 定位 |
| 网络请求超时 | 代理轮换 | 切换代理节点重试 |
| 连接超时 | 重连机制 | 重新建立 CDP 连接 |

**最佳实践**:
- 配置分级超时策略，区分页面加载、元素定位、数据提取等不同场景
- 对超时场景启用自动重试，最多重试 3 次
- 记录超时原因，用于后续优化分析

### 2.3 性能监控

| 监控指标 | 监控方式 | 告警阈值 |
|----------|----------|----------|
| 首屏加载时间 | CDP Performance | > 5s |
| 页面完全加载时间 | CDP Performance | > 15s |
| 网络请求数 | CDP Network | > 100 |
| 内存使用量 | 系统监控 | > 500MB |

## 3. 元素定位优化实践

### 3.1 定位策略选择

| 策略 | 优先级 | 适用场景 | 性能 |
|------|--------|----------|------|
| CSS 选择器 | 1 | 静态页面、简单结构 | 最优 |
| XPath | 2 | 复杂嵌套结构 | 良好 |
| 文本匹配 | 3 | 按钮、链接等 | 良好 |
| 属性匹配 | 4 | 动态生成元素 | 一般 |
| 相对定位 | 5 | 列表项、卡片等 | 一般 |
| 滚动定位 | 6 | 懒加载内容 | 一般 |
| JS 执行 | 7 | 特殊场景 | 较差 |

**最佳实践**:
- 优先使用 CSS 选择器，性能最优且可读性强
- 复杂结构使用 XPath 辅助定位
- 动态元素优先使用属性匹配或相对定位
- 对特殊场景使用 JS 执行作为最后手段

### 3.2 动态元素处理

| 场景 | 策略 | 说明 |
|------|------|------|
| 懒加载内容 | 滚动等待 | 滚动到元素可见后等待渲染完成 |
| AJAX 加载 | 轮询检测 | 定期检查元素是否出现 |
| SPA 路由变化 | 路由监听 | 监听路由变化，等待页面切换完成 |
| 动态 ID | 属性匹配 | 使用 data-* 等稳定属性定位 |

**最佳实践**:
- 对懒加载内容启用智能滚动等待策略
- 对 AJAX 加载内容使用轮询检测，设置合理间隔
- 对 SPA 应用启用路由监听，等待页面切换完成
- 避免使用动态 ID 定位元素，优先使用稳定属性

### 3.3 定位失败处理

| 失败原因 | 处理策略 | 说明 |
|----------|----------|------|
| 元素不存在 | 备用定位策略 | 切换至 XPath 或 JS 定位 |
| 元素不可见 | 滚动等待 | 滚动到元素可见后重试 |
| 元素被遮挡 | 强制点击 | 使用 JS 执行点击操作 |
| 元素动态变化 | 重新定位 | 刷新页面后重新定位 |

## 4. 数据提取优化实践

### 4.1 提取策略选择

| 策略 | 优先级 | 适用场景 | 准确率 |
|------|--------|----------|--------|
| 结构化数据 | 1 | JSON-LD、Microdata | 最高 |
| DOM 解析 | 2 | 静态页面 | 高 |
| 正则匹配 | 3 | 文本内容 | 中 |
| AI 识别 | 4 | 复杂布局 | 中 |

**最佳实践**:
- 优先提取结构化数据（JSON-LD、Microdata），准确率最高
- 对静态页面使用 DOM 解析，性能最优
- 对文本内容使用正则匹配，灵活性强
- 对复杂布局使用 AI 识别，适应性强

### 4.2 字段映射规范

| 字段类型 | 映射方式 | 说明 |
|----------|----------|------|
| 标题 | CSS 选择器 | 优先使用 h1、title 标签 |
| 正文 | DOM 解析 | 提取主要文章内容区域 |
| 发布时间 | 正则匹配 | 匹配时间格式 |
| 作者 | CSS 选择器 | 提取 author 属性 |
| 链接 | DOM 解析 | 提取 href 属性 |
| 图片 | DOM 解析 | 提取 src 属性 |

**最佳实践**:
- 建立统一的字段映射规范，提高提取一致性
- 对动态字段使用正则匹配，适应格式变化
- 对重要字段进行多重验证，提高准确率

### 4.3 数据质量验证

| 验证项 | 验证方式 | 通过标准 |
|--------|----------|----------|
| 字段完整性 | 检查必填字段 | 100% 完整 |
| 数据格式 | 正则匹配验证 | 格式正确 |
| 数据范围 | 边界值检查 | 在合理范围内 |
| 数据一致性 | 交叉验证 | 与其他字段一致 |

## 5. 反检测优化实践

### 5.1 反检测策略

| 策略 | 说明 | 适用场景 | 效果 |
|------|------|----------|------|
| stealth 模式 | 启用反检测插件 | 高防护网站 | 优秀 |
| UA 轮换 | 随机选择 User-Agent | 所有网站 | 良好 |
| 请求间隔 | 设置随机延迟 | 所有网站 | 良好 |
| 代理池 | 轮换 IP 地址 | 高频访问 | 优秀 |
| 会话管理 | 复用已登录会话 | 需要登录的网站 | 优秀 |
| 行为模拟 | 模拟人类操作 | 高防护网站 | 良好 |

**最佳实践**:
- 对高防护网站优先启用 stealth 模式
- 配置合理的请求间隔（2-5 秒随机延迟）
- 使用代理池轮换避免 IP 封禁
- 对需要登录的网站复用已登录会话

### 5.2 验证码处理

| 验证码类型 | 处理策略 | 说明 |
|------------|----------|------|
| 滑块验证 | 轨迹模拟 | 模拟人类滑动轨迹 |
| 点选验证 | 图像识别 | 使用 OCR 识别目标位置 |
| 文字验证 | OCR 识别 | 使用 OCR 识别文字内容 |
| reCAPTCHA | 人工处理 | 触发人工介入 |
| hCaptcha | 人工处理 | 触发人工介入 |

**最佳实践**:
- 对滑块验证使用轨迹模拟，避免直线滑动
- 对点选验证使用图像识别，提高识别准确率
- 对文字验证使用 OCR 识别，配置合理间隔
- 对 reCAPTCHA/hCaptcha 触发人工介入，避免硬扛

### 5.3 指纹伪装

| 伪装项 | 策略 | 说明 |
|--------|------|------|
| WebGL | 固定值 | 避免暴露真实硬件信息 |
| Canvas | 固定值 | 避免指纹识别 |
| 音频 | 固定值 | 避免音频指纹 |
| 字体 | 过滤 | 移除特殊字体列表 |
| 时区 | 本地化 | 使用目标地区时区 |
| 语言 | 本地化 | 使用目标地区语言 |

## 6. 稳定性优化实践

### 6.1 异常恢复策略

| 异常类型 | 恢复策略 | 说明 |
|----------|----------|------|
| 连接断开 | 重连机制 | 自动重新建立 CDP 连接 |
| 页面崩溃 | 重启浏览器 | 重新启动浏览器实例 |
| 内存泄漏 | 定期清理 | 定时清理浏览器会话 |
| 代理失效 | 节点轮换 | 切换至健康代理节点 |
| 验证码触发 | 人工介入 | 触发人工处理流程 |

**最佳实践**:
- 配置合理的重连机制，区分临时故障与永久故障
- 对内存泄漏问题启用定期清理策略
- 对代理失效问题启用节点轮换机制
- 对验证码触发问题启用人工介入流程

### 6.2 资源管理

| 资源类型 | 管理策略 | 说明 |
|----------|----------|------|
| 浏览器实例 | 复用机制 | 复用已有实例，避免频繁创建 |
| 内存使用 | 定期清理 | 定时清理缓存与会话 |
| 网络连接 | 连接池 | 复用 CDP 连接，减少建立开销 |
| 代理节点 | 健康检查 | 定期检测代理节点健康状态 |

**最佳实践**:
- 启用浏览器实例复用机制，减少启动开销
- 配置合理的内存清理策略，避免内存泄漏
- 使用连接池管理 CDP 连接，提高资源利用率
- 定期检测代理节点健康状态，及时剔除失效节点

### 6.3 监控告警

## 7. 性能优化实践

### 7.1 并行执行

| 场景 | 策略 | 说明 |
|------|------|------|
| 多网站评估 | 并行执行 | 同时执行多个网站的评估任务 |
| 多页面抓取 | 标签页复用 | 复用浏览器标签页，减少启动开销 |
| 多请求并发 | 请求队列 | 使用请求队列管理并发请求 |

**最佳实践**:
- 对多网站评估任务启用并行执行，提高执行效率
- 对多页面抓取任务复用浏览器标签页，减少启动开销
- 使用请求队列管理并发请求，避免触发反爬机制

### 7.2 缓存策略

| 缓存类型 | 策略 | 说明 |
|----------|------|------|
| 页面缓存 | 短期缓存 | 缓存已访问页面，避免重复请求 |
| 数据缓存 | 长期缓存 | 缓存已提取数据，避免重复提取 |
| 配置缓存 | 持久化缓存 | 缓存配置信息，减少加载时间 |

**最佳实践**:
- 对已访问页面启用短期缓存，避免重复请求
- 对已提取数据启用长期缓存，避免重复提取
- 对配置信息启用持久化缓存，减少加载时间

### 7.3 资源优化

| 优化项 | 策略 | 说明 |
|--------|------|------|
| 图片加载 | 禁用加载 | 禁用图片加载，减少带宽消耗 |
| CSS/JS | 禁用加载 | 禁用 CSS/JS 加载，加速页面渲染 |
| 字体加载 | 禁用加载 | 禁用字体加载，减少请求数 |
| 广告加载 | 禁用加载 | 禁用广告加载，提高页面质量 |

**最佳实践**:
- 对不需要图片的场景禁用图片加载，减少带宽消耗
- 对不需要 CSS/JS 的场景禁用加载，加速页面渲染
- 对不需要字体的场景禁用字体加载，减少请求数
- 对不需要广告的场景禁用广告加载，提高页面质量
