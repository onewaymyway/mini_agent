## 一、浏览器-cdp Skill 核心操作与功能模块总览

### 1.1 架构分层概览

```
┌─────────────────────────────────────────────────────┐
│                    Agent 调用层                       │
│         (navigate/fill/click/extract/screenshot)      │
├─────────────────────────────────────────────────────┤
│                   内容流水线层                         │
│    WebCrawler → SiteConfig → ContentParser → DB     │
├─────────────────────────────────────────────────────┤
│                   适配器层 (Mixins)                   │
│  EcomMixin / AdminMixin / CsrfHandler / ChartExt    │
├─────────────────────────────────────────────────────┤
│                   基础操作层                          │
│         launch_browser / fill / click / scroll       │
├─────────────────────────────────────────────────────┤
│                   CDP 引擎层                          │
│              Playwright CDP transport                 │
└─────────────────────────────────────────────────────┘
```

### 1.3 原子操作方法（BaseAdapter）

| 操作方法 | 方法名 | 说明 |
|----------|--------|------|
| 浏览器启动 | `launch()` | 启动Chromium，支持stealth模式 |
| 页面导航 | `navigate(url)` | 打开URL，自动等待网络空闲 |
| 输入填充 | `fill(selector, value)` | 填充输入框 |
| 点击操作 | `click(selector)` | 点击元素 |
| 滚动 | `scroll(direction, amount)` | 页面滚动（支持智能检测） |
| 等待 | `wait_for(selector, timeout)` | 等待元素出现 |
| JS执行 | `evaluate(js)` | 执行JavaScript |
| 截图 | `screenshot(path)` | 页面截图 |
| 关闭 | `close()` | 关闭浏览器 |

### 2.2 业务边界定义

#### 已覆盖业务范围 ✅

| 业务域 | 覆盖范围 | 代表站点 |
|--------|----------|----------|
| 新闻资讯 | 列表页+详情页完整抓取 | 网易、腾讯、新浪 |
| 搜索引擎 | 搜索输入+结果页解析 | Bing、百度 |
| 电子商务 | 商品信息、价格、库存 | 京东、淘宝 |

| 内容社区 | 帖子列表、回答内容 | 知乎 |
| 视频平台 | 视频列表（非会员内容） | B站 |

#### 未覆盖业务范围 ❌（明确排除）

| 业务域 | 排除原因 | 备注 |
|--------|----------|------|
| 需要登录的付费内容 | 账号安全问题 | 视频会员、付费文章 |
| 实时交易操作 | 资金安全风险 | 股票买卖、转账 |
| 文件上传下载 | 文件系统权限 | 大型文件传输 |
| 复杂表单提交 | CSRF对抗不确定 | 多步骤注册/登录 |
| 境外网站 | 网络访问限制 | GitHub、StackOverflow |
| 需要验证码的网站 | 自动化绕过风险 | 高频触发的验证码 |

#### 边界情况说明 ⚠️

| 情况 | 处理方式 | 测试验证点 |
|------|----------|------------|
| 网站改版导致选择器失效 | 适配器升级，更新选择器配置 | T4-06部分数据缺失 |
| 网站增加反爬检测 | 启用stealth模式或代理轮换 | T4-04验证码拦截 |
| 动态渲染内容变化 | 延长等待时间或切换等待策略 | T1-06元素等待 |
| 网站API接口变更 | 更新数据提取逻辑 | T2系列端到端测试 |
