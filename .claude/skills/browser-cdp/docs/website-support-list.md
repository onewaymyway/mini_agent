## 7. 最佳实践总结

### 7.1 已验证的最佳实践

| 网站类型 | 最佳实践 | 适用场景 |
|----------|----------|----------|
| 搜索引擎 | 使用 site: 语法限定搜索范围 | 垂直领域搜索 |
| 社交媒体 | 启用智能等待策略处理动态内容 | 微博、小红书 |
| 电商平台 | 使用代理池轮换避免封禁 | 京东、拼多多 |
| 财经网站 | 优先提取结构化数据（JSON-LD） | 东方财富、雪球 |
| 视频平台 | 处理无限滚动加载 | B站、抖音 |
| 学术网站 | 使用官方 API 或 RSS | arXiv、Google Scholar |

### 7.2 反检测策略

| 策略 | 说明 | 适用网站 |
|------|------|----------|
| stealth 模式 | 启用反检测插件 | 高防护网站 |
| UA 轮换 | 随机选择 User-Agent | 所有网站 |
| 请求间隔 | 设置随机延迟 2-5s | 所有网站 |
| 代理池 | 轮换 IP 地址 | 高频访问网站 |
| 会话管理 | 复用已登录会话 | 需要登录的网站 |

### 7.3 性能优化

| 优化项 | 说明 | 效果 |
|--------|------|------|
| 智能等待 | 使用 networkidle 替代固定超时 | 减少 30% 等待时间 |
| 并行请求 | 同时发起多个请求 | 提升 50% 吞吐量 |
| 缓存策略 | 缓存已获取数据 | 减少重复请求 |
| 连接复用 | 复用 CDP 连接 | 减少 20% 启动时间 |
