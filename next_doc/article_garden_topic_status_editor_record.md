# article_garden 选题状态手动修改记录

- **需求**：选题应有地方可以修改状态，例如改为“已放弃”“已放行”。
- **完成日期**：2026-11-23

## 1. 设计

- **位置**：选题页底部「修改选题状态」。列出所有非进行中的选题，显示当前状态；目标状态只列出允许的选项。
- **可改为的状态**：
  - 待放行 ↔ 已放行；
  - 待放行、已放行 → 已拒绝（需填原因）；
  - 待放行、已放行 → 已放弃（需填原因）；
  - 已拒绝、已放弃 → 待放行或已放行（重新纳入，清除对应的拒绝记录）。
- **不能改的**：调研中、成文中（进行中）；已调研、已成稿等后续状态的选题，不能直接改回前面的状态，以免破坏产物。
- **与自动流程分开**：自动流程的转换表保持不变（已拒绝仍是终态，自动放行不会重新打开它）。人工修改通过 `states.set_status` 完成，并在历史中标记 `manual: true`。

## 3. 验证

- 全套 **252 项通过**，pyflakes 无告警。
- 变异验证：去掉“清除拒绝记录”后，对应测试失败。
