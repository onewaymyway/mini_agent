# article_garden 审阅页批量成文记录

- **需求**：审阅页增加批量生成文章的功能。
- **完成日期**：2026-11-24
- **阶段**：单阶段需求，一次完成。

## 1. 设计

- **位置**：审阅页顶部「批量成文」。列出所有可成文的选题（状态为已调研或成文失败，且证据充分），逐项勾选，另有「全选」「清空」；按钮「批量成文（N 个，后台）」。
- **后台逐个执行**：一个进程、一个批量运行记录，按列表顺序逐个成文。一题失败（成文未通过或报错）只记录，不影响其它；用户点击停止或预算用尽则整批结束，当前选题退回原状态。
- **沿用单题的全部保护**：每日调用上限、单步超时、停止信号、修复预算，都与单题成文一致。
- **保守范围**：已成稿、已审阅的选题重写需要附编辑意见，不在批量范围内；批量成文不会自动审阅或发布，成稿后仍需逐篇审阅。
- **跳过而非报错**：不满足条件的选题（不存在、状态不符、证据不足）跳过并写入运行日志；重复的 id 只处理一次。
- **命令行**：`write_article.py <domain> --batch t-0001,t-0002`；`--batch-all` 处理全部「已调研」且证据充分的选题（不含成文失败，失败需显式勾选重试）。
