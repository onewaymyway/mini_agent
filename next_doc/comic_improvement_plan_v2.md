# world_forge 漫画改进方案 v2：从「插图拼接」到「会读的漫画」

> 状态：方案（P5 开始实施）
> 承接：`comic_quality_upgrade_design.md`（P1–P4 已完成，P3 质检取消）
> 目标：让成品在叙事与镜头上接近正常漫画，而不只是排版更像漫画。

## 1. 问题定位

上一轮的判断：差距主要在「从故事到格子」这一步，而不在出图或排字。具体表现为：

1. 格与格之间没有连贯约束：每格的 `visual_en` 独立生成，读者看不出动作的前后关系。
2. 镜头只有“远景/中景/近景/特写”的标签，没有机位、视线方向，容易越轴（同一场景里人物左右位置随意翻转）。
3. 提示词是一句话拼接，图像模型没有拿到姿态、视线、构图、留白区这些信息。
4. 旁白容易复述画面，对白没有角色语气约束。

## 2. 目标定义（验收标准）

用可检查的条目定义“接近正常漫画”，每一条都能通过规则检查或人工评审确认：

| 编号 | 标准 | 检查方式 |
|---|---|---|
| A1 | 相邻格有明确承接关系，每格说明与上一格的衔接 | 结构检查：`connects_prev` 非空（第一格除外） |
| A2 | 同一场景内人物左右位置不无故翻转；翻转时必须是反打 | 规则检查（越轴）：不通过则重试 |
| A3 | 每格有视线方向与机位 | 结构检查 |
| A4 | 构图写明主体位置与留白区，留白用于气泡 | 结构检查 + 提示词包含构图 |
| A5 | 旁白不超过 30 字，不复述画面 | 长度规则检查；复述由提示词约束，人工抽查 |
| A6 | 对白按角色身份区分语气 | 提示词约束，人工抽查 |
| A7 | 提示词包含动作、视线、构图、画面左右顺序 | 测试检查提示词内容 |
| B1 | 大小格随节奏变化（高潮大格、过渡小格） | 版式检查（P6） |
| B2 | 同行可排三格，过渡页更紧凑 | 版式检查（P6） |
| C1 | 多人同框时，参考图按人物分配，避免串脸 | 参考图检查（P7） |
| C2 | 黑白模式有网点纹理 | 人工评审（P7） |

## 3. 分期

### P5 叙事与镜头语言（本次实施）
- 分镜字段扩展：`camera`（机位）、`gaze`（每个出场角色的视线）、`screen_order`（画面中从左到右的人物顺序）、`action`（动作姿态）、`composition`（构图与留白区）、`connects_prev`（与上一格的衔接）。
- 越轴检查：相邻格同时出现的两个以上角色，左右顺序翻转且未标注 `camera=反打`，则判定为越轴并触发重试。
- 旁白约束：不超过 30 字；对白语气按角色身份约束。
- 结构化提示词：把机位、动作、视线、画面左右顺序、构图与留白拼入提示词，视觉描述只保留背景与环境。
- 覆盖：A1–A7。

### P6 版式节奏
- 格子增加 `size`（大/中/小），驱动行高与列宽：大格独占行并获得更高权重，小格允许同一行排三格。
- 连续小格在过渡页使用，高潮页使用大格。
- 覆盖：B1、B2。

### P7 角色一致性与风格
- 多人同框时参考图按人物分配（每人一张立绘或表情图），缓解串脸。
- 黑白模式加入网点纹理（程序化生成半调网点，叠加到灰度图的中间调）。
- 覆盖：C1、C2。

## 4. 风险与边界

- 越轴规则只覆盖“同场景两人以上的左右关系”，不能判断视线是否真正朝向对方，这一点需要人工抽查。
- 结构字段增多会让模型输出变复杂，校验失败会增加重试次数，需要在实际运行中观察重试率。
- 叙事质量的最终判断仍需要人工阅读，规则只能防止明显错误。
