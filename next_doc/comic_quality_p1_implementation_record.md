# world_forge 漫画质量升级 · P1 实施记录

> 对应设计：`comic_quality_upgrade_design.md` 第 4 节
> 范围：节拍表、结构化分镜、版式模板、阅读方向与色彩、页数设置、服务端排字、PNG 导出
> 测试：`python -m pytest -q tests` 全部通过（165 项，含 P1 新增 27 项）

## 1. 本阶段做了什么

### 1.1 节拍表（新增）
- 分镜生成改为两步：先 `beats`（节拍表），再 `storyboard`（分镜）。
- 节拍表每页包含 `purpose`（铺垫/升级/转折/高潮/收束，并附一句说明）、`focus`（画面焦点）、`hook`（页末钩子，最后一页可空）。
- 页数固定时，校验页数必须正好相等；auto 时不校验页数。
- 节拍表保存为故事目录下的 `beats.json`，每次生成分镜时归档旧版本。

### 1.2 结构化分镜
- 每格新增字段：`sfx`（音效字）、`emotion`（情绪）。
- 对白新增 `kind`（speech / thought / shout）与 `speaker_side`（左/中/右）；缺省时由 `position` 推断。
- 对白超过 40 字视为不合格并触发一次重试（提示词要求 24 字以内）。
- 分镜每页的 `beat` 与 `hook` 从节拍表写入，便于在看板中查看。

### 1.3 版式模板（`world_forge/comic_layout.py`，新增）
- 按 `span` 分行：整行格独占一行，连续半行格两两配对，落单的半行格占整行。
- 整页只剩两个半行格时上下排列，避免窄条。
- 行高加权：整行格所在行高于半行行，突出高潮。
- 阅读方向：`rtl` 时同一行的格子从右往左排列。
- 模板名（单格/上下排列/标准两列/大小混排）仅用于记录与展示。

### 1.4 排字规划（同一文件）
- 对白 `position` 映射到 6 个区域；近景和特写的中间区域让开，改放左或右角。
- 尾巴指向 `speaker_side` 对应的横向位置。
- 旁白落在左上（rtl 为右上）；音效落在右下（rtl 为左下）。

### 1.5 服务端排字与 PNG 导出（`world_forge/comic_render.py`，新增）
- 使用 Pillow 绘制 1200×1700 的页面：格子按矩形裁切（cover），格间距 16 px，外框加粗。
- 对白气泡：圆角框 + 尾巴；心声为椭圆并带两个小圆；呼喊为粗边框；旁白为黄色说明框；音效为描边粗体字。
- 尾巴只向说话人方向短促延伸（最长约格高的 22%），不穿过整格。
- 未生成的格子显示占位框与失败原因。
- 黑白模式：格子转灰度并做自动对比度调整。
- 输出：`pages/page_NN.png`，并打包为 `comic_pages.zip`。
- 中文字体查找顺序：环境变量 `WORLD_FORGE_FONT`，再依次尝试常见 Noto CJK、文泉驿、微软雅黑、苹方等路径。找不到时记录警告，仍输出 PNG。

### 1.6 设置
- **页数**：生成分镜时确定（整数 1–20 或 `auto`，缺省 6），保存在故事的 `comic_opts` 与分镜的 `opts` 中。
- **阅读方向**：`ltr`（缺省）或 `rtl`；**色彩**：`color`（缺省）或 `bw`。两者可在生成漫画图时调整，不需要重新生成分镜。
- 非法取值报错（CLI 返回 JSON 错误，看板中由下拉与单选限定）。

### 1.7 网页预览
- `comic.html` 的格子位置与 PNG 共用同一份版式规划。
- 预览不画尾巴；完整排字以 PNG 为准。

### 1.8 界面与 CLI
- 看板故事页新增「漫画设置」（页数、阅读方向、色彩），并增加「PNG 成品页」预览与下载（单页及 zip）。
- 分镜脚本展示每页的节拍、页末钩子，以及音效与心声、呼喊标记。
- CLI：`board` 支持 `--pages`、`--reading`、`--color`；`comic` 支持 `--reading`、`--color`。

## 4. 已知限制（留给后续阶段）

- 离线 stub 的画面是占位图，因此视觉效果只能验证版式与排字，无法验证真实画面与气泡的配合。真实模型的效果需要在有 key 的环境中确认。
- 尚无质检（P3）：人物错误、乱码文字会直接进入成品。
- 黑白模式只是灰度 + 提示词约束，没有网点纹理（P2）。
- 网页预览不画尾巴。
- 自动页数不设上限，但单次模型调用的输出长度有限，超长故事需要分段生成。
- 气泡避让只基于镜头类型与位置规则，没有真正的人脸检测。
- 看板中的版式只能通过设置调整，不能手动拖动气泡（P4）。
