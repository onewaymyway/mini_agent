# article_garden 一键调研全部放行选题记录

- **需求**：调研目前只能逐个选题手动启动，增加一键调研所有放行的选题。
- **完成日期**：2026-11-23

## 1. 修改

| 位置 | 修改 |
|---|---|
| `entrypoints/research.py` | 新增 `--all`：逐个调研全部已放行选题。整批作为一次运行记录（显示在运行日志与顶栏中）；单题错误只记录，不影响其它；预算用尽或用户停止则整批结束；输出每题结果汇总。 |
| `ui/research_page.py` | 新增按钮「一键调研全部已放行选题（N 个，后台）」，无已放行选题或已有调研在运行时禁用。 |
| `tests/test_research_network.py` | 新增 2 项：批量调研会处理已放行选题；没有已放行选题时给出明确提示。 |

## 2. 设计要点

- **一个进程、一个运行记录**：页面只看到一个“调研中”任务，停止按钮对整批有效。
- **沿用单题的全部保护**：每日调用上限、单步超时、停止信号、选题状态回退，都与单题调研一致。
- **不改变单题调研的行为**：仍可逐个调研。

## 3. 验证

- 全套 **236 项通过**，pyflakes 无告警。

## 4. 注意

- 批量调研会处理所有已放行选题，不受每轮选题上限限制；选题很多时，请注意每日调用上限。
- 没有在真实网络中运行过整批调研。
