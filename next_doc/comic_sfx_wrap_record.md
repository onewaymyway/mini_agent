# world_forge 漫画 · 音效重叠与换行修复记录

> 问题：1) 大黑字音效（如「xxx声」）压住说话气泡；2) PNG 中音效不换行，而网页版会换行。
> 测试：`python -m pytest -q tests` 全部通过（260 项，本次新增 4 项）。

## 1. 诊断

1. **重叠**：音效的占位框只按字号估算，没有包含描边（约 4 px）与字形的实际高度，绘制时超出占位框，压住相邻的气泡。另外，放不下时的兜底逻辑仍会直接绘制，造成重叠。
2. **换行**：网页版的音效受 `.bz` 的 `max-width: 52%` 约束，超过时换行；PNG 中音效是整行绘制，不做换行。

## 2. 改动

- **换行一致**：音效按格宽的 52% 换行（与网页版相同的规则），逐行绘制，行距 1.05 倍字号。
- **占位框**：宽度为最长一行加左右留白（含描边）；高度为行数加字高（1.25 倍字号）再加留白。
- **放不下**：字号依次缩小为 84 → 64 → 52 → 40；仍放不下则省略该音效，并在日志中给出警告「音效「…」放不下，已省略」。音效只在有空位时才绘制。
- **顺序**：音效在对白之后排版，并参与碰撞检测。

## 3. 改动文件

路径均相对于 `external_projects/world_forge/`：`world_forge/comic_render.py`（测量、换行、缩小与省略）、`tests/test_sfx_layout.py`（新增，4 项）、`docs/README.md`、`PROJECT.md`。

## 4. 验证

- 长音效按 52% 宽度换行（半格 560 px 的「咔嗒咔嗒」换行为两行）。
- 音效与对白不重叠（碰撞检测）。
- 放不下时缩小或省略，并给出警告。
- 人工检查：渲染的样例中音效位于格内，不压住对白。

## 5. 限制

- PNG 与网页版的换行规则一致，但字号不同（PNG 的音效为 84 px，按成品页尺寸设定；网页版按视口宽度缩放）。
- 省略的音效不会出现在成品中，需要在「编辑文字」中删除或缩短，或调整分镜。
- 格子很小、对白很多时，音效被省略是预期结果。
