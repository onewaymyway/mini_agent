# article_garden 选题标题质量提升记录

- **触发**：生成的选题全是“X是什么”“X入门”“X入门指南”“X综述”，没有深度，与文库文章的风格不符。
- **原因**：缺口选题由固定模板生成标题（每种缺口类型对应一个模板），没有参考文库，也没有让模型参与。
- **完成日期**：2026-11-23

## 1. 修改

| 位置 | 修改 |
|---|---|
| `planning/topics.py` `style_profile()` | 汇总文库的文体分布、层级分布，以及 12 篇代表性标题（附文体、层级），作为写作风格参照。 |
| `planning/topics.py` `_write_titles()` | 对最终会被提出的缺口选题，每 8 个一批由模型撰写标题、角度、文体与层级；要求具体、有问题意识、点明取舍或误区，不得只写模板式标题。 |
| `planning/topics.py` `_title_validator()` | 校验：标题 8–40 字；不得以“是什么、入门、入门概览、入门指南、综述”结尾；不得与已有标题或本批标题雷同；文体与层级合法；必须有角度说明。 |
| 失败回退 | 任一批未通过，该批保留模板标题并写入运行日志，不影响其它选题与整轮运行。 |
| 去重之后再撰写 | 只为最终会被提出的选题撰写标题。被去重淘汰的候选不消耗模型调用，所以“无变化时零模型调用”仍然成立。 |

## 2. 验证

- 新增 5 项测试：模板式标题、重复标题、文体不合法会被拒绝；有深度的标题会通过；提示词包含文库风格参照；选题标题由模型撰写；标题未通过时保留模板标题、选题照常生成。
- 去掉模板式标题的校验后，测试失败。
- 测试中的假模型把对比类标题也写成了“对比”，结果写作阶段失败，原因是对比类文章必须包含对比表格——这说明文体与成文要求是一致的。测试已改为使用“概念讲解”。
- 全套 **234 项通过**，pyflakes 无告警。

## 3. 注意

- 标题质量依赖模型，需要在你的文库上看实际效果。
- 首次运行会对每个新缺口调用一次模型（每 8 个选题一批）。之后的运行只为新出现的缺口调用。
- 已经生成并仍在待放行中的旧选题不会自动改写标题；如需更新，请拒绝后重新检测缺口。
