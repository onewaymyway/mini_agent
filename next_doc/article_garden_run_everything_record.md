# article_garden 一键全部执行记录

- **需求**：除逐步按钮外，增加一个按钮，自动执行全部流水线操作。
- **完成日期**：2026-11-23

## 1. 设计

- 每一步已有对应按钮（导入、摘要、章程草稿、概念与关系、知识树提案、选题、调研、成文、审阅、发布），本次未改动。
- 新增首页「▶ 全部执行」：按顺序执行 摘要 → 概念与关系 → 知识树提案 → 缺口与选题 → 放行 → 调研 → 成文 → 标为已审阅。
- **授权**：勾选确认后点击即视为授权，等同于在 G3 挡位运行，但**不自动发布**（`auto_publish` 固定关闭），**不自动应用知识树提案**。
- **不受挡位限制**：默认 G0 下也可以使用。按挡位运行的入口保持不变。
- **约束照常生效**：每日调用上限（本库、全局）、单步超时、停止按钮、单步失败隔离。
- **选题上限**：放行数量不超过 `max_topics_per_cycle`。
