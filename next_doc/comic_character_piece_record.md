# world_forge · 角色小故事与小笑话实施记录

> 需求：选定某个角色，为它创作专门的小故事或小笑话，之后能继续变成漫画。
> 测试：`python -m pytest -q tests` 全部通过（280 项，本次新增 8 项）。

## 1. 设计

- 复用已有的「主体视角」机制（`_focus_of`）：只允许以角色为主角。
- 复用角色的事件时间线（`_subject_event_ids`）：取最近 6 件事作为素材；没有经历时仅根据角色设定创作。
- 保存为短篇（`kind=short`），`focus` 为该角色，因此分镜与漫画流程无需改动即可使用。
- 形式 `joke`（小笑话）与 `story`（小故事）分别有字数上限（200 与 2500 字），超过时把原因反馈给模型重试。

## 2. 改动

- **生成层** `generate.piece_draft`：按形式选择提示词，检查为空与超长，重试时附上原因。
- **引擎** `engine.write_character_piece`、`_run_piece`、`_piece_context`、`_split_title`、`_regenerate_piece`；`regenerate_short` 对角色作品走专门的分支（沿用原始输入，故事编号不变）。
- **离线 stub** `_task_piece`。
- **看板**：故事页「为角色创作小故事或小笑话」面板（选择角色、形式、可选提示）。
- **CLI**：`piece` 命令。

## 3. 验证

- 小笑话保存为短篇，视角为该角色，标题已从正文拆出。
- 形式与主角校验：只能以角色为主角；未知形式与不存在的角色会被拒绝。
- 字数超限会自动重试，超过次数后报错。
- 小笑话可以直接生成分镜（1 页）与漫画图（已渲染 PNG）。
- 重新创作保持故事编号，旧正文归档到 `history/`。

## 4. 限制

- 作品质量取决于真实模型；离线 stub 只能验证流程。
- 「创作后一键生成漫画」尚未做成单个按钮，目前需要在故事页依次点击「生成分镜」「生成漫画图」。
- 角色的说话风格只能从角色摘要与外观推断，没有单独的「口头禅」字段。
- 字数上限是经验值（小笑话 200 字，小故事 2500 字），可在 `generate.PIECE_LIMIT_CHARS` 调整。
