# article_garden 字数改为软目标记录

- **问题**：成文日志出现“正文约 7705 字，不在章程要求的 1500–4000 字之间”，整篇失败。字数限制过于死板。
- **完成日期**：2026-11-24

## 1. 设计

- 章程 `style.length` 改为**软目标**：提示词里仍告诉模型目标字数，但检查时：
  - 区间内：无提示；
  - 超出区间但未严重偏离：**只提示，不判失败，不触发修复**，提示写入运行日志（警告）和 `drafts/<tid>/checks.json` 的 `length_note`；
  - **严重偏离**（低于下限的一半，或高于上限的三倍）：仍判为问题，防止明显跑偏。
- 原先超长时会让所有小节按“字数不对”重写，消耗修复预算且未必能改好，现在不再发生。
- 阈值 0.5 与 3.0 是 `writing/checks.py` 中的常量 `LENGTH_LOW`、`LENGTH_HIGH`。

## 2. 修改

| 文件 | 修改 |
|---|---|
| `writing/checks.py` | 新增 `body_chars()`、`length_note()`、常量；`check_document` 只对严重偏离报问题。 |
| `writing/runner.py` | 通过评审后若字数超出区间，记录警告并写入 `checks.json`。 |
| `tests/test_writing.py` | 新增 3 项：软目标与严重偏离的判定；略超出仍成文并记录提示；严重偏离仍失败。 |

## 3. 验证

- 全套 **272 项通过**（1 项按环境跳过），pyflakes 无告警。

## 4. 注意

- 你这次的 7705 字对 1500–4000 是 1.93 倍，现在会通过并给出提示；若觉得仍然太长，可在设置里调整章程的字数上限，或告诉我是否需要把倍数做成设置项。
