# article_garden 字数改为软目标记录

- **问题**：成文日志出现“正文约 7705 字，不在章程要求的 1500–4000 字之间”，整篇失败。字数限制过于死板。
- **完成日期**：2026-11-24

## 1. 设计

- 章程 `style.length` 改为**软目标**：提示词里仍告诉模型目标字数，但检查时：
  - 区间内：无提示；
  - 超出区间但未严重偏离：**只提示，不判失败，不触发修复**，提示写入运行日志（警告）和 `drafts/<tid>/checks.json` 的 `length_note`；
  - **严重偏离**（低于下限的一半，或高于上限的三倍）：仍判为问题，防止明显跑偏。
- 原先超长时会让所有小节按“字数不对”重写，消耗修复预算且未必能改好，现在不再发生。
- 两个倍数是**设置项**（设置页「校验阈值」分组，可全局设置，也可按文章库覆盖）：
  - `thresholds.length_low_factor`：默认 0.5，范围 0.1–1.0；
  - `thresholds.length_high_factor`：默认 3.0，范围 1.0–20.0。
  严重偏离的提示里会写出当前的容忍区间。`writing/checks.py` 中的 `LENGTH_LOW`、`LENGTH_HIGH` 仅作缺省值。

## 2. 修改

| 文件 | 修改 |
|---|---|
| `writing/checks.py` | 新增 `body_chars()`、`length_note()`、常量；`check_document` 只对严重偏离报问题，容忍倍数由参数传入。 |
| `settings.py` | 新增两个设置项（界面自动出现在「校验阈值」）。 |
| `writing/brief.py` | 简报带上当前生效的容忍倍数。 |
| `writing/runner.py` | 通过评审后若字数超出区间，记录警告并写入 `checks.json`。 |
| `tests/test_writing.py` | 新增 5 项：软目标与严重偏离的判定；略超出仍成文并记录提示；严重偏离仍失败；容忍倍数来自设置并生效；设置项有范围校验且在设置页显示。 |

## 4. 注意

- 设置页的章程字数下限控件最小值为 100，若章程里的下限低于 100，设置页会报错（既有限制，未改动）。
