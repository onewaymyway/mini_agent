# world_forge 漫画 · 气泡避让实施记录

> 问题：漫画中的文本框（旁白、对白、音效）有时互相遮挡。
> 测试：`python -m pytest -q tests` 全部通过（245 项，本次新增 4 项）。

## 1. 诊断

1. **区域之间互不检查**：原来的堆叠游标只在同一区域内生效。左、中、右三个区域的元素可能彼此压住。
2. **宽度约束不足**：单个气泡最宽占格宽的 52%，两个并排就会超过 100%。
3. **堆叠不检查边界**：同一区域堆叠超出格子时，会压到其它区域的内容。
4. **音效不参与避让**：音效字直接叠在画面上，可能盖住气泡。

## 2. 改动

- **避让式排版** `comic_render._layout_panel`：按优先级依次放置；每个元素依次尝试原区域、同一垂直位置的其它区域、其余区域；在区域内从边缘向内逐步扫描（步长 6 像素）。
- **碰撞检测**：每个元素的矩形包含尾巴的延伸（心声与气泡的尾部）；与已放置元素保持 8 像素间距；不得超出格子边界。
- **宽度回退**：放不下时宽度依次缩小为 100%、80%、65%。
- **近景与特写**：候选区域中排除正中，保持人脸区域不被遮挡。
- **警告**：仍放不下时，退回原区域贴边放置，并记录警告。渲染器把警告传给拼装流程，日志中以「第 N 页：…」列出（最多 20 条）。
- **接口**：`render_page` 与 `write_pages` 新增可选参数 `warnings`。

## 3. 改动文件

路径均相对于 `external_projects/world_forge/`：`world_forge/comic_render.py`（避让排版）、`world_forge/engine.py`（输出警告到日志）、`tests/test_bubble_layout.py`（新增，4 项）、`docs/README.md`、`PROJECT.md`。

## 4. 验证

- 拥挤的一格（3 句对白 + 旁白 + 音效）：元素两两不重叠，全部位于格内。
- 近景与特写：没有气泡放在正中。
- 放不下的情况：给出警告，不会静默重叠。
- 人工检查：渲染一页拥挤样例并查看，无重叠，尾巴指向说话人。

## 5. 限制

- 网页预览 `comic.html` 仍是简化排版，不做碰撞检查。
- 警告只说明某句对白放不下，需要人工缩短对白（或在「编辑文字」中修改），系统不会自动改写对白。
- 避让只基于格子的矩形与文字尺寸，不知道画面里人物的确切位置；近景/特写的「不占正中」是按规则处理，不是人脸检测。
