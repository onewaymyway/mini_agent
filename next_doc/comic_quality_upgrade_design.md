# world_forge 漫画质量升级设计

> 状态：设计方案（P1 已实施，见 `comic_quality_p1_implementation_record.md`）
> 范围：`external_projects/world_forge` 的分镜、版式、排字与导出
> 说明：本文件由设计讨论内容重建。原设计文档未随上一版压缩包一同提供，此处内容以讨论结论为准。

## 1. 现状与短板

1. **叙事结构弱**：分镜一次性生成，没有「铺垫、升级、转折、高潮、收束」的节拍，页与页之间缺少悬念。
2. **对白质量低**：对白按位置分配，缺少情绪与性格；旁白常复述画面；没有音效、心声、呼喊的区分。
3. **版式单一**：只有两列网格，气泡按角落放置，可能遮住人脸，尾巴不指向说话人。
4. **画面粗糙**：提示词由临时拼接而成；场景没有设定图；配色没有规划；一致性主要靠一张立绘。
5. **没有质检**：人物错误、乱码文字直接进入成品。
6. **输出单一**：只有 HTML 预览，没有 PNG、PDF、CBZ 等可分享的格式。

## 2. 改进方向

把流程拆成可单独检查、单独重做的环节，每个环节产出结构化数据：

- **节拍表**：每页有明确的叙事作用、一个画面焦点和页末钩子。
- **结构化分镜（漫画剧本）**：逐格给出镜头、动作、表情、对白（限字数，区分说话/心声/呼喊）、音效、留白区。
- **版式模板**：高潮用整行大格，对话用规整格，按阅读方向排布。
- **设定图**：角色表（正面、侧面、多种表情）、场景图、风格指南与每幕配色。
- **分格出图**：结构化提示词，关键格生成候选，失败时带着具体问题重试。
- **多模态质检**：检查人物、镜头与乱码文字，并验证留白区是否真的留空。
- **服务端排字**：气泡避开人脸，尾巴指向说话人，音效与心声使用不同样式。
- **输出**：PNG 页（成品）、网页预览；之后再考虑 PDF、CBZ、条漫长图。

## 3. 已确定的决策

| 问题 | 结论 |
|---|---|
| 画风 | 默认彩色，可切换黑白网点 |
| 阅读方向 | 默认从左到右，可切换从右到左 |
| 页数 | 可设置固定页数（默认 6），也可选「按故事长度自动（不限制）」 |
| 图像模型输入 | 支持图片输入，但本阶段不做质检 |
| 候选机制 | 接受调用次数增加，需设上限 |
| 导出 | 首选 PNG；PDF / CBZ 后续再做 |
| 分期 | 先做 P1 |

## 4. 分期

- **P1**（不需要新依赖）：节拍表、结构化剧本、对白约束、版式模板、服务端排字、PNG 导出、阅读方向与页数设置。
- **P2**：角色表、场景设定图、风格指南、候选机制（上限可配置）。
- **P3**：多模态质检与自动重试（依赖图像模型的图片输入能力，已确认可用）。
- **P4**：网页阅读器、CBZ 与条漫长图导出、看板中剧本与版式编辑。

## 5. 主要风险

- **候选机制的成本**：候选会使图像调用成倍增加，必须有每故事的调用上限与超限提示。
- **自动页数的输出长度**：故事很长时，单次模型调用的输出可能不够，需要后续改为分段生成节拍。
- **中文排字依赖字体**：服务器缺少中文字体时 PNG 会出现方框，需在部署说明中写明。
- **质检误判**：多模态质检可能误报或漏报，P3 需要保留人工覆盖入口。
