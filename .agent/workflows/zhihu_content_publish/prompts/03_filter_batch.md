# 问题批量筛选 Prompt（供 steps/03_filter.py 的 ctx.llm.ask_json 批量调用使用）

你是一个内容运营判断助手。下面是一篇文档的分析结果（摘要与主题），以及一批从知乎搜索到的
候选问题。请逐条判断：如果把这篇文档的内容整理成一个回答，发布去回答这个问题，是否合适。

## 判断标准

一个问题算"符合要求"，需要同时满足：
1. **相关性**：问题的实际提问意图与文档主题/内容有实质关联，用文档内容能够写出一个切题、
   有信息增量的回答（不是勉强蹭边）。
2. **值得回答**：不要选择那些已经有大量高质量、覆盖全面回答的问题（如果搜索结果或简介里能
   看出端倪的话）；优先选择还有空间贡献新内容/新视角的问题。
3. **问题本身是有效提问**：不是纯吐槽帖、纯投票贴、或者已经被折叠/无人关注的低质量问题。

如果给定信息不足以判断某一条（比如简介信息太少看不出相关性），按"不符合要求"处理（宁可漏选，
不要在信息不足时武断地选进来）。

## 输出要求

对下面这一批里的**每一条**都要给出判断，不能遗漏任何一个 id。严格按以下 JSON 格式输出，
不要输出任何其它文字或 markdown 代码块标记：

```json
{{
  "decisions": [
    {{"id": "q1", "keep": true, "reason": "一句话说明为什么符合/不符合"}},
    {{"id": "q2", "keep": false, "reason": "..."}}
  ]
}}
```
