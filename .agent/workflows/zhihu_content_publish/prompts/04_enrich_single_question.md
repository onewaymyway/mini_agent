# 单个问题详情提取 Prompt（python_step，配合 CDP 抓取的页面文本使用）

下面是知乎问题详情页 `{url}` 抓取到的可见文本内容（已去除脚本/样式，可能有截断）：

```
{page_text}
```

## 任务

从上面的页面文本里提取以下信息，输出成 JSON（提取不到的字段一律填 `null`，
不要编造、不要用占位符充数）：

- `answer_count`：整数，回答数量（页面上常见"XX 个回答"）
- `follower_count`：整数，关注者数量（页面上常见"XX 人关注"）
- `view_count`：整数，浏览次数（页面上常见"被浏览 XX 次"，没有则 `null`）
- `description`：字符串，问题的完整描述/补充说明（没有则 `null`）
- `created_or_active_time`：字符串，问题创建时间/最近活跃时间（没有则 `null`）
- `top_answer`：对象，默认排序下排名最前面的回答：
  - `author`：字符串，回答作者（没有则 `null`）
  - `upvote_count`：整数，该回答的点赞数（没有则 `null`）
  - `content`：字符串，该回答的完整内容（没有则 `null`）

数字字段如果页面文本里写的是"1.2万"这类中文简写，换算成整数（1.2万 → 12000）。
