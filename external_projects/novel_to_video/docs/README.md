# novel_to_video 使用说明

把 `novel_writer` 导出的小说转换为竖屏短剧视频的工作台。当前版本（Phase 0–4）完成导入、项目创建、全书级素材、单章流水线、多章队列、挡位 G0–G5、预算、修改分级回退，以及全书合成（封面、转场、成片校验）。Phase 5 完成加固：项目运行锁与崩溃回收、key 池切换修复，并提供真实 API 冒烟脚本。

## 环境

```bash
cd external_projects/novel_to_video
pip install -r requirements.txt
python entrypoints/health.py        # 输出 ok 即健康
```

## 1. 导入导出目录

导出目录是 `novel_writer` 生成的 `小说_YYYYMMDD_HHMMSS/`，需要包含 `正文/`、`设定/人物/角色/`、`README.md`。

### 界面

```bash
streamlit run app.py
```

1. 打开「导入导出目录」，填写导出目录路径；
2. 填写书名（导出包不含书名）；
3. 章节范围留空即全部章节，也可填 `1-10,12,20-`；
4. 点击「检查导出目录」，查看章节数、角色数、地点数与问题清单；
5. 确认无阻断错误后点击「创建项目」。

检查过程只读，不会修改导出目录，也不会创建任何文件。

### 命令行

```bash
# 只检查，不创建项目
python entrypoints/import_novel.py "D:/novels/小说_20261101_101309" --dry-run

# 创建项目（默认写入 novel_output/）
python entrypoints/import_novel.py "D:/novels/小说_20261101_101309" --title "铁城" --chapters "1-20"
```

输出为 UTF-8 JSON。导入存在阻断错误时退出码为 1，且不会创建任何目录。

## 2. 问题等级

| 等级 | 含义 | 是否阻断 |
|---|---|---|
| error（阻断） | 缺少正文目录、章节号重复、角色 id 重复、导出目录不存在等 | 是 |
| warning（提示） | 章节号不连续、角色缺性别、章节过短、导出清洗提示等 | 否，但需要关注 |
| info（信息） | 没有章节总结、没有全书合稿等 | 否 |

## 3. 项目目录

创建后得到 `novel_output/<书名>_<时间戳>/`，内容见 `PROJECT.md` 的「目录约定」。

- `project.json` 记录导入时的配置；之后修改它会影响后续阶段，请只在明确需要时手动编辑；
- `chapters/index.yaml` 中的 `selected` 决定哪些章节进入后续流程；
- `PROGRESS.md` 只追加，用于记录决策与反馈，跨 session 续接时先读它；
- 源目录被修改后，项目页会提示指纹不一致，此时应重新导入，而不是继续使用旧项目。

## 4. 全书级素材（G-2 / G-3）

### 配置

- 图像：设置环境变量 `AGNES_API_KEYS`（逗号分隔，可配多把 key，遇限流自动切换）或 `AGNES_API_KEY`。key 只从环境变量读取，不写入项目文件。
- 文本：使用 mini_agent 的 LLM 配置（与 world_simulator、novel_writer 相同的 `providers.json` 体系）。
- 离线演示：设置 `NOVEL_TO_VIDEO_PROVIDERS=stub`，图像生成占位图，文本使用规则兜底。此模式不消耗额度，但结果不可用于正式制作。

### 命令行

```bash
# 1) 补全视觉锚点、声音设定、缺失性别（只补缺失项）
python entrypoints/build_assets.py novel_output/<项目> --stage text

# 2) 为已补全设定的实体生成定妆图（已有有效图的跳过）
python entrypoints/build_assets.py novel_output/<项目> --stage portrait

# 3) 只重生成某几个实体的定妆图（生成 _v2 等新版本）
python entrypoints/build_assets.py novel_output/<项目> --stage portrait --ids char_001 --regenerate

# 也可以一次做完 1 和 2：--stage all（默认）
```

输出为 JSON，包含本次成功/失败/跳过的实体与当前审核状态。存在失败项时退出码为 1，失败原因写在 `global/review.json` 的 `last_error` 中，修正后重跑即可，已成功的实体不会重复生成。

### 界面

「全书素材」页：点击按钮执行 G-2 或 G-3，然后在画廊中逐条审核：

- 「通过设定」：确认视觉锚点、声音设定与性别无误（缺失字段时不可通过）；
- 「通过定妆图」：确认图片可用于后续章节；
- 「驳回并重生成」：生成新版本图片；
- 「查看与编辑设定」：人工修改 visual_anchor_en、voice_profile、性别。改动视觉字段后，已通过的定妆图会标记为「需重生成」。

所有角色与地点的设定与定妆图都通过后，页面会显示「可以进入章节生产」，这是 Phase 2 的前置门禁。

### 来源标记

每个被生成或人工修改的字段都带有 `*_source` 标记：`miniagent`（真实 LLM）、`rules`（规则兜底，需审核）、`manual`（人工编辑）。导出包原有内容没有来源标记。

## 5. 章节生产（C-1 … C-9）

### 配置

- 视频：`AGNES_API_KEYS` 或 `AGNES_API_KEY`（与图像共用同一套 key）。
- 配音：默认 edge-tts，需要 `pip install edge-tts` 并能访问微软语音服务；未安装时会提示错误。离线测试可用 `NOVEL_TO_VIDEO_PROVIDERS=stub`。
- ffmpeg：需要在 PATH 中，或设置 `FFMPEG_BIN` / `FFPROBE_BIN`。
- 单章目标时长在 `project.json` 的 `target_chapter_duration_sec` 中设置（默认 90 秒）。剧本会按 `时长 × 4.2 字/秒` 压缩口播字数，超过目标 1.6 倍即校验失败。
- `project.json` 的 `script_max_retries` 与 `shots_max_retries`（默认各 2，范围 0–3）：剧本、镜头规划校验失败后，自动把全部问题（对白不是剧本原文时还会附上剧本里最接近的原句）反馈给模型修正的最多次数；用尽仍未通过才失败。每次修正多一次文本模型调用，0 表示关闭；也可在「挡位与队列」页设置。

### 运行

```bash
# 运行全部已选中章节（可重入，已完成的阶段会跳过）
python entrypoints/run_chapter.py novel_output/<项目>

# 只运行部分章节；--force-script 强制重新生成剧本
python entrypoints/run_chapter.py novel_output/<项目> --chapters 1-3
```

输出 JSON，每章的 status 为：

| status | 含义 | 下一步 |
|---|---|---|
| `waiting_assets` | 镜头里出现了库中没有的角色，或缺少定妆图 | 到「全书素材」页确认补建角色的文本设定与定妆图，再重新运行 |
| `waiting_review` | 小场景视频已全部生成 | 到「章节生产」页逐镜审核，再重新运行 |
| `failed` | 某阶段失败，`message` 说明原因 | 修正后重新运行 |
| `done` | 章节成片 `chapters/NNN/chapter_NNN.mp4` 已生成 | — |

### 界面

「章节生产」页：选择章节 → 运行本章 → 查看阶段状态与剧本 → 逐个小场景预览视频与口播音频，然后：

- 「通过」：确认该镜头；
- 「驳回并重生成」：填写意见后删除旧视频，下次运行时重新生成；
- 每个镜头卡片显示出镜角色（定妆图与名字）、地点名与说话人姓名；画面描述提到了某角色但出镜角色里没有时会提示；
- 「重新规划本章镜头」：模型把一整场戏写成一个镜头时，代码只能按时长拆开，拆出的镜头共用同一条画面描述、视频会很相似，页面会给出提示。勾选确认后可丢弃本章镜头及其配音、视频、审核并重新规划（剧本与补建角色不动）；
- 「编辑镜头内容」：修改英文画面描述、中文描述、出镜角色或口播文字。对白必须仍能在原文中逐字找到。保存后已通过的审核会变为「需重审」，需要重新运行本章。

### 补建角色其实已经存在：合并

补建角色卡片里有折叠项「这个角色其实已经存在？合并到已有角色」：选择对应的已有角色，勾选确认后点「合并」。合并后：

- 补建角色的名字成为所选角色的别名，以后各章按名字自动归到它；
- 各章镜头里这个说话人改归所选角色，沿用其音色与形象；
- 为它生成过的音频、提示词、视频会被清理并需重新生成，章节成片标记为过期；
- 补建角色从库中删除，不再需要审核。定妆图文件保留在磁盘上。

合并不可撤销，请确认确实是同一个角色。

### 查看模型的输入与输出

出错时不必翻文件，直接在「章节生产」页看：

- **剧本校验（C-2）**：通过/未通过、场次数、口播字数与目标，以及完整问题清单（例如哪一行对白在原文中找不到）；
- **模型调用记录（输入 / 输出）**：最近几次文本模型调用，最新一条默认展开。三个标签页：
  - 「返回的原始内容」：模型未经加工的输出，解析与校验在它之后；
  - 「发送的提示词」：实际发给模型的完整提示词；
  - 「系统提示」。
- 运行日志里每次调用都完整打印输入（系统提示与提示词，调用前）和输出（调用后），不截断；多行内容的续行以 `│` 开头。

「全书素材」页同样有 G-2 的模型调用记录。数据保存在项目的 `logs/llm_trace.jsonl`。

常见问题定位：

| 现象 | 看哪里 | 常见原因 |
|---|---|---|
| 剧本校验“第 N 行出现在任何场次标题之前” | 「返回的原始内容」 | 模型带了解释文字或代码块；JSON 包装会被自动解包并在日志给出⚠提示 |
| “口播总字数超过目标 1.6 倍” | 剧本校验的口播字数 | 模型没有压缩；可开启 `script_max_retries` |
| “对白未在原文中找到” | 剧本校验问题清单中的行号与对白 | 模型改写了台词；对白必须逐字摘录；会自动修正，次数用尽才失败 |
| 镜头规划“对白不是剧本中的连续原文” | 「镜头规划校验（C-3）」的问题清单，与「模型调用记录」里每次修正的输入输出 | 模型把长台词删减或拼接；对白只能截取剧本原句中的连续一段；会自动修正，次数用尽才失败 |

### 缺失的地点与道具

- 镜头里出现库中没有的**地点**，或模型认为对剧情有意义的**关键道具**（每镜头最多 3 个，日常小物品不列）时，章节页会警告列出名称；运行 C-5 时会为它们起草设定并写入全局库（`global/locations.json` / `global/props.json`，`source=auto_added`）。
- 草稿与补建角色一样要确认：先在「全书素材」页通过**设定**，再生成并通过**定妆图**（道具定妆图为 1:1 单件物品图），章节才会继续；G3 及以上挡位自动通过。
- 道具定妆图缺失时 C-8 会被拦截。视频接口最多 3 张参考图：角色与地点优先，有余量时才带道具；道具外观始终写进提示词。
- 旧项目没有 `global/props.json`，按空库处理，无需迁移。

### 角色多形象（默认关闭）

同一个角色换装、受伤、伪装时，只用一张定妆图会与剧情不符。在「挡位与队列」页勾选「启用角色多形象」后：

- 镜头规划只在角色外观与基础外观明显不同时指定一个「形象」（如“战斗装”“病中”），绝大多数镜头不需要；
- 角色还没有的形象由 C-5 起草，和补建角色一样要在「全书素材」确认设定与定妆图（类型显示为“角色形象”，id 形如 `char_001:look_01`），G3 及以上挡位自动通过；
- 该镜头的提示词与参考图使用这个形象；形象还没有定妆图时 C-8 会被拦截，不会悄悄用基础形象顶替；
- 关闭时一切与之前相同。已规划的章节不会自动改变，需要时在章节页「重新规划本章镜头」。

### 补建角色

剧本中出现的新说话人会被自动起草为角色（`source: auto_added`，`auto_added_chapter` 为出现的章节号）。在确认其文本设定和定妆图之前，本章不会进入配音和视频生成。

剧本校验里的“说话人不在角色库中”只是提示，无需修改剧本。镜头规划（C-3）会先尝试把这些说话人归入库里已有的角色（例如“盖亚播报”归入“盖亚”），页面的“补建角色”表格会逐个写明处理结果，只有“需要确认”的才有审核卡片；请顺便核对归并是否合理。**直接在「章节生产」页的“补建角色”区处理**（「补建角色审核」页是同一套卡片）：

1. 点「运行第 N 章流水线」，运行到 C-5 时自动起草这些角色的设定；
2. 展开「查看与编辑设定」，核对设定并**选择性别**（模型起草的性别不算确认，必须你选一次，选的值与模型相同也要点「保存修改」）；
3. 点「通过设定」→「生成定妆图」→ 看图后点「通过定妆图」；
4. 重新运行本章。

「通过设定」是灰色时，卡片里会写明缺什么。

## 6. 导入之后要做什么

导入报告中的提示需要人工确认：

1. 核对「清洗警告」列出的章节（第 8、43、47 章是删除工具残留，第 21 章是疑似重复结尾）；
2. 角色性别缺失可在 G-2 由真实模型推断，或在「全书素材」页人工补全；
3. 书名如不正确，可在项目目录的 `project.json` 中修改 `title`（仅影响显示）。

## 5. 挡位与批量运行（Phase 3）

挡位决定哪些检查点自动通过，默认 **G0**（全部手动）。

| 挡位 | 全书素材 | 剧本/分镜 | 小场景审核 | 章节合成 | 补建角色 |
|---|---|---|---|---|---|
| G0 | 手动 | 手动 | 手动 | 手动 | 手动 |
| G1 | 手动 | 手动 | 手动 | 自动 | 手动 |
| G2 | 手动 | 自动 | 手动 | 自动 | 手动 |
| G3 | 自动 | 自动 | 自动（机械合格才通过） | 自动 | 自动补建 |

- **全书合成（F-1）在任何挡位下都需要人工确认。**
- **G3 必须设置预算上限**（视频调用、图像调用、耗时分钟）。任一超限即停止后续章节，已完成章节保留。
- **小场景在 G0–G2 始终逐镜确认**；G3 只自动通过通过机械检查（无错误、一致性 pass、视频已生成）的镜头，并在 `PROGRESS.md` 中留下记录。

### 界面

「🚦 挡位与队列」：选择挡位（G3 需填写预算）、查看检查点策略表、按章节范围运行队列、查看全书状态。

### 命令行

```bash
# 按项目设置的挡位运行全部选中章节
python entrypoints/run_queue.py novel_output/<项目>

# 指定章节与挡位
python entrypoints/run_queue.py novel_output/<项目> --chapters 1-3 --gear G2
```

退出码：0 正常，1 有章节失败，2 因预算停止。`waiting_*` 不是错误。

## 6. 修改与回退（Phase 3）

在章节生产页对某个镜头提出修改时，应选择影响层级：

| 层级 | 清理范围 | 适用场景 |
|---|---|---|
| clip_only | 该镜头视频 | 只想重新生成画面 |
| prompt | 提示词、一致性结论、视频 | 修改了画面描述 |
| dialogue | 配音、提示词、视频，剧本需重新校验 | 修改了台词 |
| shot_plan | 该镜头及其之后的全部镜头，回到 C-4 | 需要重新切分镜头 |

清理只影响当前章节。该章成片标记为 stale；若全书成片已存在，也会标记为 stale。其他章节的文件与状态不受影响。

## 7. 补建角色审核（Phase 3）

「🧩 补建角色审核」列出章节生成中自动新增的角色，展示文本设定与定妆图状态。卡片自带操作按钮（编辑设定与性别、通过设定、生成与通过定妆图），也可直接在「🎬 章节生产」页的“补建角色”区处理，两处是同一套组件。

## 8. 全书合成（Phase 4）

在「🎞️ 全书合成」页或命令行完成：

1. **F-1 检查**：所有选中章节必须 `done`，且章节成片未过期。
2. **封面（可选）**：设置标题、布局、时长（1–8 秒）。背景图由图像接口生成（提示词要求无文字），标题由本地叠字生成。改标题只需重新叠字。
3. **人工确认**：合成前必须确认，任何挡位都不能跳过。确认绑定当前章节成片；章节重新合成后确认失效。
4. **合成**：封面硬切前置，章节间可选硬切或 0.5 秒淡化。合成后自动校验时长、分辨率、帧率、音轨。

```bash
python entrypoints/compose_book.py novel_output/<项目> --check
python entrypoints/compose_book.py novel_output/<项目> --confirm "已审看"
python entrypoints/compose_book.py novel_output/<项目> --transition fade
python entrypoints/compose_book.py novel_output/<项目> --no-cover
```

## 9. G4 / G5 挡位（Phase 4）

| 挡位 | 行为 |
|---|---|
| G4 托管 | 与 G3 相同的自动检查点；章节失败后收紧口播块上限并重规划，最多 1 次 |
| G5 不停机 | 与 G3 相同；章节失败后重置失败阶段重试，最多 3 次 |

G4 和 G5 都必须设置预算上限。全书合成在所有挡位下都需要人工确认。

## 10. 真实 API 冒烟（Phase 5，需本机执行）

投入整章生成前，先用最小花费确认接口可用：

```bash
# Windows PowerShell
$env:AGNES_API_KEYS="key1,key2"
# macOS / Linux
export AGNES_API_KEYS="key1,key2"

cd external_projects/novel_to_video
python entrypoints/smoke_real_api.py --out smoke_out
```

脚本生成一张定妆图与一个 4 秒镜头，逐步输出结果。全部通过退出码为 0。若失败，把 JSON 输出（不含 key）反馈即可定位问题。仅测图像：加 `--skip-video`。

## 11. 崩溃与恢复

- 队列运行时会在项目目录写入 `.runlock`。正常结束会删除该文件。
- 若进程被强制结束，遗留的锁会在下次运行时被识别并回收（持有进程已退出，或心跳超过 5 分钟）。
- 遗留的 `running` 章节会回退到稳定状态（已有成片则为 done，有待审镜头则为 waiting_review，否则为 pending），之后可直接重新运行。
- 同一项目不能被两个进程同时运行，第二个会收到“项目正在运行”的提示。

## 12. 性别确认（Phase 5 补充）

导出包的角色档案通常不写性别。系统的处理方式：

1. 「⚧ 性别确认」页点击“重新检索线索”，系统在人设卡与全部正文中检索含角色名的句子；
2. 每个角色展示建议（只有人设卡明确写出性别时才给出）、依据与证据（章节号与原句）；
3. 证据中的代词与亲属词未必指向该角色，请逐条判断，再选择男 / 女 / 无法确定并确认；
4. 确认后写入角色，来源记为 user，并追加到 PROGRESS.md。未确认的角色不能通过素材门禁。

## 13. 转义导出

若导出包的目录名或文件名显示为 `#U5c0f` 之类的转义文本，创建项目时会自动在 `source/normalized/` 生成中文名副本，之后所有读取都使用该副本。原始导出目录不会被修改。

## 14. 驾驶舱

启动后默认进入「🧭 驾驶舱」，可以看到：

- **顶部指标**：当前步骤、章节进度、待你处理数量、失败镜头数、挡位与预算用量；
- **下一步提示**：按优先级给出当前应处理的步骤，并标明在哪个页面处理；
- **实时运行**：点击「开始运行队列」后在后台运行，面板每 3 秒刷新，显示当前章节与运行记录；
- **停止**：「请求停止」后，正在运行的章节会完整跑完，下一章开始前停止；
- **章节流水线**与**检查点清单**：每章的状态、镜头通过情况，以及性别确认、素材、全书合成等关卡。

运行状态保存在项目的 `logs/runtime.json`。

## 15. 实时日志

素材生成、章节运行、全书合成、封面、性别检索都在后台运行，并在页面下方显示实时日志：

- 每条日志包含时间、级别（✔ 完成、⚠ 提示、✘ 失败）与内容，例如 `G-3 生成定妆图：林远（character，char_001）`；
- 日志保存在项目的 `logs/job.jsonl`，关闭页面后仍可回看；
- 任务运行中可点击「请求停止」，当前实体或步骤完成后停止；
- 同一项目同一时间只能运行一个任务（素材、章节队列、合成共用），冲突时会提示“项目正在运行”。

## 16. API key 配置（图像与视频）

图像（G-3 定妆图）与视频（C-8 小场景）通过 mini_agent 的 Agnes skill 调用，key 由 skill 自动解析，无需在本项目中额外设置。

在 mini_agent 项目根目录放置 `providers.json`（可从 `providers.agnes.example` 复制），任选一种写法：

```json
{ "providers": { "agnes": { "api_keys": ["key1", "key2"], "key_rotation": "round_robin", "key_cooldown": 60 } } }
```

或在 `llm_fallback_chain` 中配置 `provider` 为 `agnes` 的条目的 `api_keys`。

优先级：环境变量 `AGNES_API_KEYS`（逗号分隔）→ `providers.json` → 环境变量 `AGNES_API_KEY`。

若提示“未找到可用的 Agnes API key”，错误信息会列出实际检查过的位置，并给出找到的 providers.json 路径或说明未找到。

## 17. 运行信息与命令行

图像与视频生成的过程信息（请求档位、重试、失败原因、接口耗时、视频轮询）同时写入界面的运行日志和命令行。若生成失败，可以直接在日志中看到原因，例如“不可重试错误 status_code=401”，无需查看命令行。

## 18. 章节运行日志

运行章节（单章或全部）时，章节页下方的“章节运行日志”会按步骤显示：

- 文本模型调用：剧本、镜头规划、补建角色，包括输入字数与耗时；
- 每个镜头的视频生成：提交时长与参考图数量，完成或失败（失败会显示原因）；
- 每段配音的音色、字数与时长；
- 面板顶部显示当前运行的章节与阶段，运行中可请求停止（当前章节完成后停止）。
