# 章节字数控制技能（Word Count Controller）

## 职责

确保每章的实际字数与规划字数匹配，避免"写到哪算哪"导致的篇幅失控。同时在字数偏差时给出可操作的调整方案，而不只是报告数字。

---

## 核心操作

### 1. 章前配额下发

`chapter-writer` 开始写作前调用，返回本章的详细字数指令：

```
📏 第[n]章字数配额

总目标：4,500 字（容忍区间：3,825 – 5,175，±15%）
剩余全书配额：257,200 字 / 还剩 32 章

本章场景分配建议：
  ├─ 开场定向（环境+人物到位）   400 字
  ├─ 场景一：考核对战            1,800 字  ← 动作场景，短句为主
  ├─ 场景二：晋升仪式+师傅异样   1,600 字  ← 对话+心理
  └─ 结尾钩子                    300 字
     小计：4,100 字（核心）+ 400 字弹性空间

⚠️ 注意：上一章超出 420 字，本章请控制在 4,500 字以内消化偏差。
```

### 2. 实时字数检查

写作中途可调用，返回当前进度提示：

```
当前已写：2,340 字 / 目标 4,500 字
已完成：52%
剩余配额：2,160 字

已完成场景：开场 ✓ · 场景一 ✓
待写场景：场景二（预估 1,600 字）+ 钩子（300 字）= 1,900 字
→ 剩余配额与待写量基本匹配，按计划继续。
```

### 3. 章后字数核算

章节完成后调用，更新档案并输出偏差处理方案：

**情况 A：轻微偏差（±15% 以内）→ 正常**
```
✅ 第[n]章完成
实际：4,620 字 / 目标 4,500 字（+2.7%）
状态：正常，无需调整
全书进度：42,800 / 300,000（14.3%）
```

**情况 B：中度超出（+15% ~ +40%）→ 就地消化**
```
⚠️ 第[n]章超出
实际：6,800 字 / 目标 5,000 字（+36%）
超出量：1,800 字

消化方案（自动计算）：
  方案一：将超出量分摊到后续 3 章
    第[n+1]章：4,200 → 3,600 字（-600）
    第[n+2]章：4,200 → 3,600 字（-600）
    第[n+3]章：4,500 → 3,900 字（-600）
  
  方案二：压缩当前章节（推荐）
    本章可压缩区域：
    · 第3段环境描写（约400字）→ 精简为100字
    · 内门弟子晋升仪式细节（约600字）→ 保留核心动作，删去铺陈
    · 师傅回房后的独白（约800字）→ 移至下章作为开场，增加悬念

推荐：方案二（就地压缩），原因：下两章均为高密度情节章，减少配额会影响质量。
```

**情况 C：严重超出（>+40%）→ 拆章**
```
🔴 第[n]章严重超出
实际：9,200 字 / 目标 5,000 字（+84%）

建议拆分为两章：
  新第[n]章（4,500字）：保留至考核结束
  新第[n+1]章（4,700字）：从晋升仪式开始
  
拆分点建议：第4场景"李凌云走出考核场"——天然的场景切换点
影响：原第[n+1]章编号后移，需通知 novel-planner 更新章节列表
```

**情况 D：字数不足（< -15%）→ 扩写建议**
```
⚠️ 第[n]章字数不足
实际：2,800 字 / 目标 4,500 字（-38%）

可扩写方向：
  · 场景一"对战"过于简略（当前800字）
    → 补充：对手的技法细节 / 李凌云的应对心理 / 周围观众的反应
    → 预计可扩充至 1,600 字（+800字）
    
  · 晋升仪式缺少仪式感（当前300字）
    → 补充：门派传统细节 / 其他弟子的反应 / 李凌云的内心感受
    → 预计可扩充至 700 字（+400字）
    
  · 结尾钩子力度弱（当前200字）
    → 补充：师傅表情的细节描写 / 李凌云的疑惑感
    → 预计可扩充至 500 字（+300字）

预计扩写后总字数：4,500 字，达标。
```

## 场景级字数分配

写作复杂章节时，可先做场景级拆分再写作：

```
场景分配工具：
输入：章节总目标 5,000 字，场景清单 [场景A, B, C, D]

输出建议：
  场景A（动作）：1,500 字 — 30%
  场景B（对话）：1,200 字 — 24%
  场景C（心理）：  800 字 — 16%
  场景D（高潮）：1,200 字 — 24%
  场景E（钩子）：  300 字 —  6%
  合计：5,000 字

弹性说明：
  高潮场景（D）可上浮至 1,800 字，从场景C压缩至 500 字补偿
```

### 各类场景的字数参考

| 场景类型 | 最小 | 标准 | 最大 | 备注 |
|---------|------|------|------|------|
| 开场定向 | 200 | 400 | 600 | 过长则拖沓 |
| 普通动作 | 600 | 1200 | 2000 | 视复杂度 |
| 重要战斗 | 1500 | 2500 | 4000 | 高潮战斗可放宽 |
| 日常对话 | 500 | 900 | 1500 | 超过即冗长 |
| 重要对话 | 800 | 1400 | 2200 | 含场景描写 |
| 心理描写 | 300 | 600 | 1000 | 宜精简 |
| 环境描写 | 100 | 300 | 600 | 独立段落上限 |
| 章末钩子 | 100 | 300 | 500 | 精简有力 |

```

整体进度
  已写：82,400 字 / 规划：80,000 字（+3%）✅

各幕配额剩余
  第一幕：完成，实际超出 2,400 字（已在幕内消化）
  第二幕：剩余配额 160,000 字（未开始）
  第三幕：剩余配额 60,000 字（未开始）

章节偏差分布
  严重超出（>+40%）：0 章
  中度超出（+15~40%）：2 章（已消化）
  轻微偏差（±15%）：8 章 ✅
  字数不足（<-15%）：0 章

节奏密度评估
  平均章节字数：8,240 字（规划均值：8,000 字）✅
  最长章节：第7章 11,200 字（高潮章，合理）
  最短章节：第3章 3,800 字（过渡章，合理）
  
预警
  ⚠️ 第二幕规划了 20 章 × 均值 8,000 字 = 160,000 字
     但目前第二幕场景清单估算约需 185,000 字

```

## 压缩与扩写的黄金法则

### 压缩优先级（从高到低删减）
1. 重复的情绪描写（同一情绪出现两次以上）
2. 冗余的环境铺陈（超过600字的连续环境描写）
3. 过度解释性对白（角色解释读者已知的信息）
4. 低信息密度的过渡段落
5. 次要角色的多余反应描写

### 扩写优先级（从高到低添加）
1. 高潮/冲突场景的慢镜头细节
2. 关键人物决策时的心理过程
3. 伏笔埋设的铺垫厚度
4. 重要关系的情感互动细节
5. 标志性场景的环境氛围

## 与其他模块交接

- **接收来源**：novel-planner（各章字数规划）、chapter-writer（实际产出字数）
- **输出给**：chapter-writer（写作前配额指令 + 实时字数提示）
- **通知**：novel-planner（章节拆分/合并时需更新蓝图）、memory-manager（字数档案变更）

## 文件管理

所有文件保存到工作目录（{WORKSPACE}）：

- 字数档案：`{WORKSPACE}/大纲规划/其他设定/word_count.json`
- 字数偏差报告：`{WORKSPACE}/大纲规划/其他设定/word_count_log.md`（每次偏差超过±15%时追加记录）
