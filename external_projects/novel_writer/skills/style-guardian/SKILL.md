# 风格守护技能（Style Guardian）

## 职责

让全书"读起来像同一个人写的"。建立风格指纹、区分有意调整和有害漂移、守护整部作品的语言统一性。

---

## 风格指纹建立（两种模式）

### 模式 A：从参考文本提取（推荐）
用户提供参考作品片段（500字以上），提取：句长分布、段落长度、高频句式结构、动词密度、对话归因方式、情绪处理方式（直陈vs行为映射）、环境描写密度。

### 模式 B：从已写章节提取
**触发条件**：用户确认前3章质量满意后手动触发——不自动建立。
原因：若前3章质量不佳，会建立错误的基准。

## 核心操作

### 1. 写作前风格提示

```
风格提示（第n章）
叙事视角：第三人称有限，跟随李凌云
当前幕次基调：[act_level_tones 对应值]
chapter_type：conflict → 短句为主，节奏紧张

本章避免的高频词（累计过多）：
  "须臾"（前5章用6次，本章暂停）
  "沉声道"（前3章用5次，换其他动作替代）

本章推荐签名技法：
  细节慢镜头（适合战斗高潮）
  环境映心（结尾情感钩子）
```

### 2. 写作后风格检查

```
风格检验报告：第n章

🔴 风格问题（需修改）：
  "不禁"出现3次（禁用词）→ 替换为具体行为

🟡 风格漂移提醒：
  叙事距离偏近（偏向第一人称感）→ 略微后退
  "说"字出现12次 → 至少4处换为动作归因

🔵 高频词提醒：
  "刹那"：本章第3次，总计9次（开始偏高，下章注意）

✅ 风格优点（记录为范本）：
  第4段战斗分镜张力十足（ch_009_p4）
```

### 3. 幕间风格对比（新增，幕末触发）

区分"有意调整"和"有害漂移"：

```
幕间风格对比：第一幕 → 第二幕

有意调整（符合 act_level_tones）：
  ✅ 平均句长从18字→15字（第二幕紧张化，符合规划）

可能有害的漂移：
  ⚠️ 环境描写密度从每章3处→每章1.2处（下降过多）
  ⚠️ 对话中"说"字占比从35%→58%（上升过快）

结论：整体方向正确，建议保留适当环境描写密度
```

### 4. 跨章高频词统计（每5章）

```
过度高频（下5章须减少）：
  "须臾"：前10章共11次（阈值：每10章≤6次）
  "沉声"：前10章共9次（阈值：每10章≤5次）
```

### 5. 多视角风格分化

每个视角建立语言差异标记：
- 视角A（主角）：内向型词汇，关注内心冲突和身边细节
- 视角B（配角）：外向型词汇，关注人际关系和宏观格局
