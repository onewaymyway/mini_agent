# 世界构建技能（World Builder）

## 职责

建立并维护一个自洽的虚构世界。确保世界规则在整部小说中保持一致，设定服务于故事而不成为负担。

**本次改进**：新增设定使用率追踪（防止冗余设定积累）；新增"按需扩展"工作流（何时扩展、扩展时如何检查冲突）。

## 设定使用率追踪（新增）

每个设定条目都记录 `use_count`（被正文引用次数）和 `last_used_chapter`（最后出现章节）。

### 使用率统计操作

每章写完后，将本章涉及的地点/规则/历史更新 use_count：

```
更新触发：chapter-writer 完成一章，写作备注中列出引用的设定条目
更新字段：use_count +1，last_used_chapter = 当前章节号
```

### 冗余设定巡检（每幕结束触发）

```
🗂️ 设定使用率报告（截至第n章）

📦 从未使用的设定（use_count = 0）：
  - 历史事件："远古三皇之乱"（建立时间：第1章前，从未出现在正文）
  - 地点："南陆·火云城"（建立但从未有角色前往）
  建议：评估是否需要删除或整合到现有情节

⚠️ 长期未使用的设定（距最后使用已超20%进度）：
  - 规则："血月现象导致灵气紊乱"（最后使用于第3章，当前第18章）
  建议：在后续章节安排一次自然引用，或标记为"背景设定不需要再出现"

✅ 活跃使用的核心设定：
  - 炼气术境界体系：use_count=28（每章都在使用）
  - 青云宗地点：use_count=15
  - 灵石经济体系：use_count=8
```

## 按需扩展工作流（新增）

**核心原则**：设定不要一次设计完，按写作需要逐步扩展，每次扩展都检查冲突。

### 何时扩展设定

以下情况触发设定扩展：

```
触发一：chapter-writer 在写作过程中遇到"这里需要一个设定但没有"
        示例：第12章角色要去一个新城市，但 world_bible 里没有这个地方

触发二：consistency-checker 发现"使用了未定义的设定"
        示例：正文出现了"炼气期以上可以使用护体真气"，但 world_bible 未记录此规则

触发三：plot-simulator 推演时发现"现有设定限制了更好的情节"
        示例：旅行速度设定导致某个情节时间上无法成立
```

### 扩展前冲突检查

新增任何设定前，执行以下检查：

```
新设定：炼气期修士可以通过特殊功法提前突破，无需机缘

冲突检查：
  □ 与已有 hard_rules 是否冲突？
    hard_rules 记录："境界突破需要机缘，不可强行拔苗助长"
    → 冲突！新设定与现有规则矛盾
    
  解决方案（三选一）：
    A. 放弃新设定（维持现有规则）
    B. 修改新设定（改为：某种极稀有的功法可以作为"机缘"，本质上还是需要机缘）
    C. 修改现有规则（需要通知 consistency-checker 重新校验之前所有依赖此规则的章节）
```

### 设定扩展记录格式

```
扩展记录：
时间：第12章写作前
内容：新增地点 loc_008 "血月城"
触发原因：第12章需要一个中立城市作为对手的秘密据点
冲突检查：与现有设定无冲突
关联设定：位于东陆边境，靠近 loc_001 青云宗辖区，旅行时间3天
```

## 核心操作

### 设定查询（chapter-writer 调用）

```
GET location [loc_id] → 返回地点详情（含重要规则）
GET power_rules [realm] → 返回该境界的能力范围
GET travel_time [from] [to] [character_level] → 计算旅行时间
GET faction [fac_id] → 返回势力当前状态
```

### 世界规则自洽性检查

```
⚠️ 世界设定冲突
章节n描述：李凌云从青云宗飞到血月城，仅用了半天
记录数据：炼气期御器飞行速度=每日千里；两地距离=3000里
计算结果：最少需要3天
建议：修改为传送阵传送，或修改旅行时间
```

## 规则体系设计原则

**力量体系三要素**：代价（使用有什么消耗）· 限制（什么情况下失效）· 例外（谁/什么情况可打破）

**设定增量原则**：不要在初期设计大量用不到的细节；每次扩展检查冲突；重要规则更改记录变更日志。
