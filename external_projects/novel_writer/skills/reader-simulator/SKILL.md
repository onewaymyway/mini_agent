# 读者体验模拟技能（Reader Experience Simulator）

## 职责

从读者视角而非作者视角审视内容——作者知道的太多，容易高估读者的理解和投入程度。本技能模拟目标读者的真实阅读体验，发现作者视角的盲区。

---

## 读者画像设定

使用前，先确认目标读者类型（来自 novel-planner 的 platform/读者字段）：

| 读者类型 | 注意力阈值 | 容忍空洞段落 | 期待节奏 | 情感代入门槛 |
|---------|-----------|------------|---------|------------|
| 网文重度读者 | 极低（<300字无钩子就放弃）| 极低 | 快，每章有小爽点 | 低（快速代入）|
| 网文轻度读者 | 低（第一章无吸引力放弃）| 低 | 中快 | 中 |
| 出版文学读者 | 中（允许慢热）| 中 | 中慢 | 较高（需要时间建立连接）|
| 严肃文学读者 | 高（重视语言本身）| 高 | 慢 | 高（情感共鸣要真实）|

## 模拟维度

### 1. 注意力曲线模拟

逐段分析读者的注意力水平：

```
输入：章节文本
输出：
  段落1-3   注意力：高（开篇）
  段落4-7   注意力：中高（跟进）
  段落8-12  注意力：中（警报：连续描写，无事件）← 危险区
  段落13    注意力：骤升（冲突出现）
  段落14-16 注意力：高（高潮）
  段落17-18 注意力：中高（余波）
  段落19    注意力：高（钩子）

危险区诊断：段落8-12，连续5段无新信息/事件/情绪变化
            读者流失风险：中等
            修复建议：在第9段插入一个小冲突或新信息，打破平静
```

### 2. 理解度模拟

检测读者可能产生困惑的位置：

```
困惑类型：
  信息跳跃   前文没有铺垫，突然引入新概念/新角色/新地点
  时间跳跃   没有明确说明时间变化，读者可能以为还在同一时刻
  视角混乱   一段内叙事视角在不同人物之间切换
  代词模糊   "他"指代不明确，两个男性角色在场时容易混淆
  世界规则   使用了世界设定中的专有名词但未解释（对新读者不友好）
```

### 3. 情感连接度模拟

评估读者是否与主角产生情感共鸣：

```
情感连接检查项：
  □ 主角的核心欲望在本章是否有清晰的感知？
  □ 主角面临的困境，读者是否能代入理解？
  □ 情感高峰时，读者是否有足够的前置情绪积累？
  □ 主角的关键决策，读者是否能理解其内在逻辑？
  □ 章末的情感状态，读者是否能感受到？

情感失联风险信号：
  - 主角做出读者无法理解的选择（动机不足）
  - 情感高峰来得太快（情绪蓄积不足，打动不了读者）
  - 大量内心独白但情感是被"告知"而非被"感受"
```

### 4. 可信度模拟

检测哪些情节/角色行为会让读者感到"假"：

```
可信度风险点：
  巧合过多     关键情节依赖多重巧合推进
  决策失智     角色明知A选择更优，却选了B（动机不足）
  胜利太容易   主角几乎没有代价就赢了（削减了张力）
  情感转变太快  前一章还是敌人，这章就成了朋友（关系跳跃）
  世界规则破例  例外情况没有合理解释，显得主角"天选之人"
  对话过于"有用" 每句台词都恰好包含读者需要的信息（太刻意）
```

### 5. 节奏感知模拟

从读者感知层面评估节奏，而非作者层面的计划节奏：

```
读者的节奏感知由以下决定（不是章节字数）：
  信息密度   每500字内有多少新信息/事件/发现
  情绪起伏   情绪的高低变化频率
  段落视觉节奏  长短段落交替产生的视觉节奏

节奏问题诊断：
  "感觉很慢" → 通常是信息密度低，不是字数多
  "感觉很快但记不住" → 信息密度高但情绪没有落点
  "一口气读完但空洞" → 事件多但人物情感缺失
```

## 读者认知状态快照

在特定章节节点，模拟"只读到这里的读者"的认知状态：

```
读者认知快照：截至第n章

已知信息（读者视角）：
  确认知道的：李凌云有混沌根骨（第8章明确展示）
  猜测到的：王道长认识其父亲（读者意识到了，但未确认）
  完全不知道：身世全貌，神器来历

当前期待（读者最想看到的）：
  强烈期待：王道长和父亲关系的真相
  中等期待：李凌云和对手的再次交锋
  轻微期待：内门生活的展示

担忧（读者最不想发生的）：
  不希望：王道长是坏人
  担心：主角会一直隐忍不爆发

未回答的疑问（读者心里的问题）：
  ① 师傅到底认不认识父亲？
  ② 左手伤疤是怎么来的？
  ③ 对手为什么那么针对主角？

风险评估：
  如果第n+1章没有回应"王道长与父亲的关系"这个读者最强期待
  流失风险：中等（读者会继续，但满足感下降）
```

## 模拟报告格式

```
读者体验报告：第n章《章名》

目标读者类型：网文轻度读者

注意力曲线：
  最强吸引段：段落13-16（战斗场景）
  危险区：段落8-12（连续铺垫，无事件，流失风险：中）

理解度问题（2处）：
  ① 第5段：突然出现"血月城"，前文未曾提及，读者不知道是什么地方
     修复：加一句地理/背景说明（或在对话中自然带出）
  ② 第14段：代词"他"指代不明，王道长和李凌云同在场，容易混淆
     修复：将其中一个"他"改为角色名

情感连接评估：中等
  亮点：主角在考核时的内心挣扎写得真实，读者能代入
  薄弱：章末的情感钩子（王道长的神情）描写太简短，分量不足
       建议：扩展3-4句，给读者时间感受到这个时刻的重量

可信度风险（1处）：
  第16段：主角一招击败三人太过顺利，缺乏代价
  建议：让主角付出一个小代价（受轻伤/消耗大量内力），结果相同但合理性提升

节奏评估：前半慢 → 后半快 → 收尾偏急
  建议：将章末最后两段扩展，给"余波"更多空间，不要冲动结束

综合建议：修复2处理解度问题 + 扩展章末余波，预计读者满意度显著提升
```

## 与其他模块交接

- 调用时机：chapter-writer 完成一章后（可选）· consistency-checker 校验后 · revision-editor 诊断时
- 依赖：novel-planner（读者类型/主题）· plot-tracker（读者应知道哪些信息）
- 输出：体验报告，反馈给 revision-editor 或直接给 chapter-writer 参考
- 深度模拟时：与 plot-simulator 的"读者认知模拟"功能互补（本技能更细粒度）
