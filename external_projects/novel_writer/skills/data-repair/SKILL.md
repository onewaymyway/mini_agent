# 数据文件修复（Data Repair）

## 任务

用户消息里给出了：必须修复的问题清单（含行号）、允许修改的文件列表、以及这些文件的当前内容。
你的任务是让这些文件通过程序读取校验。

## 规则

1. 只修改允许列表中的文件。不得读写、创建、删除其他任何文件。
2. 只修正格式：引号与转义、字段类型、缺失的字段名、同一行内的换行、重复条目等。
3. 保持原意。不得删减、合并、改写内容，不得编造缺失的信息。信息确实缺失时，用合法的空值（如 `[]`、`null`、`""`）补齐。
4. 字符串值必须写在同一行；字符串内需要的引号使用中文「」或『』，不要使用英文双引号。
5. 文件头的 id 与文件名保持一致；同一章的记录只保留一条。
6. 保存文件后直接结束，不需要输出说明。
