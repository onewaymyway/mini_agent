# 对话专项创作技能（Dialogue Crafter）

## 职责

专门处理"重要对话场景"——让每句台词同时完成多项叙事任务，让对话有层次、有温度、有辨识度。新增冲突对话和群体对话两个专项模块。

---

## 对话的四个层次

写任何重要对话前，先确认覆盖了哪几层：

```
第一层  表层内容    角色实际说的话（字面意思）
第二层  潜台词      没说出口但双方都明白的真实意思
第三层  信息功能    向读者传递了什么新信息
第四层  关系功能    如何改变了两人的关系状态
```

好的对话至少覆盖三个层次。只有第一层是"填字数"。

---

## 每句台词的任务清单

重要台词应同时完成至少两项：

```
□ 推进情节（事情往前走了）
□ 揭示人物性格（只有这个人才会这样说）
□ 传递信息（读者知道了某件事）
□ 制造/缓解冲突（关系张力变化）
□ 埋设/推进伏笔
□ 显示权力关系（谁主导这段对话）
□ 体现潜台词（说A意B）
```

## 模块一：常规对话

### 对话节奏

| 场景 | 密度 | 说明 |
|------|------|------|
| 审讯/对峙 | 高密度 | 一来一往短句，张力来自节奏 |
| 谈判/博弈 | 中密度 | 台词之间有动作/停顿，计算感 |
| 情感倾诉 | 低密度 | 台词之间大量留白和心理描写 |
| 揭秘/摊牌 | 先低后高 | 铺垫慢，揭示时节奏骤快 |

**加速**：缩短台词字数 · 减少动作归因 · 用破折号打断  
**减速**：台词之间插入动作/环境/心理 · 一方长时间沉默 · 短回答打破长铺垫

### 语言差异化

从 character-manager 的 speech_pattern 提取每个角色的语言指纹：

```
用词倾向     简洁/华丽/口语/书面/特殊词汇偏好
句长偏好     短句/长句/变化型
情绪表达     直接型/迂回型/行动型
标志句式     口头禅/标志性表达
禁区         某类词绝对不会说
```

**检验**：遮住所有角色名，只读台词——能分辨出谁在说话吗？不能则差异化不足。

### 潜台词写法

**说A意B型**

```
场景：A想质问B是否知道父亲秘密，但不能直说

差的写法：
  "你认识我父亲，你在隐瞒什么？"

好的写法：
  A沉默片刻，然后：
  "师傅，您见过很多弟子吧。"
  王道长停顿了一下："见过一些。"
  "那您还记得每个人吗？"
  茶杯轻轻放下的声音，比任何回答都更清楚。
```

**回避型**：一方问了，另一方回答了另一个问题——这本身就是一种回答。  
**过度回应型**：对小问题反应过度，说明触碰到了要害。  
**共识型**：两人说着不相关的话，但两人都知道在说另一件事。

### 对话归因多样化

```
动作归因（推荐）：
  他放下茶杯："……"
  她转过身："……"
  王道长盯着他看了许久，才开口："……"

情绪归因（次之）：
  他冷声道："……"（不要滥用冷/轻/淡等修饰）

省略归因（高级，连续不超过4-5句）：
  连续交锋时完全省略，靠内容让读者自行对应
```

### 完整对话场景结构

```
① 定场（1-3句）：交代空间/时间/物理状态；选一个服务情绪的场景细节
② 入题（逐步）：1-2句看似无关的话热场，建立对话基调
③ 核心交锋：最重要的话；核心句前放慢节奏增加分量
④ 余波（不能省略）：双方的情绪反应——沉默/动作/离开
⑤ 章末处理：1-2句内心独白，让读者明白这段对话对主角意味着什么
```

## 模块二：冲突对话（新增）

**冲突对话**指吵架、质问、摊牌、指控等情绪激烈的场景。写法与普通对话有本质区别。

### 冲突对话的核心特征

情绪在控制与失控之间摇摆。这个摇摆本身就是戏剧张力的来源：

```
控制期：角色还在用语言博弈，话语精准，每句话都有意图
失控期：情绪突破语言，出现意料之外的话（说了不该说的）
         或沉默（不能/不愿再说了）
恢复期：一方率先收住（或被打断），局势重新设定
```

### 冲突升级的三个波次

好的冲突对话不是一直拉满，而是有波次：

```
第一波：试探与防守
  双方都在评估边界，话有锋芒但没有直刺要害

第二波：突破
  有一方说出了真正的指控或真正的痛点
  这句话会让另一方有明显的反应（不是继续辩论，是被击中）

第三波：收场（不是解决）
  冲突通常不在对话里解决，而是以某种方式终止：
  一方离开 / 被打断 / 沉默 / 说出了自己也没预料的话
```

### 高压下的语言变形

不同性格的角色在高压下语言会产生特定变形：

| 性格类型 | 高压下的语言变化 |
|---------|----------------|
| 平时话少、内敛 | 突然多话，说出平时不说的话；或完全沉默 |
| 平时强势、主导 | 更粗暴直接，失去平时的精准；或反而变得极度冷静（冻结状态）|
| 平时温和、迁就 | 在某个临界点突然爆发，说出积压已久的话；声音反而变小而不是变大 |
| 平时理性、分析型 | 开始重复同一个论点；或拒绝听对方说话 |

**使用方法**：从 character-manager 的 stress_response 字段获取该角色高压下的变化，据此设计冲突对话中的语言变形。

### 不能说出口的话

冲突对话里最有力量的往往是没说出来的话：

```
场景设计方法：
  确定"A最想说但不能/不敢/不愿说的是什么"
  用这句话的缺席来组织整个对话——
  读者能感受到那句话的存在，即使它从未出现

实例：
  A最想说：你当初为什么抛下我？
  实际对话：绕着这个问题的所有话，唯独不问这一句
  效果：比直接问更有力量
```

### 冲突对话的出口设计

冲突怎么结束，决定了读者看完的情感状态：

| 出口类型 | 情感效果 | 适用情况 |
|---------|---------|---------|
| 一方离开（未解决）| 悬而未决，紧张感延续 | 关系冲突，下章继续 |
| 外部打断 | 紧张感转移，矛盾暂存 | 需要推进情节时 |
| 一方说出意外的话 | 认知震动，关系重定义 | 重要转折章 |
| 沉默收场 | 余韵悠长，读者填补空白 | 情感深层冲突 |
| 表面和解（实际未解决）| 压抑感，读者知道还会爆发 | 积压型矛盾 |

## 模块三：群体对话（新增）

**群体对话**指三人及以上同时在场的对话场景。

### 群体对话的核心挑战

**挑战一：读者搞不清谁在说话**

```
解决原则：
  每位角色的台词前后至少每隔3-4句就出现一次明确标识
  （角色名、动作归因、或极具辨识度的说话方式）
  
  不要让三个人连续说话，中间没有任何标识
```

**挑战二：沉默的角色消失了**

没有说话不等于不存在。沉默角色的存在感通过：

```
动作：王道长一直在整理茶具，没有参与对话
反应：李凌云说完那句话，对手的表情微微变了
视线：她说话时，眼神不经意瞟向角落里一直沉默的老人
```

**挑战三：每个人都在说，但对话没有去向**

群体对话必须有一个"核心轴"——这场对话在各方之间产生的核心张力：

```
确定方法：
  在写作前回答：这场对话结束后，三人之间的权力关系/信息状态发生了什么变化？
  如果回答是"没变化"，说明这场对话还没设计好
```

### 群体对话的站位设计

每个人在这场对话里的"位置"：

```
主导者    掌控对话节奏和走向的人（不一定是权力最高的）
挑战者    打破或质疑主导者设定框架的人
观察者    少说话、多观察，但在关键时刻一句话改变走向
调停者    试图缓和紧张局势（但未必成功）
```

**使用方法**：三人以上在场时，先分配"站位"，再设计台词。

### 分配发言权

```
高权力角色说话少，但每句话分量重
低权力角色说话多，但容易被打断或忽视
局外人偶尔一句，往往击中要害（因为他们看得最清楚）
```

### 群体对话中的双线结构

高级技法：表层对话 + 暗线对话同时进行：

```
示例场景：三人在场，A和B有未解决的矛盾，C不知道

表层对话：A、B、C 在讨论明日的行程
暗线对话：A和B在每句话里都在进行另一场没有C参与的博弈

设计方法：
  先写暗线对话（A和B之间真正在说什么），
  再把它"翻译"成表层对话（三个人名义上在讨论的话题）
  让A和B的每句表层话都在暗线里有第二层含义
```

## 常见对话问题诊断

| 症状 | 根本原因 | 修复 |
|------|---------|------|
| 读起来像背台词 | 缺少节奏变化，句子等长 | 加入停顿、打断、不对称回应 |
| 所有人说话方式一样 | 没有基于性格设计语言指纹 | 回到 character-manager 提取特征 |
| 冲突对话没有张力 | 情绪一直拉满没有波次 | 设计三波次，第二波才到临界点 |
| 群体对话混乱 | 缺少明确标识 + 沉默角色消失 | 每3-4句标识一次；给沉默角色安排动作 |
| 对话结束什么都没发生 | 没有改变任何状态 | 至少选一项任务（情节/关系/信息）|
| 对话感觉假 | 台词服务叙事而非角色逻辑 | 先想"这个人会怎么说"，再想如何传递信息 |
