# 人设创作技能（Character Designer）

## 职责

从无到有设计一个"真实存在感"的角色。不只是填写属性表，而是建立角色的内在宇宙——他为什么成为这样的人、他的矛盾从哪里来、读者为什么会记住他。

本技能专注于**创作阶段**，与 `character-manager`（追踪管理阶段）分工明确：先用本技能把人设想清楚，再由 character-manager 负责后续的状态追踪。

---

## 人设创作的核心理念

### 好人设的三个标准

**1. 有伤口（Wound）**
每个令人难忘的角色背后都有一个塑造性创伤或核心缺失——不一定是悲剧，但必须是真实的。这个伤口决定了角色的核心恐惧，进而驱动所有行为。

**2. 有矛盾（Contradiction）**
真实的人是矛盾的。角色的魅力往往来自内部张力：表面冷漠内心渴望被认可、口称不在乎却处处在意、强大外壳包裹着脆弱内核。没有矛盾的人设是平的。

**3. 有逻辑（Logic）**
角色的所有行为都必须能从其性格、经历、欲望中自然推导出来。读者可以不同意角色的选择，但必须能理解"为什么他会这样做"。

## 人设设计流程

### 阶段一：确定角色定位

在深入设计前先确认：

```
角色类型：主角 / 重要配角 / 功能配角 / 反派 / 对立面
在故事中的功能：推进情节 / 衬托主角 / 代表主题 / 制造冲突 / 情感锚点
与主角的关系：盟友 / 对立 / 镜像 / 导师 / 羁绊
设计深度需求：完整人设（主要角色）/ 中等深度（重要配角）/ 功能性设计（次要角色）
```

> **镜像角色**：与主角共享相似的起点或欲望，但走向了不同的道路——这类角色往往是最能揭示主题的存在。

---

### 阶段二：挖掘心理底层

这是人设最核心、最容易被跳过的部分。

#### 欲望-恐惧模型

```
表层欲望（Want）：角色说自己想要的 / 外部目标
深层欲望（Need）：角色真正需要的 / 内在缺失
核心恐惧（Fear）：最不能接受的结果
塑造性伤口（Wound）：导致以上一切的根源经历
```

示例：
```
表层欲望：成为最强的剑客
深层欲望：被父亲认可，证明自己有价值
核心恐惧：自己是个平庸之人，终究无法被爱
塑造性伤口：幼年时父亲当众否定他的天赋，说他"没有修炼的资质"
```

这四层之间的张力，就是驱动整个角色弧线的引擎。

#### 信念系统

```
核心信念（角色认为世界是怎样运作的）：
  正面信念："只要足够努力，一切皆可改变"
  扭曲信念（伤口导致的错误认知）："只有强大才值得被爱"

道德底线（绝不会做的事）：
行事原则（通常会怎么做）：
```

---

### 阶段三：构建外在表现

心理底层决定外在表现，**从内到外**设计，不要反过来。

#### 外形设计

外形要"说话"——每个细节应服务于性格或故事：

```
整体气质（第一眼印象）：
标志性特征（1-2个让读者记住的细节）：
  好的示例："右眉有道细疤，笑时会消失" / "习惯把袖子卷到肘部"
  差的示例："高挑、黑发、英俊"（泛化，无辨识度）
  
着装风格（反映身份/性格/过去）：
体态习惯（站姿、走路方式、惯用小动作）：
```

> **标志性细节原则**：一个好的外形细节能在第一次出现时就埋下性格信息，在后续章节重复出现时唤起读者记忆，在关键时刻被赋予新的含义。

#### 语言与行为模式

```
说话方式：
  用词倾向（简洁/华丽/口语/书面）：
  语速节奏（快/慢/跳跃/停顿多）：
  标志性口头禅或句式：
  情绪激动时的变化：
  
行为习惯：
  压力下的应激反应：
  独处时的状态：
  对待不同人的态度差异（权威/平辈/弱势者）：
  
决策模式：
  冲动型 / 谨慎型 / 依赖他人型
  面对道德两难时的倾向：
```

---

### 阶段四：雕刻成长背景

背景是解释角色"为什么是现在这个样子"的答案，而不是履历表。

#### 关键经历筛选原则

不需要写完整传记，只需要找出**3-5个塑造性时刻**：

```
塑造性时刻类型：
  □ 第一次意识到世界不公平的时刻
  □ 被最在乎的人抛弃/背叛/否定的时刻  
  □ 第一次为某事感到真正骄傲的时刻
  □ 被迫做出违背自己的选择的时刻
  □ 遇到改变人生轨迹的人的时刻
```

每个塑造性时刻的记录格式：

```
时刻描述：[发生了什么，简短]
角色当时的感受：
留下的影响（信念/恐惧/行为习惯）：
至今是否已经"和解"：是 / 否 / 部分
```

#### 重要他者（Significant Others）

对角色影响最深的人：

```
人物：[关系]
影响内容：给了什么 / 夺走了什么 / 教会了什么
目前关系状态：存在 / 失联 / 死亡 / 关系已变
在角色内心的位置：理想化 / 怨恨 / 复杂 / 已释怀
```

---

### 阶段五：设计内在矛盾与成长弧线

#### 核心矛盾

一个好角色的核心矛盾通常是：**"他相信的"与"他真正需要的"之间的冲突**。

```
当前错误信念（阻碍成长的认知）：
真正需要学会的事：
成长的代价（要放弃什么才能成长）：
成长的触发点（什么事件会逼他改变）：
```

#### 角色弧线类型

| 弧线类型 | 适用场景 | 核心运动 |
|---------|---------|---------|
| 成长弧 | 大多数主角 | 从错误信念→觉醒→改变 |
| 堕落弧 | 悲剧主角/部分反派 | 从正常→被腐蚀→毁灭 |
| 平弧（稳定弧） | 部分主角/重要配角 | 角色不变，但改变了世界 |
| 创伤弧 | 深度剧情角色 | 从破碎→挣扎→重建（不一定完整） |

## 常见人设问题诊断

| 问题症状 | 根本原因 | 解决方向 |
|---------|---------|---------|
| 角色行为难以预测（不是意外，是混乱） | 缺乏一致的决策逻辑 | 明确"决策优先级"和"底线" |
| 角色感觉"完美"、读者不代入 | 缺乏真实的缺陷和脆弱 | 加入"扭曲信念"和软肋 |
| 主角和配角感觉一样 | 缺乏差异化设计 | 让他们在同一情境下做出截然不同的选择 |
| 反派感觉脸谱化 | 反派没有正当化自身行为的逻辑 | 给反派一个"他自己认为正确"的世界观 |
| 角色成长不可信 | 成长缺乏足够的内外部压力支撑 | 明确成长的代价，确保触发点足够重大 |
| 角色没有记忆点 | 缺乏标志性细节 | 设计1-2个外形/行为上的记忆锚点 |

## 与其他模块的交接

**输出给 character-manager**：完成人设卡后，将核心信息转换为 character-manager 的 JSON 档案格式，进入追踪管理阶段。

**输出给 plot-simulator**：人设卡中的"决策逻辑"和"底线"是剧情推演的边界参数——推演结果必须在这些参数内才成立。

**输出给 consistency-checker**：人设卡中的"不会这样做"列表，作为后续一致性校验的行为边界依据。

## 关系对设计（新增）

### 职责

有时需要同时设计两个互相塑造的角色——主角与导师、主角与对手、主角与羁绊。"关系对"设计的核心不是两张独立的人设卡，而是**两人之间的张力从哪里来**。

### 关系对类型

| 类型 | 核心张力来源 | 典型演变 |
|------|------------|---------|
| 主角 × 导师 | 导师拥有主角渴望的东西，但传授方式是主角必须克服的考验 | 仰望→质疑→超越→理解 |
| 主角 × 对手 | 相似的起点或欲望，不同的选择 | 竞争→对立→互为镜像→某种理解 |
| 主角 × 羁绊 | 无条件的接受（或拒绝接受）让主角无法继续逃避自己 | 陌生→依赖→羁绊成为成长的代价 |
| 主角 × 反派 | 反派代表了主角如果选择错误会变成的样子 | 对立→主角在反派身上看到自己的影子 |

### 关系对设计框架

```
步骤一：确定关系类型和两人的核心共同点
  他们共同拥有什么？（相似的欲望/伤口/起点）
  这个共同点如何让他们相互吸引（或排斥）？

步骤二：设计关键不同点
  同样的起点/欲望，他们在哪个选择节点走向了不同的路？
  这个不同点是什么导致的（性格差异/际遇差异）？

步骤三：设计张力核心
  他们之间最根本的张力是什么？
  （不是表面的冲突，而是深层的、无法用言语解决的东西）

步骤四：设计互相塑造的方式
  A的存在如何迫使B思考/改变？
  B的存在如何迫使A思考/改变？

步骤五：设计关系弧线
  关系的起点、关键转折点、终点
  转折点通常是一个迫使两人直面深层张力的事件
```

### 关系对输出格式

```
关系对设计卡：[角色A] × [角色B]

关系类型：主角 × 对手（镜像关系）

共同核心：
  两人都渴望"被认可"，都有被否定天赋的创伤
  这让他们在第一次见面时就有某种莫名的识别感

关键分叉点：
  相同的起点，但A选择了隐忍积累，B选择了激进证明
  这个选择差异的根源：A失去了被人保护的经历，B从未有过保护
  → 所以A在乎"不让别人受牵连"，B在乎"让所有人看到自己"

深层张力：
  B是A"如果走了另一条路"的样子
  A是B"不愿承认但内心羡慕"的样子
  他们对彼此有本能的厌恶，但这种厌恶里有某种认同

互相塑造：
  B迫使A思考：一直隐忍的代价是什么？
  A迫使B思考：如果强大不能让你不孤独，那强大有什么用？

关系弧线：
  起点：轻蔑对峙（表面）/ 本能识别（暗线）
  转折一（25%进度）：第一次合作，意外发现对方的真实能力
  转折二（60%进度）：共同面对强敌，不得不正视彼此
  终点方向：不会成为朋友，但会成为彼此最重要的见证者
```
