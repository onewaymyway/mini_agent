# 钩子设计技能（Hook Designer）

## 职责

管理全书每一章的"进入感"和"离开感"——读者翻开这章的第一句，以及读完这章后是否想继续翻下一页。前三章是最关键节点，有专项开篇系统；此后每章都有标准的章末钩子和章首衔接设计流程。

---

## 模块一：前三章开篇系统

### 读者决策链

```
网文读者：前100字 → 要不要读完这章
          第一章末 → 要不要读第二章
          第三章末 → 要不要追这本书

出版读者：前300字 → 要不要买
          前三章  → 要不要读完
```

### 第一段：黄金100字

**禁止的开场类型**

```
✗ 天气/环境铺陈："这是一个平静的早晨……"
✗ 主角醒来："他睁开眼睛，看到了陌生的天花板……"
✗ 自我介绍："我叫李凌云，今年十七岁……"
✗ 世界观说明："在这个大陆上，修炼者被称为……"
✗ 冷场景回忆：大段描写久远的过去
```

**有效的开场类型**

| 类型 | 机制 | 适用场景 |
|------|------|---------|
| 悬念切入 | 直接写反常现象，不解释 | 悬疑/玄幻/反转类 |
| 冲突切入 | 矛盾正在发生时介入 | 动作/冲突类 |
| 情感切入 | 读者能立刻理解的窘境 | 言情/成长类 |
| 反差切入 | 平常场景里有明显不对劲 | 悬疑/黑色幽默类 |
| 声音切入 | 叙事者的声音本身是钩子 | 第一人称/文学性强的作品 |

**第一段必须包含**

```
① 人物存在感（感受到有人在，不需要介绍）
② 一个具体的意象或行动（不能只是泛泛描写）
③ 一个问题或张力（读者想知道"然后呢"）
```

### 三章递进钩子系统

**第一章——建立陪伴欲望**（让读者想继续跟着这个人）

```
必须完成：
  □ 主角在这个世界的处境（不是履历）
  □ 主角最吸引人的一个特质（通过行动展示）
  □ 核心困境的第一个信号（轻，但必须存在）
  □ 章末悬念（读者迫切想知道答案）

章末钩子选项：
  信息悬念："王道长转过身，神情里有一种她从未见过的东西。"
  危机悬念："门外的脚步声在她房间门口停下来。"
  情感悬念："他第一次觉得，也许不是所有人都应该成为修炼者。"
```

**第二章——承诺这本书值得追**

```
必须完成：
  □ 回应第一章章末悬念（至少给出部分答案）
  □ 展示世界规则/独特性（通过事件，不是说明）
  □ 引入第二个重要角色
  □ 让主角面临一次有代价的选择
  □ 章末抛出比第一章更重要的悬念
```

**第三章——确认要追下去**

```
必须完成：
  □ 核心冲突明朗化（读者知道这本书要解决什么）
  □ 主角核心欲望和主要障碍都已清晰
  □ 至少埋下一条主线伏笔
  □ 读者感受到这个世界的规则感
  □ 章末钩子指向全书大冲突方向
```

**三章自检**

```
□ 第一段：有具体的人/物/动作，有问题或张力
□ 第一章内没有大段世界观说明
□ 主角首次登场通过行动/处境，不是自我介绍
□ 前三章内核心冲突已明朗化
□ 三个章末钩子类型不重复，且形成递进关系
□ 前三章内没有回忆倒叙（或不超过200字）
```

### 按题材的开篇策略

| 题材 | 重点 | 必须有 | 避免 |
|------|------|--------|------|
| 网文玄幻/修仙 | 展示天赋/特殊性 或 展示困境 | 前三章主角第一次展示实力 | 大量设定说明 |
| 悬疑/推理 | 展示诡异现象，制造不合理感 | 第一章末出现谜团 | 谜团前的大量铺垫 |
| 言情/都市 | 建立主角情感处境 | 前两章两主角有意义的互动 | 拖延两人相遇 |
| 历史/架空 | 用最小代价传达时代感 | 具体物件/称谓暗示时代 | 一开口就是历史背景 |
| 严肃文学 | 叙事声音本身是钩子 | 第一段语言质感独特 | 为情节钩子牺牲文风 |

## 模块二：全书章末钩子系统

每章结尾都需要一个有效钩子。以下是完整的钩子类型库和选择指南。

### 钩子类型全库

**悬念钩子**（最常用）——抛出一个读者迫切想知道的问题

```
信息悬念：揭示了一个新信息，但还没解释清楚
  "那封信上只写了四个字：速来，要死。"

危机悬念：以危机时刻结束，下章才解决
  "门被踹开的一刻，他看清了来人的面孔——"

反转悬念：最后一句话推翻了本章建立的认知
  "她转身离开，没有看到王道长从抽屉里取出那张旧画像。"
```

**情感钩子**——以情绪峰值收尾，读者被情感牵着走

```
共鸣钩子：主角的情绪让读者感同身受
  "他第一次，在这个世界上感到了一丝温暖。"

悲伤钩子：以失去或遗憾结束，余味绵长
  "他转过身，走了出去，没有回头。"

期待钩子：主角做出了一个决定，读者想看结果
  "他终于抬起头，做了一个连自己都没想到的决定。"
```

**信息钩子**——揭示重要信息的片段，但不完整

```
"王道长收起古籍，喃喃道：'果然是他的孩子……'"
→ 揭示了什么，但没说完，读者必须继续
```

**行动钩子**——主角开始做某事，读者想看结果

```
"李凌云握紧了剑，向青云峰内门深处走去。"
→ 行动开始，结果在下章
```

**问题钩子**——直接以一个问题结束

```
"但如果师傅一直知道，他为什么从不说？"
→ 主角/读者心中的问题，答案在下章
```

### 钩子强度分级与适用场景

| 强度 | 类型 | 适用 chapter_type |
|------|------|------------------|
| 强 | 危机悬念 / 反转悬念 | conflict · climax |
| 强 | 情感钩子（悲伤/共鸣）| climax · reveal |
| 中 | 信息钩子 / 信息悬念 | setup · reveal |
| 中 | 期待钩子 / 行动钩子 | conflict · setup |
| 轻 | 问题钩子 / 共鸣钩子（轻）| transition · opening |

**原则**：连续三章不能用同一类型钩子；过渡章用轻钩子；高潮后用情感钩子，不用危机钩子（给读者喘息）。

### 钩子力度自检

写完章末后，遮住最后一段，问自己：

```
① "我知道下章会发生什么吗？" 
   → 如果已知且不感兴趣，钩子力度不足
② "如果这是今晚最后能读的一章，我会不会熬夜再翻一章？"
   → 如果答案是否，钩子需要加强
③ "这个结尾符合本章的情感基调吗？"
   → 紧张章后用情感钩子，不要再加危机
```

## 模块三：章首衔接设计

章首衔接解决的是"上一章钩子 → 本章开头"的过渡问题。

### 四种衔接模式

**直接切入**（最常用于强钩子后）

```
上章末：门被踹开，他看清了来人的面孔——
本章首：是王师兄。（直接给答案，然后展开）

原则：强悬念钩子之后，不要拖延答案超过200字
```

**时间跳接**（适用于悬念解决后，跳过无意义过渡）

```
上章末：他终于做了一个决定。
本章首：三天后，青云宗迎来了这一年最热闹的考核日。

原则：跳过的时间段内"没有值得写的事"，直接跳
```

**视角切换**（适用于多视角小说，或需要平行叙事时）

```
上章末：A在危险中（悬念）
本章首：切换到B的视角，展示同一时段B的行动

原则：切换前在章末用醒目标记（"与此同时……"）；
      切换后不超过两章必须回到原视角解决悬念
```

**情绪延续**（适用于情感钩子后）

```
上章末：他第一次感到了温暖。
本章首：那种温暖在接下来的三天里一直跟着他，
        即使他努力假装没有。

原则：情感钩子是余波，本章首要承接这个余波，
      不要一开头就切换到完全不相关的事件
```

### 章首自检

```
□ 本章开头是否回应了上章的章末钩子？
□ 如果是强悬念钩子，答案是否在200字内给出？
□ 章首的第一句是否有存在感（具体意象/行动/声音）？
□ 读者看完第一段后，是否清楚"我们现在在哪里、正在发生什么"？
```

## 输出格式

针对每章（或每次被调用）输出：

```
钩子设计报告：第n章

章末钩子：
  类型：[类型]
  强度：[强/中/轻]
  具体文本：[可直接使用或参考的钩子句]
  理由：[为什么选这个类型和强度]

章首衔接（针对下一章）：
  衔接模式：[直接切入/时间跳接/视角切换/情绪延续]
  建议第n+1章开头：[具体写法建议]

连续三章钩子检查：
  第n-2章：[类型]
  第n-1章：[类型]
  第n章：[类型]
  → 是否有重复类型：[是/否]
```

## 与其他模块交接

- 前三章调用时机：novel-planner + character-designer 完成后，chapter-writer 写前三章前
- 日常调用时机：chapter-writer 写完每章正文后，设计章末钩子；开始写下一章前，设计章首衔接
- 依赖：novel-planner（全书主题/章节规划）· chapter-writer（本章 chapter_type）
- 输出：钩子文本 + 衔接建议，直接整合进 chapter-writer 的写作内容
