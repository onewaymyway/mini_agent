# json-repair

## 任务

你会收到一段损坏的 JSON 对象原文，以及该对象应当满足的结构要求。

- 只修正语法错误：缺失或多余的引号、逗号、括号，被截断的尾部。
- 不得删减、改写、合并任何字段的内容；不得补充原文中没有的信息。
- 某个值无法从原文确定时，保留为 `null`，不要猜测。
- 输出一个合法的 JSON 对象，只包含对象本身，不要任何说明文字或代码围栏。

## 输出

把结果写入提示中指定的文件。文件内容必须能被标准 JSON 解析器直接读取。
