# 一致性检验技能（Consistency Checker）

## 职责

小说的"自动审稿员"。章节写完后系统性发现各类矛盾，从事实硬错误到主题偏移，形成分级可操作的修改建议。

---

## 触发时机

| 条件 | 类型 |
|------|------|
| chapter-writer 完成一章 | 标准检验（本章全部维度）|
| 某幕最后一章完成 | 深度审稿（跨章节全局）|
| 重大蓝图变更后 | 影响传播检验 |

幕次边界识别：从 novel-planner 的 structure.acts[*].chapter_range 读取。

---

## 五个检验维度

### 1. 事实一致性（硬错误）

- 姓名/外貌/标志性细节前后一致
- 已死亡角色不再出现
- 角色不知道的信息，不在对话中表现出知道（对比 character-manager 的 known_secrets）
- 地理距离/旅行时间符合 world-builder 的 travel_rules
- 季节/时间描述连贯
- 同一时刻角色不出现在两个地点

### 2. 人物行为逻辑（软矛盾）

对比 character-manager 的 behavior_guide：

```
□ 行为是否违反 wont_do 列表（最高优先级）
□ 决策是否符合 decision_logic
□ 说话方式是否符合 speech_pattern
□ 压力下反应是否符合 stress_response
□ 情绪反应是否与 current_state.emotional 匹配
```

### 3. 世界规则遵守

```
□ 使用能力是否在当前境界范围内
□ 禁忌是否被无故打破
□ 例外情况是否有合理解释
```

### 4. 伏笔完整性

```
□ 本章计划兑现的伏笔是否兑现
□ 兑现内容是否与 plot-tracker 的 reveal_content 一致
□ 新增隐性承诺是否已注册为新伏笔
```

### 5. 主题一致性（新增维度）

对比 novel-planner 的 meta.theme 和 protagonist_arc：

```
□ 本章核心情节是否服务于全书主题？
□ 主角行为是否与当前 arc_stage 匹配？
  （如：弧线仍在"扭曲信念期"，本章却突然顿悟——过早）
□ 本章情感基调是否与该幕的 emotional_arc 相符？
□ 配角立场表达是否无意中削弱了全书价值观？
```

主题偏移属于"软提醒"级别，不阻塞写作，但记录到幕末深度审稿复盘。

---

## 检验报告格式

```
一致性检验报告：第n章

总体评级：🟢通过 / 🟡有瑕疵 / 🔴重大问题

🔴 硬错误（必须修改，阻塞进入下章）
  错误#1
  类型：时间线矛盾
  位置：第3段第2句
  问题："三天后到达血月城"，但 world_bible 记录炼气期修士飞行该距离仅需1天
  修改建议：改为"翌日清晨"或说明交通方式

🟡 软矛盾（建议修改）
  矛盾#1
  类型：人物行为逻辑
  问题：李凌云主动向敌人求饶——违反 wont_do[0]
  修改建议：改为迂回策略，或补充保护他人的前提

🔵 伏笔/主题提醒
  伏笔：王道长说"有时间带你去看样东西"——建议注册为新伏笔
  主题：李凌云主动倾诉感受，但弧线仍在"情感是弱点"阶段——建议后续补充后悔/抵触

✅ 通过项
  人物外貌一致 ✓ / 旅行时间合理 ✓ / 境界能力合规 ✓ / fs_003 已兑现 ✓
```

## 深度审稿（幕末触发）

额外执行：

```
1. 跨章节时间线完整梳理（该幕全部章节）
2. 主要角色成长轨迹是否合理推进
3. 该幕情感弧线是否如 acts[n].emotional_arc 实现
4. 伏笔健康：该幕新增 vs 兑现数量是否平衡
5. 主题连贯：有无某章情节与全书主题明显背离
6. 张力曲线：实际走向 vs plot-tracker 规划是否匹配
```

输出"幕次健康报告"，反馈给 novel-planner 判断是否需要调整后续蓝图。

---

## 特殊情况

**有意的"看似矛盾"**：标注为"疑似伏笔矛盾"，建议注册到 plot-tracker，不作为硬错误。

**重大改动传播**：评估哪些后续章节依赖了被改动的信息，哪些模块记录需要同步更新。

---

## 与其他模块交接

- 接收：chapter-writer（章节文本）
- 查询：character-manager / world-builder / plot-tracker / novel-planner
- 输出：chapter-writer（修改意见）· plot-tracker（新伏笔注册请求）
- 通过后通知：memory-manager（触发摘要存储）
