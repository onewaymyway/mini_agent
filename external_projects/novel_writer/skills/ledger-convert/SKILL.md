# ledger-convert

## 任务

你会得到一个已经损坏、无法被 JSON 解析的旧版伏笔账本文件路径。请：

1. 用文件读取工具完整阅读该文件。它可能缺括号、缺引号、被截断，也可能夹杂说明文字，请尽量识别出每一条伏笔记录。
2. 按提示中给出的「目标布局」，在指定的写出目录下直接写出 Markdown 小文件：每条伏笔一个文件，字段用 `key: JSON值` 逐行书写。
3. 不要修复或输出原始的 JSON 文件，不要改动原文件。
4. 原文没有的信息不要编造；无法确定的字段填 null。
5. 不遗漏任何一条伏笔。写完后自检：每个文件的文件头是否闭合、id 是否与文件名一致。

## 输出

只写入提示中指定的目录。完成后给出回执：写出了多少条伏笔，有哪些字段是推断或留空的。
