# 步骤越界自动还原

## 问题
`ch65.revise_loop` 等步骤会顺手改后续章节（如第66章正文）。旧逻辑只检测并要求 agent「恢复为修改前的内容」，
但 agent 手里没有改前内容，无法还原，三次尝试用完后步骤失败（耗时约 1750 秒）。

## 方案
1. 步骤开始前，框架备份所有受保护文件（后续章节步骤的产出）的原始字节。
2. 每次 agent 尝试结束后检测越界；有越界则由框架直接还原（改回原内容；原本不存在的新建文件删除）。
3. 还原成功：不算失败，本次不浪费重试；若仍需重试，提示里附一句「已自动还原，不要再动」。
4. prompt 中新增【受保护文件】清单（最多 12 个），明确告知只读、改了也会被还原。
5. 还原失败或关闭开关时，退回旧行为（要求 agent 处理）。

## 开关
`_studio/settings.json` 中 `step_guard_auto_restore`，默认 `true`；设为 `false` 恢复旧行为。

## 取舍
受保护范围仍是「后续章节步骤的产出」。agent 若改的是该范围之外的文件，不在本机制内。
