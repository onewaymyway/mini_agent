# 架空世界工坊 · 使用说明

## 启动看板

```bash
pip install -r requirements.txt
streamlit run app.py --server.port 8509
```

## 典型流程

0. **世界观简介**：在「总览」生成一篇背景介绍，快速了解当前世界观；世界推进后可重新生成。
1. **新建**：输入一句概念，生成宪章草案与首批设定。
2. **设定与提案**：「按要求修改设定」可选中对象修改，也可不选，由系统判断涉及哪些对象；「自动补全实体关系」为关系较少的实体建立连接（目标关系数可调），提示中会说明仍有几个实体未达标；页面底部的「关系图」可拖动、缩放、聚焦查看；批准宪章（`set_charter`）。可用「自动完善世界观」一键补全缺口并扩展；或在「按要求扩展」中用一句话提出需求（如「北方增加一个冰原部族」）。查看待确认提案：可勾选后批量批准或拒绝；「全部」按钮需先勾选确认。批量处理按列表顺序逐条检查，单条失败不影响其它条目。
3. **推进**：选择步数，并可设定每步时长与时间单位（分钟、小时、天、星期、月、年）；默认取「设置」中的值，也可只为本次推进临时调整。推进过程的每个阶段（收集状态、模型调用、解析、逐条写入、时钟推进）会实时显示，并保存到世界的运行日志中，可在「运行日志」中回看历史运行。
4. **时间线**：可切换为「按主体视角」，每个角色/实体一行的泳道图展示其参与的事件（同一时间的事件会错开排列），下方可选择某个主体查看它自己的时间线、同行者与变更；在任一事件之后开新分支（即回退），可在分支间切换与对比。
5. **故事与漫画**：生成小故事线时，「素材来源」可选「某个主体的时间线」：选中角色或实体，它参与的事件作为素材，并成为故事的主角；成文、分镜、漫画都沿用这一视角。直接创作短篇时也可以指定视角。漫画生成分两步：先生成**节拍表**（每页的叙事作用：铺垫/升级/转折/高潮/收束、画面焦点、页末钩子），再按节拍生成**分镜**（每格的镜头、版式、对白、音效、情绪）。漫画设置在故事页的「漫画设置」中：页数（生成分镜时确定：3/4/5/6/8/10/12 页或「按故事长度自动（不限制）」）、阅读方向（从左到右默认，或从右到左）、色彩（彩色默认，或黑白网点）；阅读方向与色彩可在「生成漫画图」时调整，无需重新生成分镜。成品为 **PNG 页**（服务端排字，`pages/page_NN.png`，可逐页下载或下载全部 zip）；页面上方的网页预览（`comic.html`）用于快速查看，尾巴与完整排字以 PNG 为准。每个操作（生成小故事线、成文、分镜、漫画图、导出）都会在状态框中实时显示运行日志，并保存到「运行日志（故事与漫画）」中回看；导出给 novel_writer。
## 命令行

```bash
python entrypoints/cli.py health
python entrypoints/cli.py init --concept "蒸汽与符文并存的海上帝国"
python entrypoints/cli.py approve --world <wid> --proposal <pid>
python entrypoints/cli.py advance --world <wid> --steps 2 --amount 3 --unit day   # 运行日志实时输出到 stderr
python entrypoints/cli.py fill --world <wid>
python entrypoints/cli.py expand --world <wid> --request "北方增加一个冰原部族"
python entrypoints/cli.py relations --world <wid>
python entrypoints/cli.py modify --world <wid> --request "把北港改为冬季封冻"
python entrypoints/cli.py enrich --world <wid>
python entrypoints/cli.py overview --world <wid>
python entrypoints/cli.py arc --world <wid> --from 0 --to 30
python entrypoints/cli.py short --world <wid> --arc <sid>
python entrypoints/cli.py board --world <wid> --story <sid> --pages 6 --reading ltr --color color   # --pages 可为 1–20 或 auto
python entrypoints/cli.py comic --world <wid> --story <sid> --reading rtl --color bw --candidates 2   # 输出 pages/*.png 与 comic_pages.zip
python entrypoints/cli.py limits --world <wid> --budget 120 --candidate-max 4    # 上限设置（本世界）
python entrypoints/cli.py text --world <wid> --story <sid> --page 1 --panel 2 --narration "雨停了"   # 修改文字，不调用图像模型
python entrypoints/cli.py comicexport --world <wid> --story <sid>                # 导出 CBZ 与条漫长图
python entrypoints/cli.py style --world <wid>                                    # 风格指南（全世界一份）
python entrypoints/cli.py sheets --world <wid> --story <sid> [--overwrite]       # 角色表：侧面 + 愤怒/悲伤/惊讶
python entrypoints/cli.py scenes --world <wid> --story <sid> [--overwrite]       # 场景图：分镜中用到的地点
python entrypoints/cli.py choose --world <wid> --story <sid> --page 1 --panel 1 --k 2   # 采用第 2 张候选
python entrypoints/cli.py export --world <wid> --story <sid>
```

## 环境变量

| 变量 | 作用 |
|---|---|
| `WORLD_FORGE_PROVIDERS=stub` | 全部离线（规则文本 + 占位图），不消耗额度 |
| `WORLD_FORGE_DATA_DIR` | 数据目录，默认 `data/` |
| `MINI_AGENT_ROOT` | mini_agent 仓库根，用于找到 LLMHelper 与 gen_image_with_text skill |
| `WORLD_FORGE_SKILLS_DIR` | 手动指定 `.claude/skills` 目录 |
| `AGNES_API_KEYS` / `AGNES_API_KEY` | 图像模型 key（与 skill 规则相同） |
| `WORLD_FORGE_IMAGE_BUDGET` | 单次操作图像调用上限的默认值（世界未单独设置时使用），默认 80 |
| `WORLD_FORGE_FONT` | PNG 排字使用的中文字体路径（未设置时依次尝试 Noto CJK、文泉驿、微软雅黑、苹方等常见字体） |

## 时间与历法

- 时钟以分钟为基本单位，推进步长 = 数值 × 单位。
- 架空历法：1 小时 = 60 分钟，1 天 = 24 小时，1 星期 = 7 天（周一至周日），1 月 = 30 天，1 年 = 12 月。
- 显示格式：`第 Y 年 M 月 D 日 周X HH:MM`，年、月、日从 0/1 起编号。
- 旧版本的世界（按年推进）会自动转换，无需手动处理。

## 角色与人设图

- 「角色」页每张卡片左侧显示人设图，并可单独「重新生成人设图」，历史版本可在卡片中展开查看。
- 「角色」页的「一键生成所有人设图」会为存活且还没有人设图的角色批量生成；勾选「覆盖已有人设图」则全部重新生成（旧图保留在 history/）。
- 批量生成在后台运行，逐个角色显示进度，可随时停止，已生成的人设图保留。

## 漫画排版与排字（P1）

- **版式**：每页由格子的 `span` 决定行：整行格独占一行、连续半行格两两配对；整页只剩两个半行格时上下排列，避免撑成窄条。整行格所在行更高，用来突出高潮。
- **阅读方向**：`rtl` 时同一行的格子从右往左排列，旁白默认在右上，音效默认在左下。
- **对白**：每句不超过 40 字（提示词要求 24 字）；类型取 `speech`（说话）、`thought`（心声，云朵式椭圆）、`shout`（呼喊，粗边框）；`speaker_side`（左/中/右）决定尾巴指向。
- **避开人脸**：近景和特写的画面正中会让开，气泡改放到左上或右上角。
- **音效与旁白**：音效为描边粗体字，直接叠在画面上；旁白为黄色说明框。
- **未生成的格子**：PNG 中显示占位框与失败原因，不会静默留白。
- **黑白模式**：格子转灰度并加强对比，并使用「黑白网点」风格提示词；真正的网点纹理与印刷版式留到后续阶段。

## 漫画的风格与设定图（P2）

- **风格指南**：在故事页「风格与设定图」中生成一次（全世界共用）。它包含线条、主色、光照的英文描述，之后每次出图都会带上，保持全书画风一致。黑白模式不带配色。
- **每幕配色**：节拍表为每页给出配色，写入该页每格的提示词；黑白模式不使用。
- **角色表**：为本故事出场且已有立绘的角色生成侧面和三种表情（愤怒、悲伤、惊讶）。分镜格的「情绪」决定参考哪张表情图：愤怒/生气、悲伤/哭/难过、惊讶/震惊会命中对应表情，其它（包括平静）沿用立绘。
- **场景图**：分镜格可以指定「地点」（取自地理类设定）。生成时先由文本模型写英文场景描述，结果保存在该设定条目上，再生成场景图；出图时作为参考图。
- **参考图优先级**：上一格 → 主角表情图（无则立绘）→ 地点场景图 → 其它出场角色立绘；最多 3 张（与原先一致）。
- **候选**：「每格候选数」可选 1–3（默认 1）。候选会全部保存，默认采用第一张成功的；在「单格重新生成」中可查看候选图并选用其中一张，选用后只重新拼装成品，不调用图像模型。
- **上限设置**：故事页「上限设置」或 CLI `limits` 可修改本世界的两个上限，保存在世界元数据中，对漫画、角色表、场景图生效：
  - 单次操作的图像调用上限：1–500，默认 80（未设置时取环境变量 `WORLD_FORGE_IMAGE_BUDGET`）；
  - 每格候选数上限：1–5，默认 3；候选数选择框只显示不超过该上限的选项。
  超出范围会报错且不保存。调用达到上限时停止，已完成的保留，并在日志中提示。
- **注意**：风格指南、角色表、场景图都只是参考，不做自动质检；生成结果需要人工查看。

## 漫画阅读与导出（P4）

- **网页阅读器**：每次拼装成品时生成 `reader.html`，引用同目录 `pages/` 中的 PNG 成品页。可翻页（按钮或方向键，从右到左时方向键反向）、连续滚动。整个故事目录需要一起移动。
- **导出 CBZ**：`comic.cbz`，标准漫画压缩包，包含各页 PNG 与 `ComicInfo.xml`；从右到左的漫画会写入对应的阅读方向标记。
- **条漫长图**：`comic_strip.png`，成品页按顺序竖向拼接（页与页之间没有间距，不重新排版）。
- **编辑文字**：故事页「编辑文字」可修改某一格的旁白、音效与对白文字（说话人与气泡位置不变），保存后只重新排字拼装，不调用图像模型。对白仍受 40 字上限约束，对白数量不能增减。
- **注意**：导出只使用已生成的成品页；需要先生成漫画图。

## 漫画的叙事与镜头（P5）

分镜不再只有景别标签，每格还包括：

- **衔接 `connects_prev`**：一句话说明本格如何承接上一格（动作的前后、视线的指向、场景的变化）。
- **机位 `camera`**：平视、俯视、仰视、过肩、特写镜头、推近、拉远、反打。
- **视线 `gaze`**：每个出场角色的视线方向（朝左、朝右、朝画外、朝观众、向下、向上、看向对方、低头）。
- **画面左右顺序 `screen_order`**：两人以上同框时，画面中从左到右的人物顺序。
- **动作 `action`** 与 **构图 `composition`**（写明主体位置与留白区，留白用于放气泡）。
- **旁白不超过 30 字**，只写画面无法表达的信息。

**越轴检查**：相邻格中同时出现的两个以上角色，左右顺序翻转且未标注机位「反打」，会被判为越轴并触发重试。反打只用于两人对话时的交替拍摄。

图像提示词按镜头、机位、构图、动作、视线、画面左右顺序、人物外观、背景与配色的顺序结构化拼接，并要求保留气泡留白。

## 停止与重新生成

- **停止**：推进、生成小故事线/短篇/分镜/漫画图、世界观简介、立绘等耗时操作在后台运行。页面顶部的任务条实时显示日志，点击「停止」后，操作在下一个安全点结束（每次模型调用前、每一步或每一格之间）。当前正在进行的模型调用会完成，已写入的内容全部保留；漫画会拼装已完成的格子。同一世界同一时间只能有一个后台任务。
- **重新生成**：
  - 小故事线：沿用原来的事件重新生成，故事 id 不变。
  - 短篇：沿用创建时的原始输入重新成文。
  - 分镜：重新生成后，漫画图需要重新生成。
  - 漫画：可以重新生成全部格子，也可以只重新生成某一格，其它格保留原图。
  - 立绘、世界观简介：直接覆盖。
- **旧版本**：重新生成前，旧文件会保存到对应目录的 `history/` 下（带时间戳），故事页的「旧版本」里可以查看。
- **暂不支持**：推进历史的"重新推进"（需要用分支回退实现）；扩展世界观、关系补全、按要求修改设定仍为同步操作，暂无停止按钮。
