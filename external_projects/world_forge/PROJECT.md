# world_forge — 架空世界工坊

> 方案：`next_doc/world_forge_external_project_plan.md`（已确认）。
> 看板端口：**8509**。遵循外部项目标准结构：自包含，可独立于 daemon 运行。

## 目标

用户给出一句概念，初始化一个架空世界；随后通过交互与自动方式完善设定，推进世界历史（自动生成角色与事件），
支持时间线回退与分支；并把世界中的事件产出为小故事线（供 novel_writer 使用）、短篇小说与漫画（真实生成分镜图）。

## 已确认的决策

- 新建外部项目，不扩展 world_simulator（只借鉴其分支落盘设计，不 import 其代码）。
- 次要设定自动写入；与宪章或既有设定冲突的写入一律阻止，记录原因，不静默覆盖。
- 漫画真实生图，封装参考 novel_to_video：经 mini_agent 的 `gen_image_with_text` skill 调用 Agnes 图像模型，
  无 key 时自动降级为占位图并在界面与结果中标注。
- 默认中文。

## 关键设计

- **写入唯一入口**：`proposals.submit`。流程：一致性检查 → 有问题即 `blocked`；否则风险分级，minor 自动写入（`applied`），
  major 进入 `pending` 等待批准。所有记录都保留在 `proposals/queue.json`，可追溯。
- **风险分级**：宪章、删除、势力/历史/技术类新增、修改核心字段或权力归属、主要角色、角色死亡，都属重大；
  地理、物品、次要角色、描述性补充属次要。
- **一致性检查**：重名、引用不存在的对象、已死亡角色参与事件或复活、事件违反宪章硬规则（由模型在推进时标注）、
  历史产生后宪章不可改、被关系引用的实体不可直接删除。
- **分支**：每条分支保存自己的完整事件文件。回退 = 在更早的事件上分叉。设定库全局共享（不分支）。
- **锁**：所有写操作在 `locks/world.lock` 下串行化；模型调用一律在锁外完成。
- **失败不落地**：模型输出结构不合格时重试一次，仍失败则抛错，不写入任何内容。

## 已知限制

- 真实文本模型（mini_agent LLMHelper）与真实图像模型（Agnes）未在本环境端到端验证：本环境没有 API key 与 mini_agent 的 provider 配置。
  离线模式（`WORLD_FORGE_PROVIDERS=stub`）已完整跑通全部流程与测试。
- 离线规则生成只产出占位文本，内容标注为「规则占位」。
- 推进时事件引用的新角色若被判为重大（如主要角色），事件会因引用待确认对象而被拦截，需先批准角色提案。
- 待确认的事件不会进入时间线，后续推进基于已落地的历史进行；若希望推进基于待确认事件，需要后续改造。
- 设定库不分支：不同分支共享同一套设定，分支只分事件。
- 分镜每页 1–5 格；网页预览 comic.html 以嵌入方式引用图片，可独立打开，但不画尾巴，完整排字以 PNG 页为准。
- 漫画目前没有质检环节：图像模型生成的人物错误或乱码文字会直接进入成品（P3 处理）。
- 漫画风格仍为提示词约束，黑白模式只是转灰度，尚无真正的网点纹理（P2 处理）。
- 页数为 auto 时不设上限，但单次模型调用的输出长度有限，故事很长时节拍表或分镜可能生成失败（需要分段生成，待后续阶段）。
- PNG 排字依赖中文字体；服务器上找不到字体时中文会显示为方框，可通过 `WORLD_FORGE_FONT` 指定。
- 尚未注册到 daemon（需在 daemon 侧执行 `mini-agent projects register external_projects/world_forge`，注册后默认不开启定时任务）。
- 测试环境下 Streamlit 只做 AppTest 冒烟，界面交互需要在浏览器中手动走一遍。
