# 文章 → 讲解视频：使用说明

本项目把一篇 Markdown 文章转换为讲解视频：配音、字幕、动态画面、署名与水印。
界面由 Streamlit 提供（端口见 `project.yaml`），也可以用命令行。

## 0. 从 mini_agent 看板启动

在 mini_agent 看板的「🗂️ 外部项目」中注册 `article_to_video`（「➕ 注册新项目」→「扫描 external_projects 目录」），然后点「▶ 启动」「🌐 打开」。端口为 8507，默认只监听本机（`http://localhost:8507`）。也可以直接运行：

```bash
streamlit run app.py --server.port 8507 --server.address 127.0.0.1
```

## 1. 准备

- Python 3.10+，并安装 `requirements.txt` 中的依赖（streamlit、pillow、pytest）。
- ffmpeg 与 ffprobe 会自动查找（与 novel_to_video 一致），顺序：环境变量 `FFMPEG_BIN` / `FFPROBE_BIN`（也认 `NOVEL_FFMPEG_PATH` / `NOVEL_FFPROBE_PATH`）→ pip 包 `imageio-ffmpeg` → conda 环境（当前激活的优先，其次名字含 novel/mv/video 的）→ 系统 PATH。找不到时，报错会列出每种方式的尝试结果。
- 中文字体：程序会自动查找系统字体（Windows 微软雅黑、macOS 苹方、Linux Noto CJK 或文泉驿）。找不到时，设置环境变量 `ARTICLE_TO_VIDEO_FONT` 指向一个 .ttf / .ttc / .otf 文件。
- 文本模型：通过 mini_agent 配置（写稿与模型版分镜需要）。
- 语音：CosyVoice 或 edge-tts（按项目设置中的引擎顺序降级）。
- 生图：Agnes，需要环境变量 `AGNES_API_KEYS`（或 `AGNES_API_KEY`）。没有 key 时插图自动改为程序绘制，流程不中断。

## 2. 最快的方式：驾驶舱

启动界面后，在侧边栏选择「🧭 驾驶舱」（R7 起，驾驶舱是主入口，侧边栏只剩驾驶舱、新建项目、项目、设置）。驾驶舱顶部是「流程总览」（每个步骤的状态与下一步），下方的步骤区包含「🧭 总控」与各个步骤（大纲、口播稿、配音、分镜、合成导出），用一排单选按钮切换：

1. 在「📥 新建项目」导入文章（上传 .md，填写作者与水印）。
2. 选择挡位（见第 3 节）和预算。
3. 点击「▶ 运行流水线（后台）」。
4. 需要人工确认时，流水线会停在该检查点，状态显示为「等待人工确认」。在驾驶舱的对应步骤中确认后，回到「🧭 总控」再次运行即可继续。
5. 全部完成后，在「🎬 合成导出」步骤下载成片、字幕、封面和报告。

点击运行后，驾驶舱下方的「流水线运行监控」会实时显示：

- **步骤时间表**：每个阶段（大纲、口播稿、配音、分镜、画面渲染、章合成、导出）及其下每一章的开始/结束时间、用时、状态（✅ 完成 / ⏸ 等待确认 / ❌ 失败 / ⏹ 已停止 / ⏳ 进行中）；失败时显示原因和完整堆栈。
- **后台日志**：每 2 秒刷新、自动滚到最新一行；耗时久的步骤每 30 秒会写一条「仍在进行（已 N 秒）」。
- 命令行启动的流水线也会显示在这里（只能查看，不能从界面停止）。
- 日志文件在项目目录的 `logs/job.jsonl`。

任何时候都可以点「⏹ 请求停止」。已完成的产物会保留，下次运行会从断点继续。

### 2.1 各页面的后台运行与日志

- 大纲、口播稿、配音、分镜、合成导出中会运行的操作（生成大纲、写稿、配音、生成分镜、渲染、合成、导出、试听、单章预览）都在后台运行，页面不会卡住。运行中可在页面底部的「运行日志」面板点「⏹ 请求停止」。
- 每个页面的底部都有本页的运行日志（每 2 秒刷新，自动滚到最新一行）。页面顶部的状态条会显示本页最近一次任务的结果；失败时显示原因，详细堆栈在日志中。
- 同一项目同一时间只运行一个后台任务。有任务运行时，相关按钮会暂时禁用，等待其结束即可。
- 「📚 项目」页底部显示该项目的最近日志（全部页面的记录）；「📥 新建项目」导入成功后，底部显示导入日志。
- 编辑、保存、确认是即时操作，不会产生后台任务。

### 2.2 设置（⚙️ 设置）

所有可调参数集中在「⚙️ 设置」页，分两层：

- **全局默认**（「全局默认」标签）：保存到项目集合目录下的 `settings.json`。只影响之后新建的项目，以及没有覆盖该字段的已有项目。
- **当前项目**（「当前项目」标签）：每个字段旁显示生效值的来源（项目覆盖 / 全局默认 / 内置默认）。保存只写入与全局不同的字段；可以整组或逐字段「恢复为全局默认」。保存后会列出受影响的阶段（例如改了字幕只需重新合成，改了画幅需要重新渲染画面）。

作者、来源标题、来源链接、BGM 文件路径属于项目本身，只能在「当前项目」中设置。

各业务页面（导入、大纲、口播稿、配音、分镜、合成导出、驾驶舱）的默认值都来自设置；页面上只保留本次运行的临时选择，例如驾驶舱的「运行到哪一步」、是否确认终审、是否离线冒烟。API key 不保存在设置中，仍只从环境变量读取。

## 3. 挡位

| 挡位 | 含义 | 适用场景 |
|---|---|---|
| **G0**（默认） | 大纲、口播、分镜、终审都需要人工确认 | 第一次使用，或需要逐步把关 |
| **G1** | 只有大纲与终审需要人工；口播与分镜通过校验后自动确认 | 大纲已满意，希望减少点击 |
| **G2** | 全自动；必须设置预算上限 | 批量生产，已确认流程稳定 |

G2 必须设置「最多生图次数」或「最长耗时」中的至少一项，否则拒绝启动。超限时流水线停止，状态显示为「超出预算」，已完成的部分保留。

## 4. 阶段说明

流水线依次执行以下阶段，可以用「运行到」选择停在哪一步：

1. **大纲（outline）**：把文章划分为 5～7 章，给出每章的时长预算。大纲默认使用模型（mini_agent 的 LLM）。点击“生成 / 重新生成”时会从原文重新调用模型，不复用已有的分节摘要；只有勾选“复用已有的分节摘要（断点续跑）”时才会复用。目标时长在大纲页与设置页是同一个值，修改任意一处都会更新另一处，需要已配置的文本模型；未就绪时页面会显示原因并禁用生成，此时可改选「离线规则」先生成一版（结构较粗略）。模型失败不会悄悄改用规则版。R5 起，模型输出的金句与数字会按内容对齐原文（忽略标点与大小写）；对不上原文的条目会被剔除并写入运行日志，不会让整个大纲失败。只有 JSON 结构不合法或摘要为空时才会重试。若中途失败，已完成的分节摘要会保留，下次生成从未完成的组继续。口播稿（R11 起）出现问题时，先由模型只修正出问题的句子，不再整章重写；只有段落级错误或修正失败时才整章重写。金句由模型判断与原文哪一句意思相同（不要求逐字一致）。口播稿（R9 起）的忠实度校验同样忽略标点与大小写：金句只要内容与原文一致，就会被换成原文中的规范写法；数字按完整记号比较（3.5 与 35 不相同，3,000 与 3000 相同）。检查点 C0：可在「🗺️ 大纲」改章标题、合并或拆分章、调整时长。大纲页（R8 起）先显示「大纲校验」：覆盖、时长、忠实度、结构四类，每类给出通过/需注意/未通过与处理建议；随后是章节卡片（标题、一句话、覆盖的小节、预计分钟与占比）。大纲页还有「金句（写稿时原样使用）」（R10）：可以直接输入金句并指定所属章节，所属章节的口播必须原样使用这些金句，不要求金句出现在原文中（列表会标注“原文”或“人工”来源）。模型给出但原文中找不到的金句，列在「模型给出但未在原文中找到的内容」中，可以修改文字后加入大纲，或忽略；数字暂未接入口播，只能忽略。
2. **口播稿（script）**：逐章写出口播。校验会拦截改了数字、编造原话、编造英文词和 Markdown 残留。检查点 C1。
3. **配音（voice）**：逐句合成，生成时间轴。缓存只重做改动的句子。
4. **分镜（storyboard）**：决定每段用卡片、流程图、堆叠层图、表格、公式、列表、金句、递进卡、定义卡还是插图。检查点 C2。模型版分镜会在结果里附上「覆盖报告」，公式、递进、概念定义、回顾、对比未被镜头承载时在整章提示中说明；分镜页的「📊 结构覆盖报告（C2）」面板列出每个原文结构由哪些镜头承载。第四期起还有两种卡：对比卡（原文「不是…而是…」的对照，两侧逐字取自原文）与回顾卡（多行总结，每张最多 3 条，超过则分两张）；设置页「视觉」里有两个默认关闭的开关：严格覆盖（未承载则本章分镜失败）、插图主体必须出自原文的具象类比。
5. **画面（render）**：绘制卡片与插图，插图受预算约束。
6. **合成（compose）**：每章编码为视频，字幕、进度条、章标签在此加入。
7. **导出（export）**：拼接各章，加入片头、片尾、下三分之一条、水印和 AI 声明，输出成片。检查点：终审。

## 5. 预算与生图

- 每分钟插图上限（默认 2.5）决定每章可生成的图片数量。
- 「一图多用」：同一张生成图可以按不同取景用于多个镜头（默认每图 2 个镜头）。在「⚙️ 设置」的「视觉与插图」中调整，或在分镜页点「🔁 重新分配一图多用」。
- 改水印、改署名、改字幕与转场只重做最后几步，不会重新生图或重新渲染画面。

## 6. 多期

超过 15 分钟（可在「⚙️ 设置」的「讲解与配音」中修改「单期最长」）的文章会在章边界拆成多期。每期独立成片，文件名带「_第N期」；期首有「上期回顾」，期末有「下期预告」，内容取自相邻章的一句话。命令行加 `--merge-all` 可额外导出全集。

## 7. 署名与水印

在「⚙️ 设置」的「当前项目」标签页中设置：作者（留空则不署名）、来源链接、片头标题卡、下三分之一条、片尾卡、角标、水印（文字，位置与模式可选）、AI 生成声明、背景音乐（需要你提供本地音频）。「🎬 合成导出」页只显示生效值，不再重复设置表单。

- 水印位置可选四角、居中或斜向平铺；模式可选固定或缓慢漂移。
- AI 声明默认开启，并写入片尾卡与文件元数据。

## 8. 命令行

```bash
# 一键流水线（挡位 G0：在检查点停下）
python entrypoints/run_pipeline.py --id <项目目录名> --gear G0

# 全自动（必须设预算）
python entrypoints/run_pipeline.py --id <项目目录名> --gear G2 --max-images 200 --max-minutes 60

# 只跑到分镜，不做后面的步骤
python entrypoints/run_pipeline.py --id <项目目录名> --until storyboard

# 离线冒烟：语音静音、生图占位、大纲用离线规则，不产生费用（写稿仍需要文本模型）
python entrypoints/run_pipeline.py --id <项目目录名> --offline --gear G1

# 终审后导出（G0/G1 需要 --approve）
python entrypoints/run_pipeline.py --id <项目目录名> --until export --approve --merge-all
```

项目目录名即导入时生成的目录名，位于项目集合目录下（由 `ARTICLE_TO_VIDEO_HOME` 决定）。命令的输出是 JSON，同时写入项目目录下的 `pipeline.json`。退出码：完成为 0，其它为 1。

### 8.1 批量队列（命令行）

界面的「📦 批量生成」页负责加入文章、设置标题与作者、共用参数。命令行读取同一份队列（位于项目集合目录下的 `_queue/`）：

```bash
# 查看队列状态（JSON），不运行
python entrypoints/batch_run.py --status

# 前台运行队列，直到队列处理完；Ctrl+C 可中断（当前篇记为「已停止」，下次运行继续）
python entrypoints/batch_run.py

# 运行前重排失败、已停止、停在检查点或超预算的条目；加编号则只重排一篇
python entrypoints/batch_run.py --requeue
python entrypoints/batch_run.py --requeue q0003

# 只重写报告，不运行
python entrypoints/batch_run.py --report

# 队列不在默认目录时，用 --root 指定项目集合目录
python entrypoints/batch_run.py --root D:\video_projects --status
```

- 每次运行结束（包括中断）都会写入 `_queue/report.md` 与 `_queue/report.json`：每篇的状态、重试次数、耗时（墙钟）、生图次数、成片路径与未完成原因。
- 退出码：0 = 正常且没有失败条目；1 = 有失败条目，或参数与队列错误；3 = 已有运行者（界面或另一条命令行正在运行），本次未启动；130 = Ctrl+C 中断。
- 批量生成会产生模型与生图费用，入口不登记为定时任务，只由人手动运行。
- 队列运行到导出阶段时默认自动通过终审并导出（共用参数「自动导出成片」）。关闭后，每篇会停在终审，需要在驾驶舱逐篇确认。

## 9. 整章重置

若某章的口播、分镜或画面不满意，可在驾驶舱的「整章重置」中选择章与起始阶段，勾选确认后删除该章从此阶段起的产物。图片缓存保留，重新生成时会按内容指纹复用。重置不可撤销，且会丢弃该章的人工编辑。

## 10. 常见问题

- **状态是「等待人工确认」**：这是门控在工作。去对应页面（大纲、口播、分镜、合成导出）确认后再运行。
- **状态是「超出预算」**：增大预算，或减少插图（降低每分钟上限、提高一图多用的镜头数）。
- **插图变成了卡片**：生图未配置或失败，清单里会写明原因。配置 `AGNES_API_KEYS` 后重新运行即可，已成功的图片会复用。
- **中文显示为方框或乱码**：设置 `ARTICLE_TO_VIDEO_FONT` 指向一个中文字体文件。
- **成片校验未通过**：报告中会列出原因（分辨率、帧率、音轨、时长、字幕越界或水印越界）。
- **配音失败**：检查语音引擎的网络与代理设置。配音默认直连，不读取系统代理；需要走系统代理时，在「⚙️ 设置 → 讲解与配音」打开「配音使用系统代理」，或填写指定代理地址。大模型与生图同样默认直连：分别在「讲解与配音」打开「大模型请求使用系统代理」、在「视觉」打开「生图请求使用系统代理」；失败时不会悄悄替换为静音。

## 11. 边界

- 本项目不抓取网络图片，不做真人素材剪辑。
- BGM 只使用你提供的本地音频，不下载、不生成音乐。
- 生成的插图与配音带有 AI 生成性质；默认在片尾与元数据中声明，请按平台规则保留该声明。
