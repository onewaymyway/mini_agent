当前已完成 P0（导入）、P1（规划）、P2（口播稿）、P3（配音与时间轴）、P4（分镜与画面）、P5（合成与导出）、P6（署名与水印）、P7（自动化与收尾，驾驶舱）。全部阶段已完成。使用说明见 `docs/USAGE.md`。

使用顺序：「📥 新建项目」导入 → 「🗺️ 大纲」生成并确认（C0）→ 「📝 口播稿」写稿并逐章确认（C1）→ 「🔊 配音」逐句配音并生成时间轴 → 「🎞️ 分镜」生成并确认（C2）→ `render_visuals.py` 渲染画面清单。

合成导出：「🎬 合成导出」逐章合成（需画面已渲染）→ 导出成片。也可用 `compose_part.py` 与 `export_final.py`。

署名与水印：「🎬 合成导出」页下方可设置作者、片头/片尾、下三分之一条、角标、水印与 AI 声明、BGM。改水印只重做最后一步，不重算章视频。
