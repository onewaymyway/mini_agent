# 看板

启动：`streamlit run app.py --server.port 8506`，浏览器打开 http://localhost:8506 。页签顺序：推荐、抓取结果、报告、反馈记录、信息源、订阅、添加信息源、运行与调度、设置与管理。

## 推荐
把抓取结果整理成几个分区，减少在平铺列表中翻找的时间。

- **分区**：今日精选、多源热点、关注主题、探索、稍后看、其余（折叠）。同一事件只出现在一个分区。
- **卡片**：标题、来源（多源显示“N 个来源”）、首次出现时间、一句话理由；右侧有 👍 / 👎 / ⏰（同一事件的所有报道一起记录）、🚫（不再显示此信息源）、“🖥 打开”（专用浏览器）与“打开”（新标签页）。
- **会话快照**：反馈、屏蔽等操作不会改变列表；点“🔄 刷新推荐”或重新加载页面才会更新。
- **🔀 换一批**：页面顶部和最下方都有。排除当前屏幕上的条目，换成下一批未展示过的内容，并回到页面最前面。可连续点击，“刷新推荐”会清空排除记录。
- **⚙ 显示数量设置**：调整精选、探索、热点、主题、稍后看、其余的条数，保存后刷新生效。
- **快速分诊模式**：一次只显示一条，用 👍 / 👎 / ⏰ 或“跳过”快速打标，适合冷启动。
- **筛选**：时间范围、信息源分类、信息源类型、“显示已处理”。
- **兴趣画像**：查看画像与学到的关键词、来源权重；可添加手写主题与屏蔽词。
- **学习权重**（默认关闭）：训练后需通过留出集验证，并在页面开启才会生效。
- **LLM 增强**（默认关闭）：开启后点击“运行”才调用模型，生成主题与摘要，并判断近似报道是否为同一事件；有每日上限。
- **离线回放**：比较推荐顺序与时间倒序在历史反馈上的表现（仅供参考）。
- **已“不再显示”的信息源**：可在底部恢复。

## 抓取结果
查看每个信息源的快照：按信息源分类与类型筛选，或“合并显示”把多个源在时间窗内合成一张列表。每条可“感兴趣 / 不感兴趣”，也可直接打开原文。

“立即抓取”的结果区域（在“信息源”页签中）显示抓取结果与调试信息，失败时包含错误位置原文与可下载的抓取原文。

## 报告
选择报告计划，查看摘要与 Markdown 内容；可整份听报，或逐条朗读（使用浏览器语音，不生成音频文件）。

## 反馈记录
列出所有 👍 / 👎 / ⏰ / 打开记录，支持按动作筛选。

## 信息源
- 列表：启用、停用、查看配置与健康状态、恢复被暂停的源。
- 编辑：选择信息源后修改配置并保存（会校验）。
- 立即抓取：抓取一次并显示结果与调试信息。
- 候选信息源：对话生成或发现的候选，预览后确认添加。

## 订阅
订阅类源（小说章节、视频更新）的进度与更新提醒。

## 添加信息源
表单添加，或对话生成（LLM 草稿 → 预览 → 修改 → 确认）。

## 运行与调度
- 调度状态：后台调度是否运行、下次执行时间。
- 运行记录：按日期列出每次运行的结果（成功、条数、耗时、错误）。

## 设置与管理
- **服务管理**：反馈接收服务与专用浏览器的启动、停止；“看板启动后自动恢复”开关。
- **专用浏览器**：状态、调试端口、抓取模式（launch 或 cdp）。
- **登录**：打开有头浏览器登录站点，登录态保存在专用浏览器的数据目录中。
- **推荐效果评估**：曝光、打开、反馈的统计。
